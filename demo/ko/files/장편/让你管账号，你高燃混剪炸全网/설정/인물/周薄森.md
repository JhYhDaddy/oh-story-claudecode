# 저우보썬

<a id="基本信息"></a>

## 기본 정보
- 신분: 로켓군 문공단 부단장, 문직 6급(소령 상당). 뉴미디어 홍보 담당이며 장천의 직속 상사.
- 핵심 특성: 부하를 감싸는 자애로운 아버지형 지휘관 + 체면 중시와 책임 전가 + 이득을 보면 즉시 태도 전환.
- 현재 능력: 조직 내 정치 감각이 예민하고 상하 조율에 능함. 뉴미디어 자체에는 완전히 문외한(10장 전문가판을 보고 먼저 ‘영혼이 빠졌다’고 한 것은 전문 분석이 아닌 감성적 판단).
- 핵심 동기: 부대 홍보 실적과 중간 평가 순위를 지키면서 자기 부하도 연루되지 않도록 보호하기.
- 약점/결함: 일이 생기면 책임을 어떻게 피할지 먼저 생각한다. 장천을 칭찬하다 영상을 본 적 없음을 들켜 체면을 구긴다. 13장 여론 위험을 알면서도 망설여 선제 개입 기회를 놓친다.

<a id="外在表现"></a>

## 외적 표현

**신분/직책**: 로켓군 문공단 부단장. 반듯한 군복과 노련한 태도. 찻잔을 들거나 관자놀이를 문지르는 습관(6장 무거운 걸음으로 사무실에 돌아와 찻잔을 들었다가 차가 식었음을 발견).

**언행 표식**:
- 감정 조절은 평범하다. 긴장하면 애써 침착한 척하다 좋은 소식에는 ‘웃음이 귀까지 걸리고’ 연달아 허벅지를 친다.
- 부하 보호: 첫 반응은 장천의 잘못을 조사하는 것이 아니라 숨게 하고 자신이 책임을 떠안는 것(‘정말 기밀 유출이라도 장천의 책임은 아닙니다’).
- 책임 전가 습관: 분위기가 나쁠 때 먼저 책임을 지는 것은 주도권을 잡기 위해서이며 순수한 희생이 아니다. 좋은 일임을 확인하면 즉시 ‘이 아이는 우리 단의 자랑’으로 말을 바꾼다.
- 10장 전문가판 상영 후 모두 침묵할 때 먼저 ‘영혼이 빠졌다’고 해 장야오쭈 대신 모두의 생각을 말한다. 어느 정도 군사적 미감이 있다.

**외모**: (원문에 자세한 묘사가 없어 임시 설정) 군복을 입은 중년 남성, 노련한 인상.

<a id="内在分析"></a>

## 내면 분석

**성격**:
- 조직 생활의 베테랑. 콘텐츠 판단보다 정치적 반응이 빠르다. 6장 조사 대신 표창하러 왔음을 알자 0.5초 만에 ‘큰일 났다’에서 ‘장천은 우리 단의 기둥’으로 바뀐다.
- 부하를 지키려는 본능은 진짜다(6장 ‘내 부하이니 어떻게든 장천을 지켜야 한다’). 다만 체면과 이익도 섞여 있어 순수한 부성애는 아니다.
- 15장 궁지에 몰리자 장야오쭈와 함께 지휘 단계를 뛰어넘어 군단장에게 보고하며 시간을 번다. 결정적 순간에는 습관적 자기보호를 넘어선다.

**목표**: 단기적으로 중간 평가 꼴찌를 피하기. 중기적으로 장천의 실적을 통해 ‘문공단 뉴미디어는 제로’라는 오명을 씻기.

**비밀/내적 모순**: 중자자는 장천을 칭찬하며 두 번 태도를 바꾸는 모습을 본다. 자신도 영상을 제대로 본 적 없고 전문 판단을 감에 의존함을 안다. 자신감이 부족해 늘 장야오쭈를 따르는 근본 이유다.

<a id="语言风格"></a>

## 말투

**화법**:
- 부하에게: 짧은 명령, 군더더기 없음(‘버릇없이!’ ‘빨리 장천에게 알려! 숨어 있으라고, 얼굴 내밀지 말라고 해!’).
- 상급자 장야오쭈에게: 간결한 보고. 예의를 차릴 겨를이 없으면 바로 본론.
- 외부인/기자에게: 공식적 예의와 빠른 태도 전환. 문제가 없음을 알면 열정적인 홍보 모드로 바뀌어 끝없이 칭찬.
- 전문 판단: 감에 따라 한마디로 규정(‘영혼이 빠졌어’). 이유를 설명하지 않지만 핵심을 짚는 경우가 많음.

**입버릇/대표 표현**:
- 급할 때: ‘일이 터졌어!’ ‘밖으로 새면 결과를 감당할 수 없어.’
- 장천 칭찬 문구: ‘젊고 유능하고 생각이 있고 머리가 좋아’, ‘독특한 영상 언어’, ‘앞날이 창창해’, ‘우리 단의 자랑이야’.
- 10장 대표 문장: ‘영혼이 빠졌어.’(짧게 결론을 내림)

**상대별 차이**:
| 대화 상대 | 어조 특징 |
|---------|---------|
| 장천(부하) | 명령조지만 보호 의도가 숨어 있음. 앞에서보다 뒤에서 관대함 |
| 장야오쭈(상급자) | 주로 복종하며 핵심 정보를 제때 보고. 가끔 먼저 행동하고 보고(장천을 숨긴 뒤 전화) |
| 중자자(외부 기자) | 경계에서 열정으로 변하는 태도가 뚜렷함. 칭찬을 멈추지 못하고 사교성이 과함 |
| 치 지휘관(더 높은 상급자) | 원문에 직접 묘사 없으나 매우 공손할 것으로 추정 |

<a id="出场记录"></a>

## 등장 기록

| 장 | 핵심 사건 | 상태 변화 |
|------|---------|---------|
| 1장 | 새로 부임한 장천에게 뉴미디어 운영 임무 전달 | 일상 업무, 특별한 감정 없음 |
| 2장 | 장천의 촬영을 현장에서 보고 흐뭇해하면서도 효과가 늦을까 걱정 | 흐뭇함→숨은 걱정(홍보 압박이 커 단기 성과를 염려) |
| 6장 | 기밀 유출로 오해해 서둘러 책임을 떠안음→중자자가 표창이라고 정정→즉시 장천 극찬 | 불안과 책임 부담→오해 해소→열정적 전환(성격을 가장 완전하게 보여 주는 장) |
| 7장 | 장천을 ‘단의 기둥’으로 소개. 취재 중 영상을 안 봤음이 드러나 얼굴이 붉어짐 | 자신만만한 칭찬→현장에서 망신 |
| 9장 | 장야오쭈의 ‘지휘관 지시로 검을 드러낸다’는 설명에 걱정이 흥분으로 변하고 역사적 의미를 깨달음 | 걱정→흥분 |
| 10장 | 홍보 실적 때문에 질책받아 불만. 전문가판 상영 후 먼저 ‘영혼이 빠졌다’고 함 | 불만→함께 느끼는 자부심. 뜻밖의 전문적 의견 제시 |
| 11장 | 중자자 이름의 특집 보도가 실린 최신 《군보》를 은밀한 태도로 건네며 정보 전달 | 조금 우쭐한 전달자 |
| 13장 | 예고 영상을 보고 우려하지만 부하의 업무로 끊겨 즉시 개입하지 못함 | 잠재적 위험 관리자, 망설임 |
| 15장 | 장야오쭈와 치 군단장에게 직보해 반대를 물리치며 장천에게 시간을 벌어 줌. 완성된 〈소원대로〉를 듣고 천재라고 확신 | 초조함→안도→‘장천, 정말 천재로군!’ |
| 17장 | 주둔지에서 관영 매체의 MV 공유 소식을 듣고 치 지휘관에게 보고. 모두 열광 | 다시 감탄하며 함께 자부심을 느낌 |
