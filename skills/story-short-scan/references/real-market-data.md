# 단편 플랫폼 과거 표본

실시간 순위가 없으면 검증할 후보를 제안하는 데 사용한다. 순위가 있으면 제목과 소개 작성법을 대조할 수 있다.

아래는 치마오·헤이옌·즈후·뎬중의 과거 표본 노트다. 표집 시각·표본 목록·통계 기준이 없으므로 정성적 패턴만 남긴다. 플랫폼 선호·분량·과금 규칙은 이번 순위 조사나 플랫폼 설명을 따르며 이 문서에서 추정하지 않는다.

## 플랫폼 차이

| 차원 | 치마오 | 헤이옌 | 뎬중 | 즈후 |
|------|------|------|------|------|
| 핵심 방향 | 회귀와 잘못 바로잡기 환상 | 강한 자극과 고통스러운 사랑 | 빠른 감정적 보상 | 감정과 인식 변화 |
| 소개 | 핵심 갈등 전면 배치 | 상처나 의문 전면 배치 | 사건과 반격 압축 | 독립된 초단편 형성 가능 |
| 도입 패턴 | 회귀/갈등 전면 배치 | 극단적 충격/도덕적 짓밟기 | 제목이 곧 플롯/극단적 사건 | 한 문장 폭탄/인상적인 문장 |
| 결말 패턴 | 화해나 새 삶 | 행복·비극 모두 | 뒤늦은 후회나 반격 실현 | 열린 결말·반전 등 다양한 마무리 |
| 특징 요소 | 회귀·책 속 진입·속마음 듣기 | 영혼 시점·극한의 고통스러운 사랑 | 실시간 댓글·독심·시스템 | 전문 세부·기발한 발상·BL |
| 반전 기법 | 태도 반전(회귀 뒤 180도 변화) | 도덕·공포 반전 | 신분·죽음 반전 | 정보 격차·감정의 깊은 층 공개 |
| 쾌감 리듬 | 압박·각성·반격·치유 | 반전과 감정 폭발 교대 | 국소적 전환이 결말에 합류 | 옛 정보의 새 의미를 점진적으로 공개 |
| 감정 표현 | 연속된 감정 변화 | 강한 감정 대립 | 직접적인 감정 표현 | 절제된 표현과 뒤늦은 방출 |

## 소개 작성법

| 플랫폼 | 소개 구조 | 핵심 특징 |
|------|---------|---------|
| 치마오 재벌물 | 정상 생활 → 상처 주는 사건 → 가장 잔인한 대화 → 여주인공의 반전 → 의문 후킹 | 갈등 대화로 관계의 상처를 보여 줌 |
| 헤이옌 여성향 | 점층적 고발/속마음 폭로/시한부 초읽기/회귀 대비/공개 망신과 비장의 패 | 핵심은 ‘이번에는 내가…’ |
| 헤이옌 남성향 | 최소 대화와 정보 폭탄/전생 피살과 회귀/직장 착취와 초자연 | 첫 문단에 갈등 장면이나 대화 배치 |
| 뎬중 | 장면 설정 + 신뢰의 함정 + 치명적 진실 + 반격 암시 | 초반 갈등 압축 |
| 즈후 | 인물 관계 + 핵심 갈등 + 전환 + 인상적인 문장 또는 여백 | 독립된 초단편 형성 가능 |

즈후 소개는 주요 대사나 여백으로 끝나는 경우가 많다. 이야기는 고부 갈등·남아 선호·의료 분쟁 같은 사회적 의제에 기울며 전문 세부가 많다. 의료물에는 의학 지식, 법률물에는 법률 세부가 쓰인다.

## 뎬중 제목

- `白眼狼妹妹把家产送人，我让她净身出户`(은혜 모르는 여동생이 가산을 남에게 주자, 나는 빈손으로 쫓아냈다) = 인물 + 행동 + 역공
- `愚人节死在棺材里后，三个哥哥都悔疯了`(만우절 관 속에서 죽은 뒤, 세 오빠는 미친 듯 후회했다) = 사건 + 결과 + 감정
- `春节返程，老公一家把我女儿挂车外狗笼子里`(춘절 귀갓길, 남편 가족이 내 딸을 차 밖 개장에 매달았다) = 장면 + 갈등 + 분노

## 장르 조합

| 장르 | 흔한 조합 | 감정 방향 | 흔한 플랫폼 |
|------|----------|----------|----------|
| 재벌·명문가 | 계약 결혼 + 첫사랑의 이상화 + 각성과 떠남 | 고통 → 통쾌함 | 치마오/헤이옌 |
| 현실 생활 | 가족의 불공정 + 회귀/각성 + 역공 | 분노 → 후련함 | 치마오 |
| 궁중·가문 암투 | 피해 + 인내와 계획 + 반격과 제위 획득 | 억압 → 극한의 해방 | 치마오 |
| 시대 배경 회귀 | 누명과 희생양 + 회귀 + 다른 길 선택 | 억울함 → 통쾌함 | 치마오 |
| 현대 미스터리 | 초자연 설정 + 범죄 + 반전 | 긴장 → 충격 | 치마오/즈후 |
| 현환·선협 | 회귀 + 이례적 행동 + 상대의 자멸 | 통쾌함 → 더 큰 통쾌함 | 치마오 |
| 영혼 시점 비극 | 극한의 학대 + 영혼의 관찰 + 후회 | 분노 → 풀리지 않는 응어리 | 뎬중/헤이옌 |
| 직장 역전 | 회귀/시공간 이동 + 투자 + 전남편의 후회 | 답답함 → 극도의 통쾌함 | 뎬중 |
| 가상 역사 | 성별 반전/신분 뒤바뀜 + 떠남 + 후회 | 억울함 → 해방감 | 치마오 |
| 가족 복수 | 외도/배신 + 증거 수집 + 공개 응징 | 분노 → 통쾌함 | 치마오/헤이옌 |
