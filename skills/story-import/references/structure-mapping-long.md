# 구조 이전(장편)

`작품분석실/{导入书名}/`를 장편 프로젝트 `{导入书名}/`로 바꿉니다. 작품·분석 디렉터리명은 같아야 하며 본문 쓰기 보호 장치가 이 이름으로 이전을 허용합니다.

외부 비교 작품·목표 플랫폼·작가 지시는 가져오기 기록(`{书目录}/.story/work/가져오기기록.md`)에서 읽습니다. 이 단계에서는 추적 디렉터리 골격만 만들며 상태는 Phase 4가 초기화합니다. 장별 상세 개요는 마지막에 묶음별로 역추론합니다.

## 이전 단계

### Step 1：创建项目骨架

프로젝트 골격을 만듭니다.

```
{导入书名}/
├── 설정/
│   ├── 세계관/
│   ├── 인물/
│   └── 세력/
├── 개요/
├── 본문/
├── 추적/
│   └── 장별기록/
├── 비교작품/                       # 선택. 외부 비교 작품을 명시 연결한 경우만 하위 디렉터리 생성
└── 참고자료/
```

### Step 2：正文标准化

원문을 `본문/`로 옮겨 `제XXX장_장제목.md`로 통일합니다. 구분자를 식별하고 제목을 추출하며 번호 앞에 0을 채웁니다(제1장 → 제001장). 본문 내용은 유지합니다. 아래 표준화 규칙 참조.

### Step 3：角色文件迁移

`작품분석실/{导入书名}/인물/{角色名}.md`를 아래 인물 템플릿에 따라 `설정/인물/{角色名}.md`로 옮깁니다. 분석 카드의 「定位」 분류를 유지합니다.

| 등급 | 기준 | 이전 방식 |
|------|------|---------|
| 주인공 | 등장 장 ≥50% + 주선 추진 + 완전한 성장 과정 | 전체 이전 |
| 악역 | 주인공과 대립 + 핵심 갈등 추진 + 명확한 동기 | 전체 이전 |
| 핵심 조연 | 등장 장 ≥20% 또는 중요한 지선 추진, 또는 독립 인격·성장 보유 | 전체 이전 |
| 기능 인물 | 등장 장 <20% + 제한적 역할 | 템플릿의 기능 인물도 작성하는 항목만 |

### Step 4：关系文件迁移

`작품분석실/{导入书名}/인물/인물관계.md`를 아래 관계 변환 규칙에 따라 `설정/관계.md`로 변환합니다.

### Step 5：同步世界观设定

현 분석 계약은 주제별 `작품분석실/{导入书名}/설정/세계관/*.md`·`설정/세력/*.md`를 출력하므로 그대로 동기화합니다. `세계관/`에는 `배경설정.md`가 필수이며 짧은 힘의 체계는 합쳐도 됩니다. 현 산출물이 없으면 멈추고 Stage 4 복구를 안내합니다. 검사기가 사용 가능으로 확인한 옛 결과는 기존 평면 설정을 현 프로젝트 경로로 변환해 출처를 표시하되 분석 서고에 역기입·덮어쓰기하지 않습니다. 아래 세계관 규칙 참조.

### Step 6：题材定位生成

분석 보고서의 핵심 발견으로 아래 템플릿에 따라 `설정/소재방향.md`를 생성합니다. 이 작품 장르·핵심 발상·감정·리듬 요약은 `작품분석실/{导入书名}/`에서 오지만 비교 작품 등록이 아닙니다. `{导入书名}`를 비교 작품으로 채우면 안 됩니다. 기록 「作者交代」의 선호·금지선은 「作者已定」에 함께 써 이어쓰기에서 볼 수 있게 합니다.

### Step 7：外部对标（只在导入记录绑定了外部对标时）

기록에 외부 `{对标书名}`가 연결돼 있으면 [benchmark-sync.md](benchmark-sync.md)를 따라 포지셔닝에 등록을 추가하고 `작품분석실/{对标书名}/`의 자료·문체를 `비교작품/{对标书名}/`로 동기화합니다. 연결이 없으면 이 단계를 생략하고 비교 하위 디렉터리를 만들지 않습니다.

### Step 8：本书文风

프로젝트에 `설정/문체.md`는 없고 `작품분석실/{导入书名}/문체.md`는 있으면 작가에게 묻습니다. ‘이 작품의 문장 길이·대사 방식·주요 기법을 정리했습니다. 작품 문체 설정으로 저장할까요? 저장하면 이어쓰기에 적용하고, 안 하면 비교 작품·기본 작법을 따릅니다.’ 동의하면 `설정/문체.md`로 복사하고 첫 줄에 `> 来源：导入时从本书已写章节整理（작품분석실/{导入书名}/문체.md）` 출처 표식을 씁니다. 거절하면 만들지 않습니다. 이미 있으면 덮어쓰거나 다시 묻지 않습니다. 작품 문체는 `설정/`에만 두며 `비교작품/`로 복사하지 않습니다.

### Step 9：大纲与卷纲（作者确认点）

아래 역추론 규칙대로 `개요/개요.md`를 만듭니다. 원문에 권 경계가 명확하면 따릅니다. 없으면 후보 구분을 보여 주고 **작가 확인을 기다린 뒤에만** 권 구조·`개요/권개요_제X권.md`를 확정합니다. 결정 또는 ‘원문 권 경계 따름’을 기록 「卷划分」에 씁니다. `플롯/분산사건.md`는 관련 권 개요·전체 개요 부록에 합칩니다.

권 개요마다 Python 3을 `python3` → `python` → `py -3` 순으로 찾아 `{PYTHON} {story-import skill 根}/scripts/outline_view.py --check --strict {书目录}/개요/권개요_제X권.md`를 실행합니다. 문제 0개여야 확정입니다. 본문 단계도 같은 스크립트로 단위별 조회하므로 통과하지 못하면 첫 이어쓰기 장에서 멈춥니다.

### Step 10：逐批反推细纲

권 개요 확정·아래 품질 점검 통과 후 기록 「结构迁移」를 표시하고 [outline-reverse.md](outline-reverse.md)에 따라 상세 개요를 묶음별 역추론합니다. 그 단계에서는 패키지만 읽고 이 파일을 다시 읽지 않습니다. 첫 묶음 전 새 대화에서 ‘가져오기 계속’을 요청하도록 권합니다.

## 본문 표준화 규칙

이름 형식은 `第{零填充三位}章_{장제목}.md`입니다. 인식 예시 파일명은 유지합니다.

| 원본 파일명 | 표준화 |
|---------|---------|
| 제1장_初入江湖.txt | 제001장_初入江湖.md |
| 제1장.md | 제001장_无题.md |
| chapter01.md | 제001장_无题.md |
| 01_觉醒.md | 제001장_觉醒.md |

원본이 큰 단일 파일이면 다음 구분자로 나눕니다.

| 구분자 패턴 | 예시 |
|-----------|------|
| `第X章` / `第X章 ` / `第X章：` / `第X章 XXX` | 第1章 初入江湖 |
| `Chapter X` | Chapter 1 |
| 숫자 번호 + 제목 | 1. 觉醒 |

- 소설 본문을 유지하고 사건·표현·대사를 다시 쓰지 않습니다.
- 인코딩은 UTF-8로 통일합니다.
- 다운로드 광고 등 소설 본문이 아님을 확실히 알 수 있는 머리·꼬리 정보만 제거합니다. 불확실하면 보존합니다.

## 인물 파일 이전 템플릿

장편 집필의 주인공·조연 카드와 필드가 같아 바로 사용할 수 있습니다. 근거는 분석 카드·핵심 사건입니다. 외모·말버릇·상징 행동은 독자의 인물 식별 기준이므로 원문 문장을 찾아 쓰고 없으면 `[待补充]`로 둡니다. 지어내지 않습니다. 아래 중국어 제목·필드·열거값은 저장·조회 계약 표식입니다.

```markdown
---
name: {角色名}
---

# {角色名}

## 角色卡
- 角色定位：{主角/反派/核心配角/功能角色; 이야기에서 맡은 일을 한 문장으로}（일회성 기능 인물도 작성）
- 身份标签：{제N장 기준 신분}（일회성 기능 인물도 작성）
- 与主角关系：{주인공 자신이면 「本人」}（일회성 기능 인물도 작성）
- 外貌特征：{원문에 나온 기억할 만한 특징 3-5개}
- 性格关键词：{행동에서 3-5개를 정리하고 모순된 면도 명시}
- 核心目标：{전체 작품·현 단계에서 이루려는 것}
- 核心动机：{반드시 이뤄야 하는 이유}
- 致命弱点：{실수를 유발하는 성격 결함}
- 口头禅/标志动作：{원문에서 반복되는 말·행동을 원문 그대로 인용}（일회성 기능 인물도 작성）
- 当前能力与资源：{제N장 기준}
- 退场方式：{퇴장했으면 장 번호·방식. 아직이면 [待补充]}

## 经历与成长
{분석 카드의 핵심 경험·성장 과정을 시간순으로}

## 出场记录
| 章节 | 关键事件 | 状态变化 |
|------|---------|---------|
| 第{N}章 | {사건} | {변화} |

## 别名
{별명·유형·근거. 없으면 「无」}
```

## 관계 파일 변환 규칙

분석의 `인물관계.md`는 방향성 표입니다: `关系ID | 主体 → 客体 | 关系动作/类型 | 表面关系 | 真实关系 | 触发事件 | 双方得失 | 变化后状态 | 证据等级 | 证据`. 같은 인물 쌍의 변화 이력은 행별로 보존합니다. 프로젝트 형식으로 변환할 때:

- 인물 쌍마다 한 행으로 합칩니다. 양방향 행동이 다르면 「当前状态」에 ‘A는 B를 보호하고 B는 A를 이용한다’처럼 씁니다.
- 관계 유형 매핑: 家人→亲情, 恋人→爱情, 朋友→友情, 敌人→敌对, 师徒→师生, 上下级→主从, 商业→利益. 동료는 실제 상호작용에 따라 友情·利益로 분류합니다.
- 감정 성향 열은 원본에 없으므로 행동·양측 득실로 판단합니다. 보호·의존은 주로 긍정, 통제·기만·경쟁은 주로 부정입니다. 둘 다 있으면 「复杂」.
- 현재 상태는 마지막 행의 「变化后状态」, 시작 장은 가장 이른 근거 장, 변화 지점은 각 행 「触发事件」의 시간순 목록입니다.
- 「真实关系」·「表面关系」가 다르면 「表面与真实」에 별도 기록하고 N장까지 독자가 아는지 표시합니다. 이어쓰기에서 일찍 밝히지 않도록 반드시 보존합니다.
- 근거 등급 C이면 현재 상태 뒤에 「（只有旁人说法）」(타인의 말만 있음)을 붙입니다.

### 대상 템플릿(설정/관계.md)

```markdown
# 角色关系图

## 关系总览

| 角色 A | 角色 B | 关系类型{亲情/爱情/友情/敌对/师生/主从/利益} | 情感倾向{正面/负面/中性/复杂} | 当前状态 | 起始章节 | 变化节点 |
|--------|--------|---------------------------------------------|-----------------------------|---------|---------|---------|
| {名} | {名} | {유형} | {성향} | {설명} | 第{N}章 | {사건} |

## 表面与真实

| 角色 A | 角色 B | 表面关系 | 真实关系 | 读者截至第 N 章知道吗 |
|--------|--------|---------|---------|---------------------|
| {名} | {名} | {타인이 보는 관계} | {실제 관계} | {알고 있음/일부 앎/모름} |

## 关系演变

{角色A}<->{角色B}：
- 起点：{초기 관계}
- 转折：{장·사건·변화}
- 当前：{현재 상태}

## 核心冲突关系

{줄거리를 추진하는 핵심 대립·협력 관계 2-3쌍}
```

표면·실제 관계가 다른 경우가 없으면 「表面与真实」에 「无」.

## 세계관 동기화

현재 story-long-analyze는 주제별 디렉터리를 출력하므로 그대로 동기화합니다. Phase 2에서 사용 가능으로 확인한 옛 결과는 Step 5대로 실제 내용에서 대상 경로로 변환합니다.

| 원본 | 대상 | 현 계약 |
|---------|---------|---------|
| `작품분석실/{导入书名}/설정/세계관/*.md` | `{项目}/설정/세계관/*.md` | 원형 동기화, `배경설정.md` 필수 |
| `작품분석실/{导入书名}/설정/세력/*.md` | `{项目}/설정/세력/*.md` | 독립된 세력 파일 원형 동기화 |

`능력체계.md`·`地理.md`·작은 세력 자료가 200자 미만이면 상위 분석에서 `배경설정.md`에 합치므로 독립 파일은 생략 가능합니다. 현 계약 산출물의 필수 파일이 없으면 story-long-analyze Stage 4 보완을 안내합니다. 사용 가능으로 확인한 옛 결과는 출처 매핑으로 변환하며 옛 파일명만으로 막지 않습니다.

## 개요 역추론

### 전체 개요의 권 구조·분권 규칙

`플롯/이야기선.md`·`플롯/*.md`·`빠른미리보기.md`에서 역추론하며 **분권은 아래 결정 규칙을 반드시 따릅니다**.

**A: 원문에 명확한 권 경계가 있음**: 「第一卷 XXXX」·「卷一」 등 권 계층 제목이 있으면 그대로 나누며 사용자에게 묻지 않습니다.

**B: 원문에 명확한 권 경계가 없음**: 기계적으로 나누지 않습니다.

1. 이야기선·장소 변경·큰 시간 도약으로 후보 경계를 찾습니다(아래 표 참조).
2. 후보를 사용자에게 보여 줍니다. 예:

   ```
   분권 후보(참고안, 확정 아님):
   - 제1권 후보: 제1-18장(세계관 구축·초기 성장, 장소: 교외 학원)
   - 제2권 후보: 제19-45장(주선 갈등 폭발, 장소: 제도 의사당)
   - 제3권 후보: 제46-XX장(최종 대결, 장소 변경: 고대 유적)
   이야기선·장소 변경을 기준으로 찾았습니다. 확인하거나 조정해 주세요.
   ```

3. **사용자 확인을 기다린 뒤에만** `개요/개요.md` 권 구조·`개요/권개요_제X권.md`를 생성합니다.
4. 확인 전에는 `개요/개요.md`에 후보만 기록하고 권 개요를 확정하지 않습니다.

> 원문에 경계가 없는 작품을 ‘권마다 기본 20-40장’으로 기계 분할하면 **안 됩니다**. 후보는 참고이며 최종 결정은 사용자 몫입니다.

### 필드 대응

권마다 줄거리 파일에서 추출합니다.
- 핵심 갈등 → 「核心矛盾」.
- `플롯/{标题}.md`의 구조 분포·사건 → 단위 카드 하나(박자·목표·장애물·핵심 행동·실현).

미완결의 마지막 카드는 N장까지만 범위를 잡습니다. N+1장 이후 단위는 이어쓰기 보완에서 배치하며 가져오기에서 미리 쓰지 않습니다.

### 필드 대응

- 장르·핵심 발상·작은 차별점 → `작품분석보고서.md`「基本信息」「核心发现」.
- 핵심 발상의 세 층위 → 표면 매력·깊은 통쾌함·장기 후킹을 각각 `작품분석보고서.md`「核心发现」「读者在追什么」「伏笔与冲突」에서 추출.
- 독자 요구·감정 동력 → `플롯/감정모듈.md`. 현 계약 산출물이 없으면 Stage 3+ 보완. 옛 결과는 대응 개요의 호환 규칙 적용.
- 리듬·촉발 참고 → `플롯/리듬.md`. 현 계약 산출물이 없으면 이전을 멈추고 보완하며 다른 개요로 대신하지 않음. 옛 결과는 「未知/待增强」로 표시하고 계속 가능.
- 장르 틀 → 현재 작품의 가져오기 분석에서 생성. 외부 비교 등록·요약은 benchmark-sync.md가 추가하며 출처 두 종류를 섞지 않음.

## 품질 점검표

이전 후 상세 개요 묶음 단계 전에 내부 검사합니다. 작가에게 읽어 주지 않으며 실패하면 먼저 고칩니다.

- [ ] 본문 파일 수 = 원본 장 수
- [ ] 주요 인물(주인공·핵심 조연) 파일 생성. 외모·말버릇에 원문 근거 또는 [待补充]
- [ ] 관계.md가 비어 있지 않고 분석에서 표면·진실이 다른 관계가 모두 「表面与真实」에 있음
- [ ] 개요.md에 권 구조 존재. 카드 범위가 해당 권 집필 완료 장 전체를 포함. `outline_view.py --check --strict` 문제 0개
- [ ] 흩어진 사건을 관련 권 개요·전체 개요 부록에 통합
- [ ] 원문 권 경계가 없으면 사용자 분권 확인 필수. 결과가 가져오기 기록에 있음
- [ ] `작품분석실/{导入书名}/`를 `비교작품/`에 복사하지 않았고 자기 작품을 비교 등록하지 않음
- [ ] 외부 비교가 연결됐으면 benchmark-sync.md 점검표 확인
