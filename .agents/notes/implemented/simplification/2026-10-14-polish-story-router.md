# Agent Note: 진입 라우터와 작가 기억 설명 다듬기

Status: implemented

## Problem

story 진입점에는 단편적인 조작 설명, 작가 기억의 충돌 처리 흐름과 맞지 않는 축약 설명, ‘기존 프로젝트가 배포되지 않았으면 무조건 setup부터’라는 규칙과 순차 가져오기·조회 대체 경로 사이의 모순이 있었다. 현재 버전을 모를 때도 의미적 버전 비교를 요구하면서 실행 가능한 분기가 없었다. 대시보드 설명은 실제로 콘텐츠 버전을 검증하는데도 여전히 수정 시간을 기준으로 설명했다.

## Decision

진입점과 작가 기억 자료 두 개를 각각 다섯 단계로 다듬었다. 전문 집필 용어와 필요한 실행 계약을 유지한다. 프로젝트 환경은 대상 스킬에 따라 확인하고 기존 조회 대체 경로를 따른다. 구조나 소재만 논의할 때는 바로 라우팅하고 프로젝트 생성 시 초기화한다. 현재 버전을 모르면 최신 안정 버전만 보여 준다. 신구 선호가 충돌하면 기억 프로토콜에 따라 후보를 기록하고 작가가 명시적으로 교체할 때만 replace한다. 기억 자료는 앞선 공유 원본 다듬기에서 수정했고 이번에 라우터와 스크립트를 다시 확인했다. 대시보드 저장·삭제는 기존 스크립트의 콘텐츠 버전 검증에 맞춰 설명하고 명령은 유지한다.

## Alternatives considered

- 배포되지 않은 모든 프로젝트에서 setup을 먼저 실행하면 경로가 통일된다. 그러나 기존 순차 가져오기와 조회 대체 경로를 막으므로 대상 스킬이 환경 조건을 처리한다.
- 현재 버전이 없으면 구버전으로 간주해 갱신하면 알 수 없는 상태를 생략할 수 있다. 그러나 비교 근거가 없으므로 조회된 최신 버전만 제시하고 갱신 여부는 작가가 결정한다.

## Consequences

진입 지침이 기존 흐름과 일치하고 알 수 없는 상태에서 거짓 비교를 하지 않는다. 라우팅은 대상 스킬의 환경 검사에 의존해야 한다. 갱신과 기존 브라우저 작업에 필요한 사용자 승인은 유지하며 새로운 확인 절차를 추가하지 않는다.
