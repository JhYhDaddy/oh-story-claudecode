# Agent Note: 한국어 문서·주석 현지화

Status: implemented

## Problem

중국어 중심 문서와 일부 영어 문서·주석을 한국어로 활용해야 한다. 이 저장소에서는 Markdown이 단순 설명뿐 아니라 스킬 지침, 배포 템플릿, 스크립트가 읽는 계약에도 쓰인다. 제목·필드명·경로를 일괄 치환하면 실제 동작이나 기존 테스트 자료가 달라질 수 있다.

## Decision

일반 설명과 코드 주석은 한국어로 번역한다. 실행 코드, 파일명·경로, 설정 키·값, 정규식이 읽는 계약 표식, 원문 검증 자료는 보존한다. 기계가 읽는 중국어 표현에는 한국어 설명을 병기한다. 공유 참조 문서는 원본을 번역한 후 기존 동기화 도구로 복제하며, 배포용 에이전트 문서는 원본 템플릿에서 다시 생성한다. 생성기가 삽입하는 문서 설명 문자열도 번역하되 권한 판단을 유지한다. 한국어 템플릿에서도 기존 호스트 정책을 적용하도록 Antigravity 생성기의 CDP 실패/웹 검색 대체 문구 변환에 한국어 대응을 추가한다.

소설 원문과 추적 상태 파생 파일처럼 테스트 증거로 쓰이는 문서는 원본을 보존하고 `demo/ko/files/`에 한국어 열람본을 둔다. 이 위치는 기존 대시보드의 프로젝트 탐색 결과를 늘리지 않도록 선택한다. 라이선스 원문은 보존하고 `LICENSE_KO.md`에 참고 번역을 제공한다.

한국어 변환에 따른 글자 수 증가가 기존 문서 예산을 넘는 경우에는 실제 로드량을 측정하여 변경 이유와 함께 명시적으로 조정한다. 호출당 제한을 묵시적으로 끄지 않으며, 필요한 예외는 기존 예외 규약에 따라 기록한다.

2026-11-07 통합 측정에서는 문서·분기·최악 중첩 예산 269개를 실제 한국어 공백 제외 글자 수에 맞춰 100자 단위로 조정했다. 기존 파일 목록과 조건부 읽기·중첩 조합을 유지한다. 전역 `path_ceiling.limit`는 35000으로 유지하고, 이를 넘는 한국어 경로 9개만 `path_ceiling.exempt`에 명시했다. 설정 직접 작성, 권 개요 작업 묶음/직접 작성, 장편 단일 장/일일 집필/대수정 직접 작성, 단편 구상/본문, 단독 원고 검토가 해당하며 실측 최대치는 각 경로의 `why`에 기록한다. 단편 장르 카드 두 개의 최종 수동 번역 뒤에는 해당 파일·분기의 예산 4개씩을 추가 재측정해 반영했다. 이는 번역의 의미를 삭제하거나 실제 동시 읽기를 서로 배타적인 것으로 등록하지 않기 위한 선택이다. 예외 경로도 개별 분기·중첩 예산 검사를 계속 받는다.

`build_architect_brief.py`가 절을 추출하는 제목 25개와 `新增物三级` 표식은 원형을 복구하고 한국어 설명을 병기했다. 한국어 제목을 가리키던 링크는 명시적 앵커로 유지하며 공유 참조도 다시 동기화한다. 번역 문서는 baseline과 같은 LF로 저장한다. 실행 코드의 절 추출 동작이나 실패 조건은 바꾸지 않는다.

## Alternatives considered

- 모든 중국어를 한국어로 치환하면 겉보기에는 일관된 현지화가 된다. 그러나 중국어 파일명·필드·표제를 읽는 기존 코드와 데이터 계약까지 바뀌므로 채택하지 않는다.
- 실행용 문서를 모두 원문으로 두고 별도 번역만 만들면 기존 동작 보존이 쉽다. 그러나 사용자가 실제로 읽고 활용하는 스킬 문서가 계속 중국어로 남으므로, 기계 소비 자료에만 이 방식을 적용한다.
- 여러 문장을 한 번에 기계 번역하면 빠르다. 표본에서 문장 간 내용 이동과 부정 조건 손실을 확인했으므로, 문장·문단별 번역과 보호 문자열 검증을 사용하고 핵심 조건을 직접 대조한다.

번역된 안내 문구를 검사하는 테스트는 원문과 한국어의 동등 표현을 검사한다. 정상 사례와 부정 사례를 함께 확인하며 배포 식별 표식·출력 스키마는 원형을 유지한다.

## Consequences

한국어로 문서와 주석을 읽을 수 있고, 기존 경로와 데이터 형식을 계속 사용할 수 있다. 호환성 때문에 일부 원문 식별자와 테스트 자료가 남으며, 한국어 열람본과 원본의 목적을 문서에 명시해야 한다. 공유 파일·생성 파일의 일치, 링크와 번호, 코드 구문과 비주석 바이트, 기존 동작 테스트를 함께 검증해야 한다. 이번 작업에는 별도의 코드 리뷰나 기능 개선을 포함하지 않는다.

2026-11-07 번역 대상 전량과 예시129개를 완료했다. 최종 범위·검사·원본에서도 확인된 Windows 제약은 `docs/LOCALIZATION_KO.md`에 기록했다. 예시 원본128개와 링크0오류, manifest0, 검수 사본352개 정합성을 확인했다.

후속 사용자 요청으로 프로젝트 운영 경로 보존 결정은 [한국어 프로젝트 경로](../architecture/2026-11-07-korean-project-paths.md)에서 변경했다. 원고와 내부 스키마 보존은 유지한다.
