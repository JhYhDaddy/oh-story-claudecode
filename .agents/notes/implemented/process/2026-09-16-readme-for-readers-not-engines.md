# Agent Note: README는 답변 엔진보다 독자를 먼저 고려한다

Status: implemented

## Problem

2026년 9월의 GEO 작업으로 README.md / README_EN.md가 답변 엔진의 취향에 맞춰졌다. 맨 위에는 사이트 링크 모음이 있었고, 이어서 LLM을 위한 영어 요약, 외부 '실용 가이드' 표, '직접 답변' 표가 배치되었다. 설치는 여덟 번째 제목이었고 첫 요청 앞에도 '설치 명령이 아님', '출력은 검토가 필요함', '호스팅 작업 공간과 자동으로 동기화되지 않음' 같은 제약 설명이 붙어 있었다. 독자는 새 작품을 시작하거나 원고를 가져오거나 본문을 고치려는 웹소설 작가다. 이들은 네 화면을 넘겨야 대시보드 화면과 설치 명령을 볼 수 있었다. GitHub 유입 자료에서 Google/Bing/Baidu 방문 수는 ChatGPT 계열 엔진의 약 7배였다. README는 사람과 기존 검색을 우선해야 한다.

## Decision

두 README의 절 순서를 통일한다. 언어 전환 → 제목 → 굵은 한 문장 소개 → 프로젝트 홈페이지 링크 하나 → `demo/story-dashboard.png` → '소개 / What it is'(핵심 아이디어와 v0.7.10 버전 설명 포함) → 설치(`npx skills add` 명령을 먼저, 자연어 설치를 다음에 배치하고 문제 해결과 호스트별 설명은 `<details>`에 접어 둠) → 설치 후 첫 요청 → 작업 흐름 개요 → Skills / Agent 체계 / Hooks / 프로젝트 파일 구조 / 지식 체계 / 지원 플랫폼 → 자주 묻는 질문 → 더 읽기 → 기여 / 소통 / 감사의 글 → ZenStory AI 프로젝트 → 한 줄 마이그레이션 안내 순서다.

상단 인용문 형태의 링크 모음, 중국어 README의 영어 요약 문단, '집필 작업별 시작'과 '자주 묻는 질문에 대한 직접 답변' 표 두 개(링크는 FAQ 뒤 '더 읽기' 목록으로 축약), 첫 요청 앞의 제약 설명, FAQ의 '보장하지 않음 / 의미하지 않음 / 도구로 직접 검증한 결과가 아님 / makes no promise / do not promise / not a recorded tool run' 같은 표현을 삭제했다. 프로젝트 홈페이지는 `项目主页：https://zenstory.ai/zh/oh-story` 링크 하나만 남겼다. 실제 요구 사항인 '먼저 `/story-setup`을 실행한 다음 새 세션을 연다'는 설치 절에 한 번 기재하고, FAQ의 업그레이드 항목은 원문을 유지했다.

## Alternatives considered

- **답변 엔진용 요약을 유지하고 절 순서만 바꾼다**. 가장 큰 근거는 검색 엔진에 이미 색인된 요약을 삭제하면 단기적으로 AI 엔진의 인용에 영향을 줄 수 있다는 점이다. 채택하지 않았다. 중국어 README 안의 영어 문단은 중국어 독자에게 불필요하며, 영어 독자는 README_EN.md로 이미 지원한다. AI 엔진 유입은 기존 검색의 약 1/7에 불과했다.
- **가이드 표를 통째로 삭제한다**. 가장 큰 근거는 외부 가이드 여섯 개가 설치나 사용 절차가 아니므로 삭제하면 화면을 가장 많이 절약할 수 있다는 점이다. 채택하지 않았다. 이 가이드들은 원고를 가져와 이어 쓰기, 연속성, AI 문체 제거, 문체 등 작가의 실제 질문에 답한다. 위치만 잘못되었으므로 FAQ 뒤에 한 줄씩 목록으로 배치하면 링크를 유지하면서도 읽는 흐름을 방해하지 않는다.

## Consequences

- 이점: 첫 화면에 화면 캡처와 한 문장 소개가 보이고, 설치 명령이 여덟 번째에서 세 번째 제목으로 앞당겨졌다. FAQ에서 면책성 문구가 빠졌다. 두 README의 구조가 같아졌고 외부 링크가 한곳에 모여 유지하기 쉬워졌다.
- 비용: 답변 엔진이 바로 인용할 수 있는 요약 문단을 잃는다. 사이트 가이드는 표에서 목록으로 바뀌며 '핵심' 열은 끝에 붙는 한 문장 설명으로 축약된다.

## 검증

두 README를 수동으로 확인했다. 처음 두 화면에는 소개, 프로젝트 홈페이지, `demo/story-dashboard.png`, 소개 절, 설치 명령이 차례로 나오며 첫 요청은 설치 바로 뒤에 온다. 다음 표현을 검색한 결과는 없었다: `不会自动同步 / 不是安装命令 / 输出仍需审阅 / 不承诺 / 不代表 / 独立产品 / 截至 / 当前版本的实际机制 / do not sync / separate product / does not promise / no promise / not a recorded`. Skills 13행, FAQ 11개, Agent / Hooks / 파일 구조 / 지식 체계 표는 원문과 행별로 동일했다.
