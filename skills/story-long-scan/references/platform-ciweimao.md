# 츠웨이마오: 수집과 분석

먼저 `/browser-cdp`로 Chrome을 시작한다. 츠웨이마오는 작은 플랫폼으로 순위마다 상위 10권만 있다. 같은 방향의 작품이 10권 미만이면 집계에 표본 부족으로 표시한다.

## 기본 명령

```bash
node scripts/ciweimao-rank-scraper.js --type monthly --outdir {outdir}    # 월표 순위
node scripts/ciweimao-rank-scraper.js --type subscribe --outdir {outdir}  # 구독 순위
```

작가가 새 작품 중 떠오르는 것을 보려면 신작 순위 `--type newbook`을 추가한다.

## 선택 매개변수

`--type`: click 조회 / favor 소장 / recommend 추천 / subscribe 구독 / monthly 월표 / tsukkomi 반응 댓글 / newbook 신작 / blade 칼날 / update 갱신 / all 전체(미지정 시 기본값).

## 필드와 인기 측정 기준

순위·제목·작가(1위만 제공)·장르(1위 외 제공)·순위 지표값·작품 페이지 링크를 수집한다. 순위마다 지표 기준이 조회·소장·월표 등으로 다르다. 여러 순위 집계 시 같은 책의 가장 큰 지표값을 취하므로 인기 비교에는 쓸 수 없다. 인기는 개별 순위에서 다시 확인한다. 작가 정보가 불완전하여 여러 순위에 있는 같은 책이 합쳐지지 않을 수 있으므로 표본 권수를 확인한다.

## 수집되지 않을 때

터미널에 「未解析到榜单」(순위를 해석하지 못함)이 나오거나 파일 머리말의 「数据质量」(데이터 품질)에 문제가 표시되면 Chrome에서 `https://www.ciweimao.com/rank-index`를 열어 페이지가 정상이고 로그인·인증 페이지로 이동하지 않았는지 확인한 뒤 다시 수집한다.

## 분석 차원

| 차원 | 확인할 내용 |
|---|---|
| 월표·구독 순위 | 유료 지지 |
| 신작 순위 | 서브컬처의 새로운 소재와 설정 |
| 반응 댓글·칼날 순위 | 상호작용 강도. 논란 판단에는 내용 근거 필요 |

## 플랫폼 독자

서브컬처·라이트노벨·팬픽 독자층이다. 시작부터 재미있어야 한다. 웃음은 인물 상호작용, 익숙한 밈에 예상 밖 변화를 더하는 데서 나온다. 지나치게 진지하거나 현실적이거나 서브컬처 요소가 없는 것이 기피 요인이다.
