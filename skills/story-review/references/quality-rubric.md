# 공통 웹소설 내용 검토 Rubric

> 매 검토에서 이 표로 이야기의 품질을 평가하고 플랫폼별 표를 추가한다. 표현의 기본값은 먼저 `style-resolution.md`와 작품 문체에 따라 판단한다.

## 채점 방법

각 항목을 먼저 PASS / WARN / FAIL로 표시하고 실제 영향에 따라 통일된 Findings Schema로 전환한다.
- 주선·인물 동기·세계 규칙·독자 신뢰에 영향 → S1
- 독자 유지·리듬·장 효과·인물의 설득력에 뚜렷한 영향 → S2
- 국소 품질·형식·표현·가벼운 리듬 문제 → S3
- 문체 제안·선택적 강화 → S4

## 핵심 차원

첫 열의 항목명은 내장 기준과 일치해야 하는 검증 계약으로 원형을 유지한다. 한국어 항목명은 PASS 열 첫머리에 병기한다.

| 维度 | PASS | WARN | FAIL |
|---|---|---|---|
| 核心卖点 | 핵심 매력: 명확한 매력을 중심으로 장이 진행되며 계속 읽을 이유를 안다 | 매력이 있으나 표현이 약하거나 지선에 희석된다 | 이번 장이 어떤 매력이나 주선을 돕는지 알 수 없다 |
| 冲突推进 | 갈등 진행: 명확한 갈등·장애·선택·대가가 있다 | 갈등이 약하고 진행감이 부족하다 | 설명/잡담/요약 위주이며 실제 진전이 없다 |
| 任务卡点 | 임무의 장애: 일을 가로막는 장애가 정보·관계·대가·선택·복선을 바꾼다 | 장애는 있지만 변화가 약해 압축 가능하다 | 절차 세부에 불과해 지워도 이야기에 영향이 없다 |
| 情绪曲线 | 감정 곡선: 준비·고조·해소·반전이 있다 | 변화는 있지만 지점이 불명확하다 | 평평하거나 갑자기 방향을 바꾼다 |
| 钩子与期待 | 훅과 기대: 시작/끝 중 최소 한 곳에서 기대를 세운다 | 훅이 약해도 다음 질문은 남는다 | 궁금증·목표·미완의 기대가 없다 |
| 开头新鲜度（仅开篇/前 3 章） | 도입의 신선함(첫 도입/앞 3장만): 구체적인 인물/처지의 진입점이 있고 장르의 기본 공식이 아니다 | 훅은 있으나 도입의 모양이 같은 장르와 겹친다 | 기본 장르 틀로서 동종 작품 어디에나 통째로 옮길 수 있다(획일화) |
| 角色动机 | 인물 동기: 행동이 목표·성격·처지·관계 압박에 맞는다 | 일부 행동의 사전 준비가 부족하다 | 줄거리를 진행하려고 인물이 왜곡된다 |
| 对话质量 | 대화 품질: 속뜻·정보 통제·인물 차이가 있다 | 정보가 쌓이거나 목소리가 조금 비슷하다 | 설명서 같고 모두 같은 말투다 |
| 设定一致性 | 설정 일관성: 기존 규칙·시간선·인물 속성에 어긋나지 않는다 | 증거를 보충할 작은 모호함이 있다 | 이미 쓴 설정이나 앞선 사실과 충돌한다 |
| 文字自然度 | 문장의 자연스러움: 구체적이고 감각적이며 행동이 정보를 담는다 | 가끔 상투어나 추상적 요약이 있다 | AI 말투·진부함·요약체가 뚜렷하다 |
| 句长节奏 | 문장 길이의 리듬: 기본 서술은 쉼표로 잇는 긴 문장이다. 짧은 문장은 가끔 독립적인 강박으로 쓰고 곧 긴 문장으로 돌아온다. 작품 문체에 별도 합의가 있으면 따른다 | 일부 파편 문장/전보체 또는 기계적인 장단 교대가 있다 | 쉼표 사이가 몇 글자짜리 조각으로 이어져 개요처럼 읽히거나 검토 수정이 긴 문장을 잘게 쪼갠다 |
| 标点节奏 | 문장부호 리듬: 어조·인물 목소리·감정 기능에 맞는다 | 국소적으로 단조롭거나 약간 과하다 | 온통 마침표로 끊거나 물음표/느낌표를 무작위로 쌓고 `……`/`——`로 억지 멈춤을 만든다 |
| 具体字数表达校验 | 구체적 글자 수 표현 검증: ‘이 다섯 글자’·‘짧은 네 글자’ 등의 수가 확인되었고 서사상 필요하다 | 수는 맞지만 ‘그 몇 글자’가 더 자연스럽다 | 실제 수와 다르거나 계수 기준을 확인할 수 없다 |
| 格式可读性 | 형식 가독성: 극적 단위/장면에 맞게 문단을 나누고 대화를 독립시키며 불필요한 빈 줄이 없고 주어 리듬이 자연스럽다 | 일부 문단이 길거나 잘게 쪼개지고 주어 반복이 조금 많다 | 긴 덩어리·기계적 분단·읽기 어려운 대화/서술·과밀한 주어 |
| 剧情循环 | 줄거리 순환: 목표→장애→행동→대가/반응→새 기대의 순환이 명확하다 | 순환 중 한 단계가 없거나 피드백이 약하다 | 목표·장애·피드백이 없어 상황 변화를 알 수 없다 |
| 高潮构建 | 절정 구성: 축적·감정 격차·보상에 단계가 있다. 강한 반전은 축적→가짜 승리→붕괴→반전/보상을 쓸 수 있다 | 폭발점은 있으나 준비나 보상이 부족하다 | 준비나 보상이 없거나 감정이 허탈하게 끝난다 |
| 关系进展 | 관계 진전: 상호작용 수위가 관계 단계에 맞고 경계 넘기에 준비가 있다 | 일부 진행이 빠르지만 증거 보충이 가능하다 | 갑작스러운 친밀/신뢰/적대로 관계가 튄다 |
| 伏笔状态 | 복선 상태: 심기·상태·회수 경로를 추적할 수 있다 | 밀도가 높거나 낮아도 이해를 방해하지 않는다 | 설정과 충돌하거나 단절되어 주선 이해를 혼란시킨다 |

## 핵심 질문 세 가지

1. **독자가 왜 다음 페이지를 넘기는가?** 답하지 못하면 최소 S2다.
2. **이번 장이 무엇을 바꾸었는가?** 줄거리·관계·정보·감정 중 최소 하나가 바뀌어야 하며 아니면 최소 S2다.
3. **어떤 증거가 판단을 뒷받침하는가?** 원문 증거 없는 finding은 내보내지 않고 ‘증거 부족’으로 바꾼다.

## 게시 권고 기준

| 종합 상황 | Verdict | 보고서 `总体判断`(종합 판단) |
|---|---|---|
| S1/S2가 없고 S3를 빠르게 처리 가능 | APPROVE | 게시 가능 |
| S2가 있거나 많은 S3가 읽기를 방해 | CONCERNS | 아래 항목을 고친 뒤 게시 |
| S1이 있거나 핵심 매력/동기/규칙 붕괴 | REJECT | 국소적으로 고칠 수 있으면 ‘아래 항목을 고친 뒤 게시’, 매력·동기·규칙 전체가 무너졌으면 ‘이 장은 다시 써야 함’ |

## 출력 요구

- 모든 문제에 severity·category·location·evidence·issue·fix를 포함한다.
- S1/S2를 먼저, S3/S4를 다음에 나열한다.
- finding마다 구체적인 문제와 다음 수정 방식을 명시한다.
- `consistency` / `factual` / `causal` / `rule_boundary` finding의 fix에는 사실 통일 방향만 쓰고 문학적 창작 제안은 쓰지 않는다.
