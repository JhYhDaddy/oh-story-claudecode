# Agent Note: 공개 도움말을 현재 스킬 계약에 맞추기

Status: implemented

## Problem

스킬 13개를 파일별로 다듬어 병합했지만 일부 도움말은 여전히 호스트를 8종으로 안내하고, 금지어 하나로 AI 문체 제거 등급을 결정하고, 권별 개요를 통째로 읽고, 집필 후 검토보다 추적을 먼저 수행하도록 설명했다. 연속성 설명도 상태 카드의 읽기 상한을 전체 상태가 늘어나지 않는다는 뜻으로 잘못 설명했고, 영어 디렉터리 예시는 실제 경로가 중국어라는 점을 밝히지 않았다.

## Decision

현재 도움말, 개발 문서, 데모 안내를 문서별로 다섯 단계에 따라 다듬고 현행 스킬·템플릿·스크립트를 사실의 근거로 삼는다. 호스트 수, AI 문체 제거 등급, 필요한 부분만 읽는 방식, 검사 후 제출하는 순서를 바로잡는다. 편집 작업 자체에 대한 설명과 근거 없는 일반화를 삭제한다. 이미 병합된 스킬 문서 367개의 다섯 단계 검토 근거를 재사용하며 AI 문체 제거의 실패 예시·대조 쌍·실제 실행 기록은 원문 그대로 보호하고 추가·변경된 부분만 재검토한다.

## Alternatives considered

- 스킬 자체만 처리하면 변경을 줄일 수 있다. 그러나 도움말이 계속 예전 규칙을 사용자에게 전달하므로 현재 안내도 보완한다.
- 전체를 다시 쓰면 어조를 통일할 수 있다. 그러나 실제 예시를 훼손하고 완료한 작업을 반복하므로 정확한 본문과 표본은 유지한다.

## Consequences

현재 안내와 과거 사례를 명확히 구분해야 한다. 실패 예시, 대조 쌍, 실행 출력과 실제 사례를 보존한다. 일반 단편 디렉터리 트리 두 곳은 오래된 Phase 7 주석만 바로잡고 새 실행 결과를 꾸며내지 않는다.

## 검증

현재 안내·개발·도움말 문서 25개의 다섯 단계 확인을 완료했다. 그중 두 언어 README는 이번 세션에서 이미 병합한 다듬기와 독립 검토를 재사용하고 원문을 유지했다. 코드 블록 53개 중 51개는 글자 하나 바꾸지 않았고, 일반 디렉터리 트리 두 곳의 Phase 7 주석만 수정했다. 실제 실행 출력과 AI 문체 제거 대조 쌍은 원문을 유지했다. 현재 안내는 현행 스킬과 스크립트에 맞췄다. 스킬 13개의 기존 문서 367개에 대한 다섯 단계 근거도 계속 보존하며, 이번 장편 누락 보완에는 별도의 범위 기록이 있다. 같은 기능의 중국어·영어 도움말을 함께 관리해야 한다는 비용이 남는다.
