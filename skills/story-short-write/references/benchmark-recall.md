# 단편 비교 작품 찾기와 회수

이 작품에 `비교작품/`가 있거나 프로젝트 루트에 `작품분석실/`가 있거나 작가가 참고 소설을 언급하면 다음 절차를 따른다. 장르 패키지는 작가가 선택한 장르로 결정한다. 비교 작품은 기법의 증거만 제공하며 장르 패키지나 현재 작품의 말투를 바꾸지 않는다.

> **디렉터리 관계**: 프로젝트 루트 `작품분석실/{书名}/`에는 분석 산출물을, `{短篇标题}/비교작품/{书名}/`에는 이 작품에서 선택한 사본을 저장한다. 읽을 때 `비교작품/`를 먼저 찾고 없으면 `작품분석실/`를 찾는다.

1. **후보 나열과 현재 작품 제외**: `ls 작품분석실/` 및 현재 작품의 `비교작품/`로 목록을 만든다. 현재 프로젝트 디렉터리명과 `설정.md`의 `基本信息`(기본 정보)로 작품 제목을 확인한다. 같은 이름이거나 출처가 현재 `본문.md`를 가리키는 `작품분석실/{当前书}/`, 과거에 잘못 만든 `비교작품/{当前书}/`는 제외한다. story-import가 생성한 현재 작품 분석은 이어쓰기 기준으로만 쓰고 비교 작품에 넣지 않는다. 제외 후 남는 책이 없으면 비교 작품 없이 장르 패키지로 쓴다.
2. **관련성 판단**: 책마다 `_meta.json`의 `genre_detected`를 읽고 아래 표로 패키지를 정한다. 현재 작품의 패키지와 같으면 ‘같은 장르’, 다르면 ‘약한 관련’으로 기록한다. 메타데이터가 없으면 분석 보고서로 판단하고 판단 불가 시 ‘미정’으로 표시한다. 표 첫 열은 실행 열거값·동의어이므로 중국어를 유지한다.

   | `genre_detected` | 대응 장르 패키지 |
   |---|---|
   | 追妻（现代 / 古代 / 民国）、小三 / 死人文学 | `追妻火葬场.md` — 후회·재결합 |
   | 世情 / 打脸爽文 / 家庭伦理 | `世情打脸.md` — 세태·응징 |
   | 重生复仇 | `复仇打脸.md` — 회귀 복수 |
   | 豪门 / 总裁（豪门联姻虐恋） | `总裁豪门.md` — 재벌·명문가 |
   | 宫斗宅斗 / 宫斗 / 宅斗 / 古言重生 | `宅斗宫斗.md` — 가문·궁중 암투 |
   | 民俗 / 怪谈 / 灵异 | `民俗怪谈.md` — 민속 괴담 |
   | 悬疑 / 推理 / 惊悚 | `悬疑.md` — 미스터리 |
   | 甜宠 / 先虐后甜 / 先婚后爱 | `甜宠.md` — 달콤한 로맨스 |
   | 双男主 | `双男主.md` — 두 남성 주인공 |
   | 沙雕 / 脑洞 / 弹幕 / 系统 | `沙雕脑洞.md` — 엉뚱한 코미디·기발한 발상 |
   | 仙侠 / 通用 / 其他 | 대응 패키지 없음. 현재 작품의 비주류 장르와 같으면 같은 장르, 아니면 약한 관련 |

3. **작가의 선택**: 후보와 ‘사용하지 않고 장르 패키지로 집필’을 제안한다. 선택 도구가 있으면 사용한다. 선택한 책은 `설정.md`의 `对标摘要`(비교 요약)에 주 비교 작품으로 기록하고 `작품분석실/{书}/`를 `{短篇标题}/비교작품/{书}/`로 복사한다. 작가가 지정한 참고 소설도 같은 방식으로 등록한다.
4. **산출물 읽기**: `작품분석보고서.md`, `사건노드.md`, `집필기법.md`, `_meta.json`을 읽는다. 용도는 아래 ‘분석 산출물 활용’을 따른다. 원문만 있고 분석 보고서가 없으면 `/story-short-analyze`를 먼저 실행하도록 안내한다. 그래도 계속하길 원하면 원문은 약한 참고로만 쓴다.
5. **요약 작성**: 구조 구간·감정 곡선·반전 위치·사전 배치·문장 리듬·참고 기법을 현재 장르 패키지의 기법에 대응시킨다. 원작 증거로 이 작품에서의 활용법을 판단해 `설정.md`의 `对标摘要`에 쓴다. 본문에서는 장면마다 1-2개를 회수한다.
6. **여러 비교 작품**: 2권 이상이면 `references/cross-book-recall.md`에 따라 보조 비교 작품에서 배울 항목을 `对标摘要`에 기록한다.

#### 분석 산출물 활용

`작품분석실/{书名}/`에는 `원문/`, `작품분석보고서.md`, `사건노드.md`, `집필기법.md`가 있고 `_meta.json`이 있을 수도 있다.

- `_meta.json`은 선택 사항이므로 없어도 집필을 막지 않는다. `structure_counts.reversal_type`은 반전 유형(시점/신분/동기/시간선/정보/인식/반전 없음)이며 이를 기준으로 `short-reversal.md`에서 구조를 고른다. 나머지 집계인 구조 구간 `beats`, 훅 `hooks`, 반전 단서 `setup_clues`, 대비 인물 `character_archetypes`, 재사용 기법 `reusable_structures`는 비교용일 뿐 목표 지표가 아니다.
- `사건노드.md`에서는 노드별 `位置`(위치), `功能`(기능), `事件`(사건)을 보고 새 이야기의 리듬을 설계한다.
- `집필기법.md`와 `원문/`에서는 대화 말투·리듬·시각적 표현 같은 쓰는 법만 배우고 구체적인 사건은 베끼지 않는다.
