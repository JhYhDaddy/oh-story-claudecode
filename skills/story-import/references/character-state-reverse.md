# 핵심 인물의 현재 스냅샷 역추론(장편 가져오기)

> 마지막 완결 장까지의 핵심 인물 상태를 초기화 트랜잭션의 `character_snapshots`에 쓰면 `tracking_commit.py init`이 `추적/인물상태/{角色名}.md`를 생성합니다.

## 1. 입력 출처

저장된 분석 산출물에서 역추론하며 `원문/`을 다시 읽지 않습니다.

| 입력 | 용도 |
|---|---|
| `작품분석실/{书名}/인물/{角色名}.md` | 신분·능력·목표·성장 과정·등장 기록 |
| `작품분석실/{书名}/인물/인물관계.md` | 마지막 완결 장까지의 핵심 관계 |
| `작품분석실/{书名}/장별분석/제N장_요약.md` | `涉及`에서 관련 장을 찾고 `状态变化`·`信息变化`·`局面结果`·`章尾钩子`에서 마지막 위치·최신 상태·아는 정보·미해결 사항 추출. 옛 요약에 필드가 없으면 핵심 사건·사건 항목으로 대체 |
| `작품분석실/{书名}/플롯/*.md` | 진영·신분 전환, 단계 목표, 장기 갈등 |
| 초기화 트랜잭션의 복선·시간선 후보 | 미해결 사항과 인물이 알 수 있는 범위 대조 |

## 2. 추적 대상

주인공·악역·핵심 조연만 독립 스냅샷을 만듭니다. 일회성 행인·한 번만 기능하는 인물은 파일을 만들지 않습니다. 경계가 불분명하면 우선 만들지 않고 실제로 재사용될 때 장별 트랜잭션에서 생성합니다.

## 3. 역추론 방법

각 핵심 인물에 대해 마지막으로 완결된 가져오기 장 N을 기준으로 정합니다.

1. `identity`: N장까지 실제 성립한 신분·직업. 미래 승진 계획은 제외.
2. `location`: 마지막 도착 지점 또는 다음 장 시작 전 확정 가능한 위치.
3. `goal`: 현재 추구하는 구체적 목표.
4. `state`: 이어쓰기에 영향을 줄 신체·감정·명성·입장. 필요한 현재 정보만.
5. `abilities_resources`: 실제 보유한 능력·물건·권한·작품·인맥.
6. `relationships`: 이후 재사용할 인물과의 현재 관계.
7. `knowledge`: 인물 자신이 이미 알고 행동에 영향을 주는 정보. 작가만 아는 진실을 섞지 않음.
8. `open_threads`: 이미 쓴 본문에 근거가 있는 미해결 사항. 순수 미래 설계는 개요에 둠.

같은 필드가 여러 번 바뀌면 N장 시점의 값만 사용합니다. 네 목록은 항목 수 상한이 없으며 용량은 아래 바이트 제한을 따릅니다. 옛 장을 가져올 때 장별 기록을 꾸며 넣지 않습니다. 이어쓰기 이후 변화는 `장별기록/제NNN장.md`가 담당합니다.

## 4. 초기화 JSON 형식

demo 《让你管账号，你高燃混剪炸全网》 제10장의 예입니다. 인물 키는 원작의 식별 이름을 유지합니다.

```json
{
  "江晨": {
    "identity": "로켓군 문공단 홍보병; 군 홍보 인기 콘텐츠 제작자",
    "location": "로켓군 문공단 고위층 영상 시사회",
    "goal": "5일 안에 팔로워 100만 명 과제를 완수하고 실력 있는 군 홍보 콘텐츠를 계속 제작",
    "state": "전문 팀의 재촬영본이 오히려 휴대전화 원본의 가치를 입증해 군내 인정이 더욱 높아짐",
    "abilities_resources": [
      "전생의 MCN 인기 콘텐츠 운영 경험",
      "《中国军魂》 반주",
      "거장급 연출 능력"
    ],
    "relationships": [
      "중자자가 군보 자원을 계속 제공",
      "저우보선과 장야오쭈가 창작 능력을 명확히 인정"
    ],
    "knowledge": [
      "《军报》 인터뷰 원고가 심의를 통과함",
      "고위층이 《诸君，且听龙吟》 휴대전화 원본을 계속 사용하기로 결정"
    ],
    "open_threads": [
      "5일 내 팔로워 100만 명 과제가 아직 정산되지 않음",
      "중자자가 말한 ‘절반만 맞혔다’의 의미가 아직 설명되지 않음"
    ]
  }
}
```

도구가 만드는 파일에는 기준 장(截至章节), 신분(身份), 위치(位置), 현재 목표(当前目标), 심신 상태(身心状态), 능력·자원(能力与资源), 핵심 관계(关键关系), 아는 정보(已知信息), 미해결 사항(未结事项)이 고정 포함됩니다. 모델이 별도 Markdown 템플릿을 만들면 안 됩니다.

## 5. 미완 원고·중복 초기화

- 마지막 장이 미완이면 모든 스냅샷은 그 직전 마지막 완결 장 기준입니다. 미완 장의 행동·획득물·관계 변화를 미리 적용하지 않습니다.
- `_tracking-state.json`이 이미 있으면 다시 `init`할 수 없습니다. 스냅샷은 초기화 때 한 번만 쓰고 이력을 덧붙이지 않습니다.

## 6. 품질 검사

- [ ] 파일 하나당 핵심 인물 하나이며 일회성 기능 인물 파일이 쌓이지 않음
- [ ] 모든 필드가 마지막 완결 장 기준 현재 값
- [ ] 인물이 아는 정보에 작가의 진실을 섞지 않음
- [ ] 미해결 사항에 본문 근거가 있으며 미래 설계는 개요에 있음
- [ ] 인물별 스냅샷 목표 ≤4096바이트. 필요하면 늘릴 수 있으나 절대 상한 8192바이트를 넘지 않음
- [ ] `tracking_commit.py check` 통과
