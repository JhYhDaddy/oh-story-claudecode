# 판체 계정 자격과 3단계 자료 기준

보고서 버전은 **V1.2**, 갱신·정리일은 **2026-10-28**입니다. A는 사용자가 확인하거나 제공한 결론·진입점이며 원본 조작 증거가 없을 수 있습니다. B는 공식 공지와 공개 전달 자료이며 상세 원문을 모두 독립적으로 읽은 것은 아닙니다. C는 타사 구현·과거 안내, D는 미상을 뜻합니다. A는 독립 로그인 검증과 같지 않고 B/C를 관리 화면의 강제 검사로 격상하지 않습니다. 짧은 이야기 테스트 계정은 Lv.2이고 작품은 초안입니다. 장편 계정 조건, 잔여 한도, 앱 경로는 아직 모릅니다.

## 웹 진입점과 증거 부족

사용자가 제공한 관리 진입점: [장편 작품 관리](https://fanqienovel.com/main/writer/book-manage), [짧은 이야기 작품 관리](https://fanqienovel.com/main/writer/short-manage). 출처만 확인했으며 로그인 상태, 내부 양식, 제출 동작의 검증을 주장하지 않습니다. 2026-10-25 태그 캡처에는 웹 작품 생성 URL이 보이지만 아래 개별 실측의 조작 기록을 대신하지는 않습니다.

## 계정과 계약 방식

- A: 계정은 실명 인증이 필요합니다. 차단 단계와 얼굴 인증 동시 요구 여부는 모릅니다. 자료를 정리하는 데는 로그인이 필요하지 않습니다.
- B: 2026-10-12부터 신규 장편은 Lv.0/1에서 완결 계약만 가능하고 Lv.2 이상은 연재·완결 계약을 선택할 수 있습니다. 기존 작품은 계속 연재할 수 있습니다. 현재 계정 등급은 작가가 확인해야 하며 소재, 비축 원고, 목표 갱신 주기로 추정하지 않습니다.
- B: 등급 3.0은 10월 12일 시행되고 10월 12일~11월 11일이 전환기입니다. 이를 근거로 현재 등급, 승급 기준, 모든 혜택을 추측하지 않습니다.
- 계약 방식, 연재 상태, 갱신 일정을 따로 기록합니다. 최소 작품 생성 필드는 과거 자료의 모호한 “갱신 방식” 대신 “계약 방식”이라고 명확히 합니다.

## 장편의 3단계

### 먼저 장을 쓰고 나중에 정보를 보완하는 진입점의 추가 관찰

2026-10-28 사용자가 화면 2장을 추가했습니다. 개인정보가 있어 원본 이미지, 계정명, 본문을 저장하거나 전사하지 않습니다. 저장소에는 아래 비식별 관찰만 남기므로 원본을 저장소 안에서 다시 확인할 수 없습니다.

- 사용자는 이 진입점에서 먼저 장을 쓰고 작품 정보를 나중에 보완할 수 있다고 확인했습니다. 기본 제목은 플랫폼이 현재 작가 ID를 넣은 “작가ID의 신작” 형식입니다. 실제 ID는 기록하지 않으며 기본 제목을 작가가 확인한 정식 제목으로 취급하지 않습니다.
- 이 사례에서는 기본 연재이며 완결 선택지가 없다고 사용자가 설명했습니다. 작품 정보 수정 화면에는 “계약 방식: 연재 방식”이 보이고 전환 컨트롤은 없었습니다. 이는 현재 작품의 관찰이며 독립 생성 양식에도 완결 선택지가 없음을 증명하지 않습니다. 등급, 기존 작품 여부, 생성 시점은 모르며 공개 등급 규칙과의 관계도 미확인입니다. 낮은 등급도 신규 연재를 보편적으로 만들 수 있다고 추정하지 않습니다.
- 수정 화면에서 제목과 계약 방식에 별표가 있고 대상 독자, 독서·콘텐츠 태그, 주인공은 미입력 상태였습니다. 소개에는 플랫폼 기본 문구가 있어 빈 값을 허용한다는 증거가 되지 않습니다. 화면의 계수 상한은 제목 15, 주인공 5, 소개 500이지만 실제 경계를 시험하지 않았습니다. 중국어 문장 부호 요구는 여전히 작가의 제약입니다.
- 출판 설정은 표지·분류 등을 작품 설정에서 보완할 수 있다고 안내합니다. 이 화면만으로 “즉시 수정”의 빈 값 저장이나 “출판 확인”의 최종 통과를 증명할 수 없습니다.
- 출판 설정에 AI 사용 여부의 예·아니요와 예약 스위치가 보입니다. 사용자는 AI 보조를 선택했다고 보고했지만 제공된 화면에는 “아니요”가 선택돼 있었습니다. 둘을 따로 기록하며 “예” 선택 후 제출 성공으로 주장하지 않습니다. 실제 작품의 AI 신고 내용을 정리할 때는 작가가 확인해야 하며 대신 기본값을 선택하지 않습니다.
- 예약을 끄면 장 심사 후 공개된다는 안내가 보입니다. 이는 화면 문구일 뿐 해당 장의 제출·심사 통과·공개를 뜻하지 않습니다. 화면의 본문 계수도 장당 최소 분량의 경계 증거로 삼지 않습니다.

| 단계 | 알려진 근거 | 처리 |
| --- | --- | --- |
| 최소 작품 생성 | A: 독립 생성 양식은 제목·계약 방식 필수라고 보고됨. 먼저 장 쓰기의 자동 제목·기본 연재 진입점도 있음 | 진입점을 먼저 구분하고 독립 양식의 수동 입력 요구를 편집기 진입점에 적용하지 않음. 계정 자격·한도는 별도 기록. 생성·제출 결과는 추가 증거 필요 |
