# Stage 3: 줄거리·이중 시간선·3축 리듬

이 파일과 [synthesis-inputs.md](synthesis-inputs.md)의 추출·근거 등급·단계 표시·사실 보존 지침을 읽습니다.

## 핵심 규칙

줄거리 지점은 ‘초기 목표·장애물 → 상황을 바꾼 선택/행동/외부 사건 → 변화·득실 → 후속 영향’으로 병합합니다. 사건 발생과 정보 공개를 분리하며 같은 사실의 이상·단서·설명·확인은 하나의 공개 경로입니다. 전체에서 주선·핵심 전환 약 8–15개만 유지합니다.

3축 리듬은 사건 진전 1–5·상태 변화, 독자 감정 유형/강도 1–5·촉발, 분량 전개도 1–3·확대/압축/생략/반복 기능을 따로 설명합니다. 감정 메커니즘은 전체 카드로 씁니다. 가장 강한 최소 3개, 실제 3개 미만이면 실제 수만큼, 재현 가치가 있으면 상한 없이 펼칩니다. 나머지는 색인에 둡니다.

출력 순서: 이야기 틀 → 줄거리 단위 → 이야기선 → `플롯/README.md` → `플롯/리듬.md` → `플롯/감정모듈.md` → 흩어진 사건·자체 점검. 권위 파일 둘 다 저장한 뒤 synthesis-inputs의 표시 절차로 `stage3`를 표시합니다.

## 1. 이야기 틀 식별

digest로 첫 3장·마지막 3장의 개요·핵심 사건을 뽑고 `개요요약.md` 초안과 결합해 작품 동력을 판단합니다. `플롯/이야기선.md` 상단에 씁니다. 틀이 단위 분할을 결정합니다.

| 틀 | 특징 | 분할 기준 |
|---|---|---|
| 성장형 | 명확한 등급 체계·경지별 구간 | 등급 단계 |
| 복수선 | 명확한 핵심 갈등·목표 동력 | 복수 대상·단계 |
| 일상·단위형 | 권마다 독립 이야기·약한 연속성 | 권·단위 |
| 다중선 교차 | 다중 시점·시간선 | 이야기선, 교차점 별도 표시 |
| 내적 성장 | 주인공의 내면 변화가 주선 | 성장 단계 |
| 감정 중심 | 관계 진전이 주선 | 만남·탐색·확인·위기·화해 |

권·부·편이 있으면 작가의 구분을 우선합니다. 아래 중국어 제목·필드·열거값은 후속 조회·검증 표식입니다.

```markdown
## 故事框架

| 项目 | 内容 |
|------|------|
| 框架类型 | {升级流/复仇线/日常单元/多线交织/蜕变成长/感情流/混合} |
| 核心驱动 | {전 작품의 핵심 서사 동력 한 문장} |
| 主轴矛盾 | {전 작품을 관통하는 근본 갈등} |
| 升级机制 | {힘·지위·관계의 진전 방식, 없으면 “—”} |
| 叙事节奏模式 | {준비→갈등→통쾌함→새 궁금증의 전형적 주기} |
| 判断依据 | {판단을 뒷받침하는 장·사건} |
```

단위 수는 뚜렷한 세분화 문제를 찾는 참고이며 채울 목표가 아닙니다. <30장 약 3–6개, 30–100장 약 5–15개, 100–300장 약 10–25개, >300장 약 15–40개. 크게 벗어나면 크기를 재검토합니다.

## 2. 줄거리 단위

**첫째: 독립 줄거리 식별.** 묶음 지점·장별 요약을 합치고 경계·근거가 불확실하면 관련 요약을 읽습니다. 한 줄거리는 네 가지를 모두 가져야 합니다. 측정 가능한 핵심 목표(거시 주제 아님), 구체적 주 갈등(더 큰 갈등의 하위 단계 아님), 비교적 독립적인 인물군, 고유한 긴장–완화 리듬입니다. 목표는 획득(대회 우승·전승), 해결(가문 위기·추격), 창조(문파·유파 설립), 탐색(부모 실종·음모)일 수 있습니다.

| 크기 | 예 | 처리 |
|---|---|---|
| 너무 작음 | 신기 획득(1–2장) | 사건으로 보고 소속 줄거리에 통합 |
| 너무 큼 | 주인공의 성장 여정(1–100장) | 주제이므로 분할 |
| 적절 | 가문의 각성과 전승 인식(1–6장) | 독립 목표·갈등·인물군·완전한 곡선 |

| 혼란 | 징후 | 수정 |
|---|---|---|
| 포함 | A 범위가 B를 완전히 포함 | 적절한 B 유지, 너무 큰 A 분할 |
| 큰 중첩 | 두 줄거리가 절반 넘게 장 공유 | 줄거리와 단계 혼동 여부 확인 |
| 시작·끝뿐 | A가 B의 처음·끝 몇 장뿐 | B의 한 단계로 통합 |
| 독립 목표 없음 | A 목표가 B의 하위 목표 | B 단계로 낮춤 |

**둘째: 사건 배정.** 줄거리마다 `digest --part chapters --points brief`로 장 구간별 사건을 보고 목표를 직접 돕거나 막거나 진전시키는 것을 고릅니다. 촉발 시작점·완료/실패 끝점을 먼저 찾고 중간 핵심 전환을 보완해 시간순으로 배치합니다. 이를 바탕으로 개요·구조 분포를 채웁니다. 귀속은 주제·인과·목표로 판단하며 같은 인물 등장만으로 같은 목표라고 보지 않습니다.

주선(전체 추진), 지선(감정·성장·전투 등), 보충 줄거리(전환·일상)의 세 층위로 나머지 사건을 포괄합니다. `플롯/{标题}.md` 필드는 아래 표가 기준입니다.

| 项目 | 内容 |
|------|------|
| 标题 | 15자 이내 |
| 类型 | {主线/爱情/成长/复仇/寻宝/悬疑/战斗/权谋/修炼/危机/谜团/日常/其他}. 悬疑는 적극 추리·조사, 谜团은 세계관·출생 등 미해결 수수께끼 |
| 概要 | {150–300자. 시간순 기승전결·인과를 자연스럽게 연결하고 같은 접속어 반복을 피함. 핵심 인물·역할·장소·소품(있으면)·주인공/세계 영향 포함} |
| 起始目标 | {누가 처음 무엇을 원했는지. 이전에 세운 목표면 첫 수립 위치 참조} |
| 主要阻碍 | {인물·규칙·자원·정보·환경의 구체적 장애물} |
| 关键变化来源 | {누구의 선택·행동 또는 어떤 외부 사건이 상황을 바꿨는지. 주인공 능동 행동으로 기본 가정하지 않음} |
| 局面变化 | {목표·위험·관계·자원·지식·행동 방향의 이전→이후} |
| 得失与承担者 | {누가 무엇을 얻고 잃거나 어떤 대가를 부담하는지} |
| 后续影响 | {후속 행동을 촉진·제한·강요하는 방식. 미완이면 open} |
| 关键信息功能 | {독자가 얻거나 기다리거나 오판하거나 확인하는 정보} |
| 读者需求 | {안정감·우월감·기대감·감정 보상·인식 반전·동행감 등} |
| 情绪模块ID | {`플롯/감정모듈.md`의 EM-001 등 참조, 전체 카드 중복 금지} |
| 套路框架位置 | {파혼 후 역전·뒤늦은 후회·성장 시련·정체 공개 충격·약자의 도전·기타. 작품 틀에서 작동하는 방식} |
| 桥段标签 | 아래 어휘표에서 맞는 항목을 쉼표로 구분. 표 밖 실제 장면도 허용. 없으면 빈칸, 억지로 채우지 않음 |
| 主题 | {최대 3개} |
| 章节范围 | 第{X}-{Y}章（共{N}章，约{M}万字） |

结构分布: 铺垫期 | 发展期 | 高潮期 | 收尾期(각각 장 범위).

情节点索引: | 序号 | 章节 | 描述 | 归入把握（明确 / 待复核） |.

### 묶음 간 병합

읽기 경계가 줄거리 지점을 자를 수 있습니다. 병렬의 같은 라운드는 서로의 새 지점·별명을 볼 수 없어 경계 ID 중복이 흔합니다. 이웃 묶음 경계 근처의 쌍만 보고 네 조건을 모두 만족해야 합칩니다. 같은 핵심 사건·목표, 주요 인물 동일, B가 A의 자연스러운 연속, 인과만 연결된 별개 사건이 아님.

- 합칠 것: ‘현장 비서 선거 준비’+‘투표’, ‘수련 돌파 전반’+‘후반’.
- 합치지 않을 것: ‘사무실에서 입지 확보’+‘현장 비서 선거’(다른 목표), ‘연기기 수련’+‘축기기 수련’(다른 단계), ‘동역 수련’+‘중주 경험’(다른 지도).
- 불확실하면 합치지 않습니다.

## 5. 리듬.md

입력은 묶음 핵심 사건·공개 후보, 3축 고저, 장별 압축 사실, 단위·이야기선입니다. 주선·관계·핵심 위험·독자 판단을 바꾸는 사건만 고릅니다. 객관적 사건은 한 번 등록하고 이상·단서·설명·확인은 같은 공개 경로에 씁니다. 모든 `EV/RV/AX/RH/TR`는 장·사건·위치로 추적 가능해야 합니다. 과정이 안 나오면 ‘텍스트에 제시되지 않음’으로 쓰며 작가의 의도적 생략으로 추론하지 않습니다.

**통쾌함 순환 분석**: 준비는 억압·곤경·정보 격차로 결핍을 만들고 실현은 실력 공개·역전·압도·목표 달성·감정 충족입니다. 반응은 주변인의 반응입니다. 남성향은 의심/경시 → 충격 → 강자의 재평가 → 확산, 감정물은 오해/냉대 → 흔들림 → 지지/표현 → 관계 공개가 흔합니다. 연결 층위는 이전 순환 끝에 새 후킹을 심습니다. 반응 비율=반응 총 글자 수÷실력 시연 글자 수. 1.5는 통쾌함을 충분히 이어받는지 검토하는 경험적 참고이며 장르와 함께 판단합니다. 연결 방식은 작은 적 뒤 큰 적·승리 뒤 위험 발견·신분 노출·이해관계 확대·관계 급변 등이 흔합니다.

```markdown
# 节奏索引：{书名}

> 권위 범위: 정보 공개·독자/인물 지식 경계·사건/감정/분량의 3축 리듬·통쾌함 순환·감정 자극점. `작품분석보고서.md`는 이 파일의 요약만 참조합니다.

## 全书情绪节奏总览

- 情绪折线：{억압/기대 → 긴장/압력 → 통쾌함/반전 → 여파/새 위기. 핵심 장 구간 표시}
- 爽点频率：{N장마다 작은 통쾌함, M장마다 중간 절정, 큰 절정 위치}
```

## 7. 흩어진 사건·마무리 점검

단위 완성 후 `digest --part chapters --points brief`로 어디에도 들어가지 않은 사건을 모읍니다.

1. 고립 사건이 전체 <5%면 바로 흩어진 사건에 넣고 「少量散落，无需再归类」로 표시합니다.
2. 인물·주제·장소·인과로 판단합니다. 목표·인과 귀속이 명확하면 기존 단위에 넣고 `[孤立情节归入]`, 인물·주제만 관련되고 목표가 불확실하면 `[低置信归入]`. 더 약하면 억지 귀속하지 않습니다.
3. 귀속하지 않은 것을 주제로 묶어 5개 이상이면 후보 단위로 만들고 `[聚类生成]`. 5개 미만은 독립 항목을 만들지 않습니다.
4. 그래도 남으면 `플롯/분산사건.md`에 장별로 쓰고 이유를 적습니다. 어떤 사건도 버리지 않습니다. 분석 보고에 수·비율을 집계합니다.

전체 저장 후 자체 점검 한 번. 결과는 저장하지 않으며 `플롯/이야기선.md`에 점검 표를 쓰지 않습니다.

| 검사 | 기준 | 미달 시 |
|---|---|---|
| 포괄률 | 단위에 배정된 사건÷전체, 85%–95% | <85%면 2번에서 누락 검토, 근거 부족이면 흩어진 사건 유지. >95%면 과도한 병합 확인 |
| 중첩 | 여러 단위가 공유하는 사건 ≤전체 1/3 | 경계가 모호하므로 병합 검토 |
| 크기·독립성 | 위 혼란 네 유형 없고 독립 기준 네 가지 충족 | 분할·병합·단계로 낮춤 |
| 핵심 정보 | 장마다 정보 행 또는 「无独立信息变化」 명시 | 원래 입력 모드로 Stage 2 보완. 옛 결과 장의 원문 재조회 금지 |
| 공개 참조 | `RV-*`가 같은 행 `EV-*`의 경로에 속하며 반복 공개로 사건을 중복 생성하지 않음 | 묶음 관찰에서 병합 |
| 3축 설명 | `AX-*` 세 축 모두 이유·근거 | 뚜렷한 변화 없음/텍스트 미제시와 근거 보완. 점수로 때우지 않음 |

30장 미만·단일 주선의 연속 발췌를 시간순 분할하면 포괄률이 자연스럽게 100%에 가깝고 흩어진 사건은 거의 0일 수 있습니다. 정상 결과입니다. 서로 다른 줄거리를 강제로 합쳤는지에 집중하며 비율을 낮추려고 인위 분할하지 않습니다.
