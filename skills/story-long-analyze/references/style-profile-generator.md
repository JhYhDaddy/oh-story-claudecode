# Stage 6: 문체 프로필 생성·단독 재구축

전체 파이프라인 마무리 또는 누락된 `문체.md`만 보충할 때 읽습니다. 문체 단독 보충은 Stage 1–5를 실행하지 않습니다. `작품분석실/{书名}/문체.md`는 이 스킬만 씁니다. 다른 프로젝트의 비교 작품으로 선택되면 story-import·story-long-write가 첫 참조 때 `{项目}/비교작품/{书名}/문체.md`로 복사합니다.

## 원칙

1. 실제 작법을 기술하며 작가 수준을 평가하지 않습니다.
2. 감정·리듬 의도는 `플롯/감정모듈.md`·`플롯/리듬.md`가 기준이고 문체는 표현 층위만 담당합니다.
3. 완전한 기존 `문체.md`는 유지하며 사용자가 보강을 명시 요청할 때만 갱신합니다.
4. Stage 6는 작품 전체를 다시 훑지 않습니다. 색인 행 번호로 원문 4–6구간만 지정 재조회합니다.
5. 요약 표현을 작가 원문으로 위장하지 않습니다. 원문·유효 표본이 없으면 오류로 알립니다.

## 출처 우선순위

1. 기존 `문체.md`.
2. 프로젝트의 비어 있지 않고 연속 원문이 담긴 `_style-sample.txt`.
3. `장별분석/제1장_심층분석.md`–`제3장_심층분석.md`의 위치 표시된 짧은 인용·작법 근거.
4. `_analysis_cache/批次-*.md`·`장별분석/*_요약.md`·`작품분석보고서.md`의 구조 관찰.
5. 기준점이 여전히 부족하면 `chapter_index.csv`에서 주요 기조를 아우르는 4–6장을 고르고 `start_line/end_line`으로 원문 구간만 읽습니다.

옛 프로젝트에 색인이 없으면 그것만 만들 수 있습니다. `_progress.md`를 쓰거나 다른 단계를 시작하지 않습니다.

## 문체만 재구축

story-long-write·사용자가 누락을 발견하면:

1. 검사기로 다른 분석 결과가 사용 가능하고 `stage_repairs`에 `stage6_style`·`stage6` 중 하나가 있는지 확인합니다.
2. `_style-sample.txt`가 유효하면 바로 사용합니다.
3. 부족하면 `chapter_index.csv`·원문 존재를 확인합니다. 색인이 없을 때는 다음만 실행합니다.

   ```text
   "{PYTHON}" "{story-long-analyze skill 根}/scripts/build_chapter_index.py" --source "{拆文目录}/원문/원문.txt" --output "{拆文目录}/chapter_index.csv" --locator-path "원문/원문.txt"
   ```

4. 기존 자료로 확인할 수 있는 서로 다른 기조의 4–6장을 고릅니다. 장마다 행 번호로 300–500자의 연속 원문 하나를 뽑아 `_style-sample.txt`를 작성·갱신합니다.
5. 아래 템플릿으로 `문체.md`를 생성합니다.
6. 저장 후 실행합니다.

   ```text
   "{PYTHON}" "{story-long-analyze skill 根}/scripts/manage_analysis_run.py" mark-stage --root "{拆文目录}" --stage stage6 --output "문체.md"
   ```

색인·원문·유효 표본이 모두 없으면 중지하고 ‘검증 가능한 문체 기준점을 얻을 수 없음’을 반환합니다. 기준점이 모두 빈 문체를 사용 가능으로 만들면 안 됩니다.

## 보고 반영

전체 파이프라인·재개 중에는 문체 저장 후 `stage6` 표시 전에 `_progress.md` 관리 단계 표를 확인합니다. `stage5`가 `completed`, 산출물이 `작품분석보고서.md`이고 보고서 「文风一句话」가 아직 미완이면 `문체.md`로 채웁니다. 기존 요약은 유지하며 옛 프로젝트 문체만 보충할 때는 기존 보고서를 바꾸지 않습니다.

## 길이·신뢰 근거

총 상한 4000자. 설명(전체 어감·대사 기법·감정 교대·참고 기법·단계별 모방 제안)은 ≤1800자, 원문 기준점은 4–6개×300–500자이며 합계 ≤2100자, 생성 기록·모방 비권장 항목 합계는 ≤100자입니다.

결론마다 「依据」 한 줄을 쓰고 아래 세 표식 중 하나를 사용합니다.

| 근거 표식 | 사용 조건 |
|---|---|
| 已有资料 | 기존 분석 결과에서 확인. 예: 장별 요약 기조 행에서 순서 집계 |
| 原文锚点 | 4–6개 원문 기준점으로 정리하며 기조 세 종류 이상 포함 |
| 样本不足 | 기준점 <4개·기조 한두 종류뿐·요약 표현에만 의존 |

문장 길이·구두점·문단 리듬은 기준점에서 정리하므로 근거 표시는 최대 「原文锚点」입니다.

## 템플릿

중국어 절·필드명은 문체 조회 계약 표식입니다. 각 항목 설명은 한국어로 작성합니다. 중첩된 원문 블록은 네 백틱의 바깥 펜스로 감쌉니다.

````markdown
# {书名} 文风

## 生成记录
- 参考资料：작품분석보고서.md·도입 3장 심층 분석·장별 요약
- 抽样章节：第 {K1}/{K2}/{K3}/{K4}[/{K5}/{K6}] 章（장마다 연속 원문 300-500자）
- 生成时间：{date}
- 适用对标书路径：작품분석실/{书名}/
- 文风可用：是  # 검증 가능한 원문 기준점 없으면 “否：이유”. 원문 파일이 없어도 유효 표본이 있으면 사용 가능

## 整体语感
- 句长分布：{짧은·긴 문장 비중과 교대 방식, 짧은 문장을 쓰는 장면. 원문의 짧은 예 1-2개와 어감 요약 한 문장}
  - 依据：原文锚点 / 样本不足
- 标点习惯：{줄표·말줄임표·마침표·느낌표·세미콜론의 빈번한 사용법, 원문 짧은 예 2-3개}
  - 依据：原文锚点 / 样本不足
- 段落节奏：{평균 문단 길이, 한 문단에 행동 하나·여럿, 줄바꿈 습관}
  - 依据：原文锚点 / 样本不足

## 对话技法
- 潜台词模式：{전형적인 속뜻 기법 2-3개: 질문과 다른 답·어조 대비·정보 숨김 등. 각각 원문 예 하나}
  - 依据：已有资料 / 原文锚点 / 样本不足
- 对话标签习惯：{발화 동사 다양성, 행동으로 발화 표지를 대신하는 빈도, 대사·행동 교차 비중}
- 角色语气区分：{주인공·핵심 조연 1-2명의 말버릇·문장 차이, 원문 예 인용}

## 情绪交替模式
- 章内基调切换：{사건 기조 순서로 긴장↔편안함·열혈↔온기 등 교대 여부·장별 횟수 확인}
  - 依据：已有资料 / 原文锚点 / 样本不足
- 跨章基调周期：{분석 범위의 첫 20장 기조 순서. 부족하면 실제 장 수·범위 명시. 고통 3장 뒤 통쾌함 1장 같은 주기 식별}
- 喜剧↔重击的转场手法：{편안함→슬픔의 급전환 기법, 원문 기준점 1-2개}

## 可借鉴技巧（从 작품분석보고서.md 直接引用）
- 写法技巧 Top 5：
  1. {기법명}: {사용법 한 문장}
  2. ...
- 可借鉴套路 Top 3：
  1. {유형명}: {적용 장면}
  2. ...

## 分层模仿建议
- 基础层（必学）：{어휘 선호·문장 리듬·발화 표지·묘사 초점 중 옮기기 쉬운 3-5개. 표현 습관만 배우고 원문 복사 금지}
- 进阶层（结构）：{리듬 추진·복선 배치/회수·시점 전환·장면 연결 중 재사용할 3-5개. 인물·장소·소품을 교체한 뒤 사용}
- 适配层（适合当前项目）：{적합한 기법·인물/장르와 어긋날 기법. 고유명·상징 대사·독특한 장면·사건 순서 그대로 이전 금지}

> 프로젝트에 필요하고 비교 작품 표본이 충분한 긴장·슬픔/억압·편안함/온기·열혈을 우선합니다. 실제 분포에 따라 4-6개를 고릅니다. 부족한 기조는 ‘이 작품은 해당 기조 표본이 부족하여 생략’이라고 쓰며 지어내지 않습니다.

## 不建议模仿
- {비교 작품의 명백한 약점·현재 프로젝트에 안 맞는 기법. 선택 항목이며 비워도 됨}
````

## 품질 검사

- 「已有资料」 결론마다 자료 경로, 「原文锚点」 결론마다 해당 기준점을 찾을 수 있어야 합니다.
- 4–6개 기준점은 서로 다른 기조를 포함하며 색인이 지정한 부분 행 구간에서 가져옵니다.
- 보강 요청 없이는 기존 파일을 덮어쓰지 않습니다.
- Stage 6 실패는 이 단계의 부족한 점만 알리고 Stage 1–5를 다시 실행하지 않습니다.
