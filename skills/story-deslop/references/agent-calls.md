# narrative-writer에게 문체 정리 맡기기

집필자에게 맡길 때만 읽습니다. 이번 작업·범위·결정을 그대로 전달합니다. 집필자는 배포 위치별 읽기 표에 따라 방법을 로드하며 프롬프트에 규칙 본문을 다시 복사하지 않습니다. 아래 중국어 필드명은 호출 계약이므로 유지합니다.

```text
项目目录：{절대 경로}
任务描述：审查+去AI味
正文文件：{이번 장 또는 작품의 절대 경로}
已读依据：{관련 앞부분·설정·설계 파일 경로. 없으면 명시}
检查范围：{기본값은 전체 세 층위 진단. 또는 작가/호출자가 지정한 문단·문제·탐지 분류}
本次诊断：{표현·서술·이야기의 실제 문제와 원문 위치. 없음/자료 부족으로 적을 수 있음}
执行授权：{직접 수정 가능한 범위. 승인된 줄거리 재작성과 반드시 유지할 사실·결과·공개 시점}
文风路径：{이 책의 문체 전체 문서 경로. 없으면 없음}
style_resolution：{적용 요구와 출처, 재정의한 기본 조항, 사실·정보 경계}
作者偏好：{호출자가 이미 가진 선호. 없으면 없음}
篇幅与格式：{장편/단편, 글자 수 범위, 이번 형식 요구}
检查分工：이번 의미 수정만 담당하고 상세 개요를 따라 줄거리를 보충하지 않습니다. 부모 절차가 최종 파일 검사를 담당하고 각 severity에 따라 처리합니다.
返回：승인된 본문을 직접 수정합니다. 경로·실제 수정·미해결 항목·필요한 설계안만 반환하고 전체 본문은 반환하지 않습니다.
```

`任务描述`의 `审查+去AI味`는 “검토 + AI 문체 제거”를 뜻하는 작업 식별자입니다.
