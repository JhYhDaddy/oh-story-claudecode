# 배경 설정

---

<a id="世界观核心"></a>

## 세계관 핵심

**평행세계 + 뉴미디어의 미개척지 + 군사·애국 주제**

현실과 매우 비슷하지만 중요한 차이가 있는 평행세계가 무대다. 차이는 두 가지다.

1. **문화연예/뉴미디어 산업의 극심한 낙후**: 평행세계 전체의 뉴미디어 생태계는 전생(주인공이 온 현실 세계)의 초기 수준에도 못 미친다. 팔로워 1만을 넘는 사람은 손에 꼽히고, 숏폼 플랫폼 ‘더우서우’는 아직 초기 시장의 기회가 열린 상태다. 문공단 계정 십여 개의 총 팔로워는 계정 수보다 적고 평균 한 자릿수다.

2. **전생 지구의 문화연예 명작이 존재하지 않음**: 〈양검〉 주제곡(원제 〈중국 군혼〉), 〈소원대로〉, 〈이별이 꽃을 피우다〉 등이 평행세계에는 없어 주인공이 ‘창작곡’으로 가져올 수 있다. 이것이 시스템 특전의 핵심 원리다.

<a id="核心规则"></a>

## 핵심 규칙

<a id="系统规则文娱国运系统"></a>

### 시스템 규칙—‘문화연예 국운 시스템’

- **발동 조건**: 사용자의 필요를 감지하면 자동으로 깨어나 연결된다. 직접 활성화할 필요가 없다.
- **최초 연결 선물**: 톱스타급 가창력 + 거장급 연출 능력 + 〈중국 군혼〉 반주.
- **임무 방식**: 현실 상황에 따라 자동으로 임무를 발동하고 수치 조건(팔로워 수/화제 열기/기한)을 주며 완료 후 보상을 동적으로 정산한다.
- **보상 구성**: 현금(10만→20만 증가) + 문화연예 기술(톱스타급 목소리·전문가급 피아노 등) + 지구 명작 반주(〈소원대로〉·〈이별이 꽃을 피우다〉……) + 화국 국운 수치.
- **국운 효과**: 국가 차원의 실제 진전으로 전환된다. 항공모함 개발 5년 단축, 반도체 인재 효율 +10%, 드론의 우위 한 세대 추가, 국산 대형 항공기 개발 속도 +10%, 경제·금융 위험 발생률 -5%. 이전 임무보다 두 배 증가한다(첫 임무 +10000, 두 번째 +20000).
- **임무 카운트다운**: ‘목표까지 X 남음, 남은 시간 Y’를 실시간 표시해 계속 압박한다.

<a id="新媒体传播规则"></a>

### 뉴미디어 전파 규칙

- **플랫폼 생태계**: 주 무대는 숏폼 플랫폼 ‘더우서우’(현실 더우인의 가명)이며 웨이보 실시간 검색어와 연동한다. 알고리즘이 관련 관심층(밀리터리 팬/퇴역 군인)에게 콘텐츠를 추천하고 대규모 유입 구간에 들어가면 기하급수적으로 퍼진다.
- **공식 보증 방식**: 군보 공식 웨이보/관영 매체 공유는 인기가 질적으로 도약하는 지점이며 ‘성공을 굳혔다’는 표식이다.
- **여론 역전 주기**: 실시간 댓글/댓글이 ‘이런 쓰레기’에서 ‘미안합니다, 제가 틀렸네요’로 바뀌는 고정 쾌감 리듬. 주요 작품을 공개할 때마다 거친다.
- **플랫폼 제재**: 악의적 명예훼손은 영구 정지, 악성 유언비어 유포는 심흔자사죄 기소로 이어질 수 있다(인터넷정보판공실 개입).

<a id="军队体制规则"></a>

### 군 조직 규칙

- 문공단은 군단급 부대에 속하며 독립적으로 뉴미디어를 운영한다.
- 홍보 실적은 중간 결산 평가에 들어가 부대 명예와 개인 진급에 영향을 준다.
- 영상 공개는 내부 심사를 거치며 중대한 홍보 결정은 군단장(치 지휘관)에게 보고한다.
- 군사력을 외부에 과시하려면 지휘관의 지시가 있어야 하며 자의로 ‘검을 드러낼’ 수 없다.

<a id="特殊设定"></a>

## 특수 설정

<a id="主角身份双重性"></a>

### 주인공의 이중 신분

- **전생**: MCN 회사 창업자. 화제성 이슈/글 50회 이상을 주도했으며 인기 계정 20개 이상의 운영 경험을 갖췄다.
- **현생**: 군 예술학교 졸업생(교내 최고 미남). 서남군구 로켓군 문공단에 자원했으며 문직 6급(대략 소령에 해당) 홍보병이다.
- 두 생의 기억이 겹쳐 군 내부의 정당한 신분 + 전생의 압도적인 콘텐츠 운영 경험 + 시스템의 최고급 문화연예 기술을 함께 갖춘다.

<a id="钟嘉嘉的特殊背景"></a>

### 중자자의 특별한 배경

- 《군보》 수습 기자로 등장하지만 배경이 보통이 아니다(장야오쭈가 전용차와 수행 병사로 판단).
- 할아버지는 퇴역 고위 장교로 군·정계 영향력이 있다. 영상의 군사·정치적 가치를 독자적으로 판단하고 상층부 지원을 자발적으로 제공한다.
- 장천의 콘텐츠 전파망에서 기자 자원(군보) + 노병 취재 소재 + 고위 장교 배경을 결합하는 핵심 외부 접점이다.

<a id="对外战略信号亮剑逻辑"></a>

### 대외 전략 신호(‘검을 드러내기’의 논리)

- 지휘관은 문화연예 콘텐츠를 통해 ‘기회를 빌려 검과 힘을 드러내라’고 지시하며 외부에 군사력 신호를 보낸다.
- 군 개방 행사(건군 기념일 개최, 로켓군 부대 사상 첫 대중 공개)는 이 전략의 연계 행동이다.
- 외부 세력도 이를 감지해 논란을 만들 수 있다. 우웨이식 여론 공격은 이미 나타났고 더 큰 외부 개입은 후속 위험이다.
