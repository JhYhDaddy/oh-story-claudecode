# 본문 서식 규칙

본문 서식 지침입니다. 시점, 대화 배치, 문단 길이는 작가의 요구와 해당 작품의 문체에 따라 정합니다. 제목과 줄바꿈은 아래 형식을 따릅니다. 고정 문단 수나 글자 수를 기준으로 삼지 않습니다.

## 절대 금지

1. **기계적 문단 분할과 긴 문단의 연속 금지**: 극적 단위, 장면, 사건 하나가 끝나는 곳에서 자연스럽게 문단을 나눕니다. 고정 글자 수로 강제 분할하거나 여러 행동·단서·시선 전환을 한 문단에 넣지 않습니다. 완결된 추론, 압박하는 분위기, 감정 변화의 연쇄는 조금 긴 문단으로 유지할 수 있습니다.
2. **문단 사이 빈 줄 금지**: 본문의 인접 문단 사이에는 줄바꿈 문자 `\n` 하나만 허용합니다. 빈 줄이나 연속 줄바꿈 `\n\n`은 안 됩니다.
3. **기계적인 대화 태그 지양**: 자주 반복되거나 공식처럼 쓰이는 ‘그가 말했다’, ‘그녀가 말했다’, ‘그가 살짝 웃으며 말했다’는 행동이나 맥락으로 대체합니다. 평범한 ‘말했다’를 드물게 쓰는 것은 허용합니다.
4. **긴 묘사 나열 금지**: 묘사 사이에 행동, 대화, 새 정보를 넣습니다. 순수 묘사만 연속해서 쌓지 않습니다.
5. **시점 약속 준수**: 1인칭 또는 제한적 3인칭 장면 안에서 다른 인물의 내면으로 임의 전환하지 않습니다.
6. **과도한 주어 반복 금지**: 한 행동 흐름의 연속 문장·문단에서 같은 주인공 이름을 불필요하게 반복하지 않습니다. 문단 첫머리나 주어가 바뀌는 지점에서 이름을 밝히고, 중간에는 대명사·행동 연결·적절한 생략을 쓰며 핵심 전환에서 다시 이름을 밝힙니다.

## 서식 지침

- 대화는 별도 줄에 쓰고, 이어지는 행동은 같은 인물의 대사 앞뒤에 배치합니다.
- 극적 단위, 장면, 감정 또는 행동을 기준으로 문단을 나눕니다.
- 장 제목은 프로젝트의 기존 형식을 따릅니다. 지정된 형식이 없으면 `## 第X章 章名`을 쓰고 제목 뒤에 Markdown 빈 줄 하나를 둡니다.
- 장 사이에 `---`, 수평 구분선, 추가 빈 줄을 넣지 않습니다.

## 예시

### 올바른 예 — 극적 단위에 따른 자연스러운 문단 구분
```
심지가 손을 들자 손끝에서 영력이 솟구쳤다.
눈앞의 결계에 균열이 생기더니 거미줄처럼 퍼져 나갔다.
그녀가 이를 악물고 힘을 더 쏟자 팔 전체가 떨리기 시작했다.
```
문단마다 행동이나 정보 변화 하나만 담습니다. 극적 단위에 따라 자연스럽게 진행하며 문단 사이에는 `\n` 하나만 둡니다.

### 잘못된 예 — 여러 사건을 한 문단에 몰아넣음
```
심지가 손을 들자 손끝에서 영력이 솟구치고 눈앞의 결계에 균열이 생겨 거미줄처럼 퍼지고 그녀가 이를 악물고 힘을 더 쏟자 팔 전체가 떨리기 시작하다가 마침내 결계가 굉음과 함께 부서져 파편이 사방으로 튀었다.
```
한 문단에 여러 행동, 단서, 결과가 섞이면 독자가 중요한 변화 지점에서 멈출 수 없습니다.

### 올바른 예 — 행동으로 대화를 시작
```
심지가 찻잔을 탁 내려놓았다.
"대체 무슨 말을 하려는 거야?"
육연은 대꾸 없이 창밖만 바라보았다.
```
행동과 맥락으로 대화를 시작해 공식적인 태그의 잦은 반복을 피합니다.

### 잘못된 예 — 대화 태그 반복
```
심지가 찻잔을 탁 내려놓았다.
그녀가 말했다. "대체 무슨 말을 하려는 거야?"
육연은 대꾸하지 않고 가볍게 한숨 쉬며 말하고는 창밖만 바라보았다.
```
같은 문단에서 ‘말했다’, ‘한숨 쉬며 말했다’를 연이어 쓰는 것은 공식적인 태그의 반복이므로 행동으로 대체합니다.

### 올바른 예 — 장 제목 뒤에 불필요한 빈 줄 없음
```
## 제2장 암류

육연이 문을 열었을 때 방 안에는 이미 세 사람이 앉아 있었다.
심지는 가장 안쪽 구석에서 쪽지 한 장을 쥐고 있었다.
```
장 제목 `##`와 본문 사이에는 Markdown 렌더링에 필요한 빈 줄 하나만 두며, 본문 문단 사이에는 빈 줄이 없습니다.

### 잘못된 예 — 문단 사이 불필요한 빈 줄
```
## 제2장 암류


육연이 문을 열었을 때 방 안에는 이미 세 사람이 앉아 있었다.


심지는 가장 안쪽 구석에서 쪽지 한 장을 쥐고 있었다.
```
문단 사이의 불필요한 빈 줄(연속 줄바꿈 `\n\n`)이 긴밀한 리듬을 깨뜨립니다.
