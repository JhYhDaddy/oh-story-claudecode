# 이야기 서사 규칙

설정을 추가하거나 수정할 때 다음 규칙을 적용합니다.

## 규칙

1. **설정 교차 확인**: 설정을 추가하거나 수정할 때 기존 설정의 핵심어를 grep으로 검색해 모순을 대조합니다.

2. **세계관 규칙 명시**: 능력 체계, 사회 규칙 등에서 ‘가능한 일’과 ‘불가능한 일’을 설정 파일에 명확히 기록하고 본문에서 일관되게 지킵니다.

3. **의문에는 문서로 기록한 실제 답이 있어야 함**: 설정한 모든 의문이나 수수께끼의 실제 답을 추적/ 또는 설정/에 기록합니다.

4. **인물 동기와 관계의 내적 일관성**: 행동은 설정된 동기에 부합해야 하며, 인물 관계의 변화에는 타당한 계기가 있어야 합니다.

## 예시

### 올바른 예 — 설정 교차 확인
```
추가 설정: 영력은 아홉 단계로 나뉘며 최고 단계는 제9단계 ‘파경’입니다.
실행 작업:
1. 설정/의 모든 파일을 grep으로 검색해 다른 영력 체계 설명이 없는지 확인합니다.
2. 추적/복선.md에서 ‘灵力’를 검색해 모순되는 복선이 없는지 확인합니다.
3. 이번 장의 추적 트랜잭션에 이 결정을 포함합니다. `delta.constraints`에 기록하고 `context.long_term_constraints`의 현재 전체 값에도 반영합니다. `tracking_commit.py`가 추적/장별기록/ 및 추적/문맥.md를 생성하며, 두 파일을 직접 작성하지 않습니다.
```
설정을 추가하기 전에 기존 설정과 복선을 검색해 모순을 방지합니다.

### 잘못된 예 — 교차 확인 없이 설정 추가
```
설정/세계규칙.md에 ‘영력은 열 단계로 나뉜다’를 바로 추가합니다.
결과: 기존 설정에는 ‘영력의 최고 단계는 9단계’라고 적혀 있어 서로 모순됩니다.
추적/복선.md에도 ‘9단계’ 설정에 의존하는 복선이 있습니다.
```
기존 설정을 확인하지 않고 새 내용을 추가하면 세계관에 모순이 생깁니다.

### 올바른 예 — 의문의 실제 답을 문서에 기록
```
본문 제15장: 밀실의 고대 거울에 낯선 사람의 얼굴이 비칩니다.
이번 장 트랜잭션: `foreshadow_changes`에 F012를 심습니다(고대 거울의 낯선 사람, 제15장에 심고 제38장에 회수 예정).
작가 측 진실인 ‘심지의 전생 기억이 남긴 투영이다’를 `timeline_events.objective_fact`에 기록하거나(시간선/작가용진실.md에 파생),
장기 설정으로 `설정/`에 기록합니다. 복선.md는 도구가 렌더링한 현재 상태 뷰이며 ‘真实答案’ 열이 없으므로 직접 작성하지 않습니다.
```
작가 측 자료에 의문의 실제 답과 회수 계획을 남깁니다.

### 잘못된 예 — 의문을 문서에 기록하지 않음
```
본문 제15장: 밀실의 고대 거울에 낯선 사람의 얼굴이 비칩니다.
추적/복선.md에는 아무 기록이 없습니다.
제40장을 쓸 때 이 의문을 잊거나 기존 추적 기록과 모순되는 설명을 제시합니다.
```
문서로 기록하지 않은 의문은 잊거나 앞뒤가 맞지 않게 되기 쉽습니다.
