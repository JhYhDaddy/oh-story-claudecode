# 기본 장르 후보

실시간 순위가 없을 때 사용합니다. 아래 장르·유형·제목은 과거 표본에서 가져왔으므로 후보 가설로만 봅니다. 실현 가능성은 최고 ‘중’까지만 부여하고 다시 조사할 순위도 나열합니다.

## 새 요소의 세 등급

| 등급 | 빈도 | 처리 방식 |
|------|------|----------|
| 새 장르 | 극히 드묾 | 여러 순위·여러 작가에서 반복 표본이 나와야 추세로 판단. 그렇지 않으면 관찰 대상에만 둠 |
| 새 특전 능력 | 비교적 적고 대부분 변형 | 적은 비용으로 검증하기 좋지만 장르의 외형과 감정 촉발 방식도 바꿔야 함 |
| 새 흥미 요소 | 흔함 | 획일화 위험이 높으므로 차별화 메커니즘이 없으면 우선순위를 낮춤 |

## 남성향 장르 후보

| 장르 | 후보 방향 |
|------|----------|
| 현대물 | 회귀·개척 경영·연예계·현대 고무력물. 회귀는 대부분의 요소와 결합 가능 |
| 현환 | 극도류·능력치 투자로 압도하는 유형처럼 피드백이 직접적인 방향 우선. 전통 현환은 최근 표본이 적으면 고위험 표시 |
| 선협 | 독특한 발상과 결합한 방향의 최근 표본부터 조사. 순수 전통형은 독자층을 따로 검증 |
| 역사 | 진·당·명·송·삼국시대. 시대 이동으로 운명 바꾸기·패권 경쟁 |
| 제천·무한류 | 팬픽 세계와 독자 창작 세계를 따로 보고 세계 규칙이 핵심 기대를 계속 실현할 수 있는지 확인 |
| SF | 종말물이 중심이며 독특한 발상·개척 경영·게임 설정과 자주 결합 |
| 미스터리·초자연 | 공포·영적 현상·기문 비술·탐정 추리 |

흔한 유형: 극도류(능력치 투자·압도적 제압), 범인류(평범한 인물의 성장·치밀한 계산), 마법사류(지식 체계·실험으로 성장), 개척 경영물(경영의 성과로 전진), 순위·사건 정리물, 시뮬레이션물, 두 세계 왕래물. 팬픽은 작가가 원작을 명시하고 플랫폼이 허용하며 최근 표본이 유효할 때만 후보로 둡니다.

## 여성향 장르 후보

| 장르 | 후보 방향 |
|------|----------|
| 현대 로맨스 | 재벌·경영자 로맨스, 떠난 아내를 붙잡는 후회 서사, 선결혼 후연애, 과거 시대로 회귀 |
| 시대 로맨스 | 궁중·가문 암투, 회귀 복수, 개척·장사, 권력 암투 |
| 판타지 로맨스 | 현환·선협에서 모두의 사랑을 받는 주인공, 무한·여러 세계를 빠르게 이동하는 서사, 종말 생존 |

## 장편 제목의 표현 방식

아래는 치마오 서고의 장편에서 흔한 제목 방식의 비율입니다. 2026년 10월 집계, 80만 자 이상 남성향 2072편·여성향 1643편이며 대부분 오래 연재된 작품입니다. 치마오의 기존 작품 명명 관행만 나타냅니다. 신작 제목은 이번 신작 순위에 자주 나오는 단어를 기준으로 합니다.

| 방식 | 남성향 | 여성향 |
|------|------|------|
| 제목에 ‘나’ 포함 | 35% | 22% |
| 콜론으로 앞뒤 구분(‘대명: 시작은 작은 현의 현령, 주원장을 격분시키다’) | 28% | 19% |
| ‘회귀’ 포함 | 7% | 9% |
| ‘시작부터’ 포함 | 9% | 1% 미만 |
| ‘…부터 시작’ | 6% | 1% 미만 |
| ‘총재/거물/패도적 경영자’ 포함 | 2% | 13% |
| ‘이혼’ 포함 | 2% | 5% |
