# 진장: 수집과 분석

먼저 `/browser-cdp`로 Chrome을 시작한다. 스크립트는 사이트 전체 순위만 수집한다. 순위는 로맨스·순애·파생작 등의 채널로 나뉘며 집계에서는 채널을 장르로 취급한다.

## 기본 명령

```bash
node scripts/jjwxc-rank-scraper.js --type 12 --outdir {outdir}   # 수입 금방
node scripts/jjwxc-rank-scraper.js --type 7 --outdir {outdir}    # 월간 순위
```

작가가 신작 중 떠오르는 것을 보려면 신인 금방 `--type 15`를 추가한다.

## 선택 매개변수

- `--type`: 수입 금방 12 / 월간 7 / 분기 8 / 완결 금방 14 / 신인 금방 15 / 천 자 금방 17 / all 전체.
- 목록은 전부 유지하고 채널별 상위 10권, 총 최대 100권의 상세 정보를 보충한다. `--top N`으로 채널별 보충 권수, `--detail-limit N`으로 총량을 바꾼다.
- `--list-only`는 목록만 빠르게 수집하지만 소장 수 같은 핵심 지표가 없다. 목록만 볼 수 있고 지표 분석은 할 수 없다.

## 필드와 인기 측정 기준

채널·순위·제목·작가·소장 수(핵심 지표이며 집계의 인기 기준)·영양액·점수·글자 수·상태·작품 페이지 링크를 수집한다. 권수는 전체 목록을 포함하지만 인기는 상세 정보를 보충한 작품만 포함한다. 포함 범위는 머리말의 「详情采集」(상세 수집)을 참조한다.

## 수집되지 않을 때

- 집계의 「采集情况」(수집 현황)에 상세 정보를 대부분 얻지 못했고 로그인하지 않았을 수 있다고 나오면 Chrome에서 진장에 로그인한 뒤 다시 수집한다.
- 일부 상세 정보를 얻지 못했다고 나오면 소장 수가 있는 작품만 결론에 쓰고 보고서에 몇 권을 다뤘는지 명시한다.

## 분석 차원

| 차원 | 확인할 내용 |
|---|---|
| 수입 금방·월간 순위 | 진입 작품의 구성. 순위를 수입으로 환산하지 않음 |
| 분기 순위 | 중기 추세 |
| 신인 금방 | 신인 신작의 장르 신호 |
| 소장·영양액 | 여성향 시장의 핵심 지표 |

## 플랫폼 독자

여성향·로맨스·순애·파생작 중심이다. 섬세한 감정과 설득력 있는 인물상을 원한다. 도입이 느려도 되지만 인물상은 먼저 세워야 한다. 고통 뒤의 달콤함·반전 응징·신분 역전이 주요 쾌감이다. 순진하고 무능한 여주인공, 못되게 굴고도 관계를 되찾으려 하지 않는 남주인공, 왜곡된 가치관은 기피 요인이다. 소개 문구로 독자에게 안심을 줘야 한다.
