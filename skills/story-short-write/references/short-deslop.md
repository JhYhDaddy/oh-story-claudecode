# 단편 AI 문체 제거 적용

이 파일은 단편의 매력 보존과 정밀 수정 범위만 보충한다. Phase 4는 수정 목록·탐지 알림에 따라 해당 위치를 고친다. [deslop-gates.md](deslop-gates.md)에서는 범위·수정 권한만 읽고 연결된 세 방법 문서까지 읽지 않는다. 작품 문체와 `short-craft.md`의 감정 처리 규칙은 계속 유효하다. 판단할 수 없는 문제는 구체적인 정보 공백을 적고 완전한 진단은 끝의 인계 규칙을 따른다.

## 단편의 기능에 따라 보존

| 표현 방식 | 보존 조건 | 수정할 때 |
|---|---|---|
| 슬픔·분노·마음이 식음을 직접 씀 | 맥락이 뒷받침하며 현재 경험이나 관계 전환을 담당 | 같은 뜻의 반복을 줄이고 뒤에 행동을 억지로 붙이지 않음 |
| 1인칭 심판·신분 선공개·뒤늦은 후회 예고 | 구체적인 인물·사건을 가리키고 장르 약속을 이루며 기존 공개 순서와 맞음 | 막연한 해설을 없애고 후속 이행을 확인. 전부 제한적 시점으로 바꾸지 않음 |
| 심판의 결정적 대사·마음이 식은 여운·무시로 끝맺음 | 이 장면의 감정 도달점을 형성 | 누구에게나 적용할 교훈은 지우되 모든 절에 궁금증을 강요하지 않음 |
| 고난·반격의 병렬 | 항목마다 새 증거·상실·관계 변화를 제공 | 중복을 합치고 세 항목 병렬이라는 형태만으로 오류 판정하지 않음 |

강한 감정에도 구체적인 처지와 인물의 이유가 필요하다. ‘매력이 있다’며 기능 없는 반복을 보존하지 않고, ‘자연스럽게’ 하겠다며 원고에 없는 잠금·녹음·컵 던지기·냉소 같은 전략을 넣지 않는다.

## 실행과 인계

탐지 후보의 의미 기능·상세도·매력 보존을 확인하고 수정 뒤 장면 전체와 소절 연결을 다시 읽는다. 동기·증거·사건 추가, 결정·결과·공개 시점 변경은 일반 정밀 수정 권한 밖이다. 원문 위치와 최소 설계안을 제시하며, 이미 명시적으로 재작성이 승인됐으면 그 권한대로 실행한다.

작가가 완전한 AI 문체 제거나 ‘왜 너무 평평한가’의 심층 진단을 원하면 독립 `/story-deslop` 절차를 사용한다. [expression.md](expression.md), [narrative-focus.md](narrative-focus.md), [story-logic.md](story-logic.md)의 세 층위 진단을 모두 읽고 소수의 어휘 신호로 대신하지 않는다. 완전한 제거 작업에서는 단편 구상·장르 방법을 미리 읽지 않고 필요한 사실은 `설정.md`, 소절 개요, 본문에서 얻는다.
