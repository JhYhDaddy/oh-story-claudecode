## 이야기의 틀

| 항목 | 내용 |
|------|------|
| 프레임 유형 | 능력 상승과 내적 변화·성장의 혼합형 |
| 핵심 추진력 | 몰락한 용혈 전사 가문의 장남 린레이는 평민처럼 육체를 단련하다 판룡의 반지를 줍고 성역 마도사의 영혼에게 가르침을 받아 마법사의 길로 바꾼다. 강자의 정점에 올라 가문의 영광을 되찾으려 한다. |
| 중심 갈등 | 가문의 오천 년 빛나는 전통(용혈 혈통/전도 살육/위패에 적힌 선조의 업적)과 현재의 경제난·옅어진 혈통·린레이의 미약한 실력 사이의 격차 |
| 업그레이드 메커니즘 | 힘: 육체 전사 훈련→용혈 각성 조짐→판룡 반지의 영혼 스승을 얻음→마법 재능 확인→대지 계열 마법사의 길로 전환·대지 흔들기 시전. 지위: 몰락 귀족 자제→마수를 거둘 수 있는 미래의 마법사 |
| 서사적 리듬 패턴 | 일상 수련의 사전 배치→강자 통과/재난의 충격→린레이의 결심(감정 해소)→새 기회(반지/스승/재능)→새 궁금증(그림자 쥐/마법 검사) |
| 판단 기준 | 제1–7장은 육체 수련·가문 비밀, 제8–13장은 신맹룡 통과로 마법 입문, 제14–19장은 성역 전투·우산진 재난·반지 각성, 제20–23장은 대지 마법 수련이다. 전사→마법사로 능력이 분명히 상승하며 피의 갈망·정점 추구라는 내면 인식도 함께 변한다. |
| 예상 줄거리 수 | 30장 미만 발췌, 독립 줄거리 3–6개 예상(실제 4개로 범위 이내) |

## 프레임워크 인식 자가검사

| 검사 항목 | 결과 | 설명 |
|--------|------|------|
| 커버리지율 | 100% | 줄거리 4개가 제1–23장을 시간순으로 연속 포괄하며 누락이 없다(작은 규모의 단일 주선 발췌에서 정상적인 결과). |
| 분할 단위 검사 | 통과 | 각 줄거리는 독립 목표·갈등·완결된 서사 곡선이 있고 단일 사건이나 거시 주제만인 항목은 없다. 가문 비밀→마법 입문→재난→수련의 단계 경계로 나누어 포함·중첩이 없다. |
| 독립성 검사 | 통과 | 각각 독립 목표·주요 갈등·인물군·긴장과 이완 리듬 네 조건을 충족한다. |
| 수량 확인 | 통과 | 실제 4개로 30장 미만의 예상 3–6개 범위 이내 |

## 주선: 린레이가 강자가 되는 길(전사에서 마법사로)

| 항목 | 내용 |
|------|------|
| 제목 | 린레이가 강자가 되는 길 |
| 유형 | 주선 |
| 설명 | 단일 주선의 선형 서사이며 기회의 발전+인식 변화에 따라 네 단계로 나눈다.**1단계(제1–7장) 가문의 각성**: 빛나는 전통과 현재 몰락의 격차가 핵심 갈등이다.핵심 인물은 힐먼(육체 훈련 입문·강자 동경 주입), 호그(용혈 혈통 공개·검사 실패·전도 살육을 되찾겠다는 맹세와 연결)다.능력·지위: 여섯 살 평민식 아침 훈련→여덟 살 8·9급 전사 목표→혈통상 투기를 닦지 못하고 육체만 단련할 수 있음을 앎.주제 모티프: 계승·결심·부자 관계.**2단계(제8–13장) 마법 입문**: 지나가는 8급 마법사가 마을을 압도하고 린레이가 전사의 한계를 깨닫는 것이 핵심 갈등이다.핵심 인물은 자주색 로브 마법사(화사의 춤으로 용병대를 몰살해 충격을 줌), 호그(마법사·마수·길들이는 조건 설명)다.능력·지위: 피가 끓는 경험(혈통 조짐)→마법사가 되어 마수를 거두려는 열망→늦가을 펜라이성 재능 검사 허락.주제 모티프: 충격·동경·선택.**3단계(제14–19장) 재난과 각성**: 성역 강자 루디·틸론이 지나가며 싸워 거석 재난이 우산진을 덮친다. 린레이가 몸을 던져 동생을 보호하다 머리에서 피를 흘린다.핵심 인물은 루디·틸론(전투의 가해자), 힐리(몸을 던져 주인 보호), 데린 코워트(반지에서 깨어난 성역 마도사 스승)다.능력·지위: 반지에 피가 묻음→피를 흡수해 각성→데린이 나와 주인을 인정하고 마법 전수를 약속.주제 모티프: 희생·운명을 뒤집는 기회·운명의 전환.**4단계(제20–23장) 마법 수련**: 자신의 재능을 모르는 불안과 스승의 존재를 숨기는 이중생활의 부담이 핵심 갈등이다.핵심 인물은 데린 코워트(재능 측정·대지 계열 마법 전수)다.능력·지위: 천 명 중 하나인 원소 친화력·또래 열 배 정신력 확인→마법사의 길로 전환→매일 여섯 시간만 자며 수련→대지 흔들기 시전.주제 모티프: 고된 수련·변화·새 여정.**복선 회수 사슬**: ①판룡 반지—제6장 썩은 나무 선반이 깨지며 떨어짐(심기)→제7장 린레이가 주워 이름을 붙임→제17장 머리의 피가 묻자 흡수하고 빛남(활성화)→제18장 데린 코워트가 나옴·제19장 피로 주인 인정(각성), 12장에 걸쳐 회수.②전도 “살육”—제3장 호그가 600년 전 매각을 밝히고 린레이가 되찾겠다고 맹세한다. 장기 복선이며 발췌에서는 미회수, 제20장 마음속으로 다시 떠올릴 뿐이다.③용혈 혈통—제3장 용혈침 검사가 농도 부족으로 실패(심기)→제10장 루가의 참혹한 죽음 뒤 피가 끓고 피를 갈망함(부분 회수, 혈통 영향 추정)→제12장 호그가 겁먹지 않은 모습을 용혈 자질로 확인(호응).④마수 그림자 쥐—제23장 끝에 어린 개체가 나타나고 데린이 알아본다(새 훅, 미회수).병행 줄거리는 없다. 성역 강자 싸움·용병의 다이아몬드 쟁탈 등은 린레이의 인식을 움직이는 외부 사건으로 주선에 종속된다. |
| 주제 | 계승과 변화·운명을 뒤집는 기회·고된 수련으로 성장 |
| 포함 줄거리 | 용혈 전사 가문의 비밀(제1–7장)→강자 통과와 마법 입문(제8–13장)→성역 전투와 우산진 재난(제14–19장)→판룡의 영혼과 마법 수련(제20–23장) |

줄거리 관계: 단일 주선의 선형 구조이며 병행·교차선이 없다. 성역 전투·용병 다이아몬드 쟁탈 등의 외부 갈등은 주선에 **의존**하여 주인공 인식을 돕기 때문에 따로 세지 않는다.
