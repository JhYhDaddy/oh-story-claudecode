# 국내 게시·투고 자료 초안

대상: 문피아, 네이버 웹소설, 노벨피아, 네이버 시리즈, 카카오페이지, 리디, 포스타입. 한국 플랫폼이 기본 후보이며 특정 플랫폼을 자동 확정하지 않는다. 직접 연재·투고 준비·개인 발행 중 목적을 먼저 확인한다. 네이버 웹소설과 네이버 시리즈를 구분한다.

## 지원 범위

지원하는 것은 기존 작품을 바탕으로 한 한국어 자료 초안과 문서 형식 검사다. 등록 화면, 공식 장르·태그 목록, 제목·소개 글자 수, 표지 규격, 심사·계약 조건은 검증하지 않았다. `PASS`는 플랫폼 적합성·제출 가능·게시 완료를 뜻하지 않는다. 미확인 규칙을 판체 규격으로 채우거나 후보 장르를 공식 선택값으로 말하지 않는다.

2026-11-08 확인 근거:
- [문피아](https://nhelp.munpia.com/faq?faqCategoryId=364&page=1): 자유연재와 새 작품 등록 안내.
- [네이버 웹소설](https://help.naver.com/service/5634/bookmark/1266?osType=COMMONOS): 챌린지·베스트·시리즈에디션 구분. 시리즈와 동일 등록 양식으로 취급하지 않는다.
- [노벨피아](https://novelpia.com/freestory/new/1): 공개 자유연재 목록. 관리자 양식은 미확인.
- [포스타입](https://www.postype.com/about): 포스트 유료 분량·가격·공개 범위 설정 안내.
- [네이버 시리즈](https://series.naver.com/novel/home.series), [카카오페이지](https://page.kakao.com/), [리디](https://ridihelp.ridibooks.com/support/solutions): 시장 조사·투고 준비 후보. 실제 접수 경로와 요건은 별도 확인한다.

## 작성 절차

플랫폼·목적을 정하고 기존 작품의 확정 제목·필명·소개 근거를 읽는다. 필요한 필드만 제안하며 새 인물·사건을 만들지 않는다. 제목·소개·장르·태그는 작가 확인 전 제안이다. 공식 양식이 필요하면 현재 공식 설명이나 날짜가 있는 등록 화면을 요청한다. 확보하지 못해도 일반 초안은 작성할 수 있다. 출처마다 확인일·화면 범위·미확인을 기록한다.

표지는 선택 사항이다. 이미지 생성은 작가가 요청한 경우만 수행하고 표지 크기·AI 이미지 허용 여부를 임의 확정하지 않는다. 실제 게시·로그인·양식 제출은 수행하지 않는다.

작성 중에는 대화로 초안을 보여 준다. 작가가 요청한 필드를 확정하거나 초안 저장을 요청했을 때 `게시자료-<플랫폼>.md`를 책 폴더에 저장한다. 기존 파일을 읽어 수동 수정은 보존한다. 저장해도 상태는 자료 초안이며 플랫폼 적합성 확인과 구분한다.

## 한국어 문서 형식

아래 메타정보 순서와 절 제목을 유지한다. 값의 제안·확정 여부는 각 항목에 표시한다. 플랫폼 확인 필요에는 남은 확인 항목을 적고 빈칸이나 '없음'으로 완료 처리하지 않는다. 출처에는 실제 읽은 공식 URL 또는 제공 자료 경로와 확인일을 적는다. 원문을 읽지 못했다면 그 사실을 쓴다.

```markdown
> 형식: ko-draft-v1
> 플랫폼: 문피아
> 목적: 직접 연재
> 상태: 자료 초안
```
