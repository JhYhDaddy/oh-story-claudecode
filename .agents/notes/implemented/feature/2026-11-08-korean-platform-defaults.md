# Agent Note: 한국 플랫폼 기본 라우팅

Status: implemented

## Problem
한국어 번역 후에도 플랫폼 선택, 단편 기본 검토와 게시 준비가 중국 시장으로 연결된다.

## Decision
한국 플랫폼을 목적별 기본 후보로 제시하고 특정 플랫폼은 자동 확정하지 않는다. 기존 중국 플랫폼은 명시적 선택으로 유지한다. 한국 시장 조사는 공개 자료와 사용자 제공 자료의 출처·시점을 기록하며 미검증 자동 수집을 지원으로 표시하지 않는다. 국내 게시 자료는 한국어 초안 형식으로 별도 검증하며 공식 양식·태그·제한을 추정하지 않는다. 일반 집필·검토 기준과 플랫폼 공식 요건을 구분한다.

## Alternatives considered
README만 바꾸면 변경량은 작지만 실제 라우팅과 맞지 않는다. 중국 지원을 삭제하면 선택지는 단순해지지만 기존 프로젝트 호환성을 잃는다.

## Consequences
한국어 작업이 중국 시장 기본값으로 흐르지 않는다. 국내 자동 수집과 등록 양식 검증은 지원하지 않는 범위를 명시해야 하며 자료 확인 비용이 남는다. 추가 필독은 한국 분기에만 한정하고 문서 예산에 등록한다.

국내 게시 자료는 ko-draft-v1으로 분리하며 기존 판체 형식은 보존한다. 단편 설계 검사기는 한국 플랫폼과 명시적인 유료 전환 없음 선언을 받으며 개요와 충돌하면 실패한다. 3개 OS CI에 국내 초안 검사를 등록한다. 문서 분량은 한국 분기와 표지 선택을 별도로 등록하고 실제 증가한 경로 예산만 올리며 전역 35K 상한과 기존 예외 목록은 유지한다.
