# 이야기 개요 규칙

장편의 권별 개요와 장별 상세 개요에 적용합니다. 단편의 소절 개요는 해당 집필 스킬을 따릅니다. 필드와 작성 방식은 story-long-write의 권별·상세 개요 템플릿을 기준으로 하며, 작업 묶음이 있으면 그 지침을 우선합니다. 여기서는 파일에 반드시 기록할 항목만 다룹니다.

## 규칙

1. **권별 개요**: story-long-write의 권별 개요 템플릿을 따릅니다. 각 제목 바로 아래에 범위(`> 作用域：卷级常任` 또는 `> 作用域：单元级 {单元ID}`)를 적습니다. 공급 자체 검사와 개요 구성 중 추가한 내용은 `개요/개요초안_{单元ID}.md`에 기록하며 권별 개요에 넣지 않습니다.

2. **细纲必填项** — 상세 개요 필수 항목: 각 상세 개요(상세개요_*.md)는 현재 ‘章节蓝图’(장별 설계도)를 포함해야 합니다. 아래 중국어는 템플릿의 필드명입니다.
   - 기본 실행 필드: 核心事件(핵심 사건), 字数目标(목표 글자 수), 字数口径(글자 수 산정 기준), 单元ID/位置(단위 ID/위치), 目标情绪(목표 감정), 主角目标/关键选择(주인공 목표/핵심 선택), 章首钩子(장 첫머리 훅), 爽点(쾌감 지점)
   - 本章禁止提前释放: 이번 장에서 미리 공개하면 안 되는 진실, 숨겨 둔 수, 관계의 결론, 최종 갈등입니다. 위 항목과 합해 필수 필드 9개입니다.
   - 内容概括(내용 요약, 5단계): 起因 / 发展 / 转折 / 高潮 / 结尾(발단/전개/전환/절정/결말). 결말에는 마지막 구체적 행동이나 장면을 적고 상태를 판정하는 문구를 쓰지 않습니다.
   - 情节安排(여러 줄거리 구성): 主线推进 / 辅线推进(권별 개요 L 번호 참조) / 事件线或任务线 / 感情线或关系线 / 逻辑线(주 줄거리/보조 줄거리/사건·임무/감정·관계/논리 흐름)
   - 人物关系和出场顺序(인물 관계와 등장 순서): 실제 등장 순서대로 인물·세력·주요 물건을 나열하고 관계 변화를 적습니다.
   - 情节细化(세부 사건): 사건 순서를 `# | 情节点（谁做了什么） | 功能标签 | 执行边界（禁＋放）` 표로 작성합니다. ‘不填写逐点字数’(사건별 글자 수를 적지 않음) 규칙을 따르고 사건 수로 분량을 예측하지 않습니다. 行动成本(행동 비용, 없을 수 있음)/收益归属(이익 귀속)도 표시하되 억지로 대가를 만들지 않습니다.
   - 结尾设定和钩子(결말 설정과 훅): 마지막 구체적 행동·장면, 미해결 문제, 다음 장 추진력, 장 끝 훅을 기록합니다.
   - 선택 항목(필요할 때 작성하며 없어도 차단하지 않음): 字数范围(작가가 상·하한을 지정한 경우에만, 예: 2000-2600), 阶段位置, 章节定位, 本章结构公式, 本章标价, 闭环状态, 写手自由区, 镜头准入, 信息差触发点, 사건 표의 「分辨率」 열입니다. 각각 분량 범위, 단계 위치, 장의 위치, 구조 공식, 이번 장의 대가, 완결 고리 상태, 집필자 재량 영역, 장면 허용 조건, 정보 격차 발동 지점, 해상도를 뜻합니다. 契约风险(약속 위반 위험)은 이번 장에서 단위 카드의 같은 항목이 바뀌는 경우에만 적습니다.

3. **누락 항목 처리**: 기존 상세 개요에 새 장별 설계도 필드가 없다는 이유로 이어쓰기를 막지 않습니다. 기존 필드(核心事件, 情节点序列, 目标情绪, 章首/章尾钩子, 字数目标)로 돌아가 읽고, 명시적으로 개요 보완·수정을 요청했을 때만 현재 템플릿으로 채웁니다. 새로 만들거나 보완·수정하는 상세 개요는 필수 항목을 채운 뒤 본문을 씁니다. 기존 권별 개요도 차단하지 않고 기존 필드 구조로 읽으며, 이미 쓴 구간의 권별 개요를 자동 수정하지 않습니다. 자료로 확인할 수 없는 보조 줄거리, 관계 변화, 대가·이익은 `[待补充]`로 표시하며 지어내지 않습니다.
