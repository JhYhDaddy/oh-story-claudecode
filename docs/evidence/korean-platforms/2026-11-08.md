# 한국 플랫폼 브라우저 검증 기록

확인일: 2026-11-08 (Asia/Seoul). Windows Chrome에서 실제 표시된 화면과 DOM 속성을 읽었다. 계정 식별 정보는 기록하지 않았다. 작품 생성·저장·업로드·게시·투고는 하지 않았다. 아래 결과는 화면 관찰이며 서버 검증 통과나 자동 연동 구현을 뜻하지 않는다.

## 네이버 새 작품 화면

출처: [새 작품 쓰기](https://novel.naver.com/my/novelWrite). MY의 새 작품 쓰기에서 진입했다.

- 제목, 장르, 연재 주기, 표지 이미지, 작품 소개, 태그, 필명, 작가 블로그 연결 항목이 표시된다.
- 장르 선택지는 로맨스·로판·판타지·현판·무협·미스터리·라이트노벨·자유장르의 8개였다.
- 연재 주기는 자유연재와 요일연재로 나뉜다. 자유연재 상태에서는 월~일 선택이 비활성화되어 있다.
- 판타지를 선택하자 기본 표지 10개와 태그 추가가 나타났다. 다른 장르의 표지 구성은 확인하지 않았다.
- 태그 선택 창은 선택 개수 `/10`을 표시하며 세부장르/배경·캐릭터·소재·직업·분위기 탭을 제공한다. 실제 11개 선택 거부나 저장 시 제한은 시험하지 않았다.
- 제목 `inputNovelTitle`과 소개 `inputSynopsisContent`에는 DOM의 `maxlength`, `required`, `placeholder` 속성이 없었다. 이는 길이 제한이나 필수 조건이 없다는 뜻이 아니다. 자바스크립트 및 서버 검사 여부는 미확인이다.
- 저장 및 저장 후 1회 쓰기 버튼이 존재한다. 화면은 저장·회차 등록을 가이드라인 동의로 간주한다고 안내하므로 두 버튼을 누르지 않았다. 필명도 추가하지 않았다.
- 따라서 초안 생성 시 화면 항목을 참고할 수 있지만, 업로드 가능 판정이나 공식 길이 제한으로 사용하면 안 된다.

## 공개 순위의 해석

### 문피아

출처: [무료 투데이 베스트](https://www.munpia.com/best/today).

- 화면에 11월 08일 14시 집계가 표시되었다. 무료 투데이·골든·선호작·신인·신규 등의 목록과 유료 목록이 구분되어 있다.
- 상위 카드에서 순위, 장르, 제목, 작가와 시간·조회 표시를 확인했다. 하위 카드에는 동일한 상세 수치가 모두 노출되지 않았다.
- 이 화면의 조회와 홈페이지 작품 누적 조회를 동일 지표로 합치지 않는다. 이번 관찰에서는 집계 산식과 시간 숫자의 정확한 의미를 확정하지 않았다.

### 네이버 웹소설

출처: [챌린지리그 랭킹](https://m.novel.naver.com/challenge/ranking)의 집계기준 팝업.

- 관찰한 선택 상태는 판타지·일간·전체, 기준일은 2026.11.07이었다. 장르 기본 선택은 사용자 설정에 영향받을 수 있으므로 주소만으로 장르를 확정하지 않는다.
- 일간/주간 및 전체/신작을 구분한다. 조회·관심등록을 함께 사용한 상위 100개 집계라고 안내한다. 신작은 공지를 제외한 최초 회차 등록 후 14일 이내를 대상으로 한다.
- 목록에는 순위, 작가, 회차 수, 조회, 별점, 관심 등이 표시된다. 표시 조회수만 재정렬해서 공식 순위를 재현했다고 주장하지 않는다.

### 노벨피아

출처: [순위 화면](https://novelpia.com/top100), [공식 랭킹 안내](https://novelpia.com/faq/49/view_2977790/) (게시 표시: 2023-10-27, 확인: 2026-11-08).

- `/top100`에서는 조회순·추천순·선작순·인생픽, 24시간·7일·30일, 전체·PLUS·자유 필터를 확인했다. TOP100 메뉴는 별도 `/novel_ranking` 주소로 연결된다. URL 이름만으로 주간 TOP100이라고 분류하면 안 된다.
- 공식 안내상 실시간 계열은 최근 등록 회차의 최고 조회수를 사용하며, 태그 차단에 따라 사용자별 목록이 달라질 수 있다. 별도 주간 TOP100은 주간 회차 조회와 연재 일수를 반영한다. 두 목록은 집계 방식·갱신 주기가 다르다.
- 안내의 연재 15화 조건 등은 해당 순위 대상 조건이다. 작품 업로드 최소 회차 조건으로 바꾸어 쓰면 안 된다.
- 공식 안내는 과거 게시물이므로 현재 필터 화면과 함께 보존하고, 공개되지 않은 가중치나 계산식은 추정하지 않는다.

## 로그인 복구 후 추가 확인

같은 날 사용자 Chrome 연결 복구 후 두 플랫폼 모두 로그인된 상태를 확인했다.

### 문피아 등록 전제

내서재의 새 작품 등록하기 및 [서재관리](https://librarym.munpia.com/manage) 진입에서 휴대전화번호 등록 창이 표시되었다. 이후 사용자가 직접 등록을 완료했고, 같은 날 작품 등록 화면에 진입한 상태를 확인했다. 에이전트는 전화번호를 입력·전송·기록하지 않았다.

### 문피아 작품 등록 양식

출처: 로그인된 내서재 → 작품 등록 화면(개인 서재 식별자가 포함된 URL은 기록하지 않음). 현재 연재 등급은 무료웹소설 > 자유연재로 표시됐다.

- 작품명은 필수 표시와 DOM `required`, `maxlength=30`을 확인했다. 다만 안내 문구는 “30자 이상 입력하실 수 없으며”라고 되어 있어 30자 포함 여부가 속성과 일치하지 않는다. 29/30/31자 경계 및 서버 검사는 미검증이며 최대 30자로 확정하지 않는다.
- 제목에 허용된 특수문자로 쉼표, 쌍점, 물음표, 느낌표, 마침표, 대괄호, 붙임표, 소괄호, 퍼센트를 안내한다. 실제 거부 동작은 시험하지 않았다.
- 작품소개는 최대 800자 안내와 `maxlength=800`을 확인했다. 작품태그는 최대 10개 안내가 있다.
- 주장르와 부장르는 동일하게 선택할 수 없다고 안내한다. 주장르 선택 전 부장르 버튼은 비활성 상태다.
- 주장르 선택지는 무협·판타지·퓨전·게임·스포츠·로맨스·라이트노벨·현대판타지·대체역사·전쟁·밀리터리·SF·추리·공포·미스테리·일반소설·시·수필·중·단편·아동소설·동화·드라마·연극·시나리오·BL·팬픽·패러디로 표시된다. 가운데점은 일부 장르명의 일부이므로 임의 분할하지 않는다.
- 연재요일, 일반/성인, 공개/비공개/일부공개, 독점/비독점, 계약/출간, 계약제안, 댓글, 신작 알림 항목을 확인했다.
- 이 빈 양식의 초기 선택은 공개·독점·계약안됨·계약제안 받기·댓글 허용·1화 공개 시 알림이었다. 다중 플랫폼 연재 자료를 준비할 때 독점이나 알림을 기본값 그대로 확정하면 안 된다.
- 계약제안은 공개 10화 이상이라는 안내가 있다. 비공개·예약 회차는 제외하며, 이 조건을 작품 등록 최소 회차로 해석하지 않는다.
- 입력·선택값을 변경하지 않고 장르 목록만 펼쳐 확인한 뒤 닫았다. 작품등록 버튼은 비활성 상태이며 누르지 않았다. 표지 및 회차 편집 양식은 이번 화면에서 확인하지 못했다.

### 노벨피아 작품추가 양식

출처: [작품추가](https://novelpia.com/publishing/new). 메뉴의 작품 관리하기 → 작품 관리 → 작품추가로 진입했다.

- 작품명, 분류(자유연재/연습작품), 독점작 여부, 연령, 1차 분류 태그, 해시태그, 연재요일, 기타옵션, 작품소개, 표지와 표지사용 규정확인 항목을 확인했다.
- 독점작 여부는 이 계정의 현재 화면에서 비독점작만 표시됐다. 다른 계정이나 계약 상태까지 일반화하지 않는다.
- 연령 선택은 전 연령/15세/19세. 1차 분류는 판타지·무협·현대·로맨스·현대판타지·라이트노벨·고수위·공포·SF·스포츠·대체역사·기타·패러디였다.
- 해시태그는 최소 2개, 하나씩 입력 후 Enter로 추가하라는 안내가 있다. 연재요일은 월~일과 비정기 체크 항목이다.
- 전연령 북커버는 400×600 이미지, 고화질 표지는 최대 20MB라고 표시된다. 각각 북커버 준비중 선택지가 있다. 파일 업로드 허용/거부 동작은 시험하지 않았다.
- 후원거부·2차창작허용·완결·들여쓰기 사용 안함 옵션이 있다. 표지사용 규정확인은 저작권 소유 또는 상업적 이용 가능 중 선택하는 구조다. 권리 확인 항목은 작가가 판단해야 하며 자동 선택하지 않았다.
- 작품등록 버튼을 누르지 않았다. 위 수치와 선택지는 화면 안내 확인이며, 서버 규칙이나 회차 편집 제한 검증을 뜻하지 않는다.

## 재개할 작업

1. 세 플랫폼의 최초 작품 양식은 부분 확인 완료했다. 문피아 제목 30자 경계, 플랫폼별 서버 제한과 회차 편집은 추가 검증 대상이다. 개인정보·인증번호는 기록하지 않는다.
2. 네이버의 회차 편집은 작품 저장이 선행될 수 있으므로, 이번 비게시 검증 범위에서는 미검증으로 남긴다.
3. 글자 수·필수값·표지 규격은 공식 안내 또는 실제 오류 메시지로 확인한 값만 별도 규격으로 채택한다.
4. 자동 수집기는 아직 미구현이다. 필터 변경·추가 목록 로딩·로그인 실패·누락에 대한 자동 테스트도 이번 수동 관찰로 대체하지 않는다.
