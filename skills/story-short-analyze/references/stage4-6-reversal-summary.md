# Stage 4–6: 반전과 작법 기법·인물과 도입 및 결말·종합 평가

Stage 4–6에서 읽는다. 앞부분은 방법, 뒷부분은 출력 템플릿이다. 각 Stage를 마치면 [quality-checklist.md](quality-checklist.md)의 해당 절로 자체 점검한다. 구조 패턴·인물 관계·투고 측면·원문의 약점에 대한 판단법은 각각의 관찰 기준에 있다. 읽을 파일은 진입 문서의 ‘시점별 읽기’를 따른다.

## 방법

### Stage 4: 반전 설계 + 작법 기법

#### A. 반전 분석

**선행 반전 확인**: 이야기 시간선이 시작되기 전부터 존재한 거짓말/오판이 있는가.

> **반전 없음/응보형**: 복수 쾌감물·회귀물 등에는 전통적인 반전 없이 악역의 응보가 차례로 실현되는 모습에서 쾌감이 나오는 경우가 있다. 이때는 반전 원리 분석을 건너뛰고 ‘응보 설계’를 분석한다. 악역이 어떻게 단계적으로 파멸하며 각 단계의 사전 배치와 만족감이 무엇인지 본다. 악행별로 대응하는 응보와 쾌감의 근거를 표로 정리한다. 이상적으로는 응보가 악행과 정확히 대응한다(상대가 쓴 수법으로 되갚음).
>
> **주도적인 응보와 악역의 자멸**: 주인공의 계획이 결과를 일으키는 경우와 악역 내부의 반목·자초한 손실을 구분한다. 인과의 사전 배치와 감정 해소를 연결해 효과를 설명하며 어느 쪽이 더 사실적이거나 통쾌하다고 미리 정하지 않는다.

**반전 원리 분석**: 반전이 있을 때 수행한다.
- 사전 단서: 원문에서 하나씩 위치를 열거하고 실제 수량을 기록한다. 수를 채우려고 추가하지 않는다.
- 오도 방향: 텍스트가 독자를 어디로 이끄는가.
- 진실 공개: 어떻게 밝혀지는가.
- 개연성: 되짚어 보아도 사실이 왜곡되지 않는가.
- 시점: 전체의 몇 % 위치인가.
- 사전 축적과 해소의 분량비: 사전 축적 글자 수 : 해소 글자 수.

**반전 사슬**: 여론 반전·겹겹의 반전 서사는 뒤 반전이 앞 반전의 결론을 뒤집는 연속 구조를 가질 수 있다. 순서대로 기록한다.
- 반전마다 유형 + 촉발 사건 + 독자의 인식 변화.
- 반전 사이의 인과: 앞 반전이 뒤 반전을 어떻게 준비하는가.
- 전체 효과: 점층/중첩/의외성.
- `reversal_type`에는 결말 영향이 가장 큰 층위 하나만 기록한다.

**겹겹의 반전 품질 검증**: 뒤 층위가 앞 증거를 어떻게 재해석하며 앞 층위의 행동이 뒤 층위를 어떻게 일으키는지 검사한다. 한 층위를 지워도 나머지의 인과·해석·감정 효과가 모두 그대로일 때만 그 층위가 불필요할 수 있다고 판단한다.

**복선형 반전**: 도입에서 이미 준 정보가 진실을 안 뒤에는 완전히 다르게 읽히기도 한다. 새 단서를 보태지 않고 독자가 스스로 깨닫게 하는 고전적인 복선의 쓰임이다. 원문 위치, 초독 때의 이해, 진실을 안 뒤의 새 이해를 표시한다.

#### B. 작법 기법 분석

다음 항목의 사용을 각각 분석한다.

| 항목 | 분석 내용 |
|------|----------|
| POV 전략 | 인칭 선택의 효과·서사 거리·신뢰성 |
| 대화 기법 | 밀도·함축 의미 비율·유형 판별 |
| 시간 조절 | 시간 도약·장면 압축·교차 편집 |
| 정보 조절 | 독자가 아는 것과 인물이 아는 것, 은폐/공개 시점 |
| 감각의 기준점 | 오감 분포·주도 감각·감각 전환 |
| 문장 리듬 | 장단문 교대·가속/감속·핵심 문장 위치 |
| 대비 설계 | 인물·전후·환경 대비 |
| 심상/물건 | 반복되는 물건·심상·상징 |
| 여백 기법 | 쓰지 않음으로 표현하기·생략·암시 |
| 전문 기술의 무기화 | 직업적 특기가 대립 수단을 어떻게 바꾸며 조작이 이미 제시된 능력·제약에 맞는가 |
| 시간제한 구조 | 명확한 기한이 선택을 제한하고 손실을 키우거나 행동을 어떻게 바꾸는가 |
| 이중 시점 서사 | 같은 사건을 두 인물 시점으로 보며 어떤 다른 정보를 얻고 독자의 감정 판단이 바뀌는가 |
| 실시간 댓글/댓글 상호작용 | 이야기 속 ‘독자 댓글’이 임무·놀림·전개 예고를 제공하는 인물처럼 기능한다. 댓글 자체도 자신감에서 붕괴로 가는 변화 곡선을 가질 수 있음 |
| 반전 매력 | 특정한 사람인 척하다가 본성을 드러내고 매번 실패할수록 상대가 더 좋아함. 반복하며 강화되는 패턴에 주목 |

각 기법에 사용 위치·효과 평가·재사용 조건을 표시한다.

### Stage 5: 인물 분석 + 도입과 결말

#### A. 인물 추출

원문에서 하나씩 추출하고 실제 담당 기능을 기록한다. 인원수를 미리 정하지 않는다.

**인물 분류: 두 축**

첫째 축 — 서사 역할: 이야기에서 차지하는 위치.
- **주인공**: 주된 시점 인물 또는 핵심 초점 인물.
- **중요 조연**: 비중이 크고 독립적인 변화 곡선을 가진 인물.
- **기능 인물**: 촉매·대조 등 특정 서사 기능을 담당.

둘째 축 — 행동 역할: 이야기에서 움직이는 방식.
- **능동형**: 스스로 전개를 추진하고 핵심 선택을 함.
- **수동형**: 전개에 떠밀리고 수동적으로 감당함.
- **변화형**: 수동에서 능동으로, 또는 그 반대로 변함.

> 한 인물이 동시에 ‘주인공’이면서 ‘수동형’일 수 있고 전개에 따라 행동 방식이 바뀔 수도 있다. 두 축은 독립적으로 표시한다.

**두 주인공 구조**: BE 고통 중심 서사·쌍방 시점 서사 등에는 서로 다른 단계를 이끄는 주인공 둘이 있을 수 있다. 판별 기준: ① 둘 다 평면적이지 않은 완전한 감정 곡선을 가진다. ② 각각 다른 인물 중심의 A 구간과 B 구간이 명확하다. ③ 독자가 둘 모두에게 강하게 공감한다. 둘 다 ‘주인공’으로 표시하고 각자가 주도한 장 범위를 밝힌다.

| 필드 | 설명 |
|------|------|
| 이름 | 전체 이름 |
| 분류 | 서사 역할{주인공/중요 조연/기능 인물} + 행동 역할{능동형/수동형/변화형} |
| 성격 | 꼬리표에서 추론하지 않고 행동에서 도출 |
| 내적 모순 | 외부 사건이 아닌 핵심 심리 갈등 |
| 핵심 대사 | 인물을 가장 잘 대표하는 1-2문장 |
| 변화 곡선 | 시작→전환→끝. 촉발 사건·위치를 표시하며 뚜렷한 곡선이 없으면 ‘평면적’ |
| 기능 태그 | 이야기에서 담당하는 서사 기능 |

**인물 기능 태그 7종**:

| 태그 | 정의 | 예시 |
|------|------|------|
| 감정의 매개 | 독자 공감의 주된 매개 | 1인칭 주인공 |
| 압박의 근원 | 부정적 감정을 만드는 인물 | 냉담하거나 통제하는 남주인공 |
| 반전 촉발자 | 핵심 반전을 일으키는 인물 | 납치 사건의 제삼자 |
| 도덕적 기준점 | 정상적 가치관을 대표하는 인물 | 주인공을 걱정하고 돌보는 어른 |
| 대조 인물 | 주인공과 대비되는 인물 | 온화한 조연과 냉혹한 주인공 |
| 촉매 | 전개를 추진하되 핵심 갈등에 직접 참여하지 않음 | 이어 주거나 온기를 주는 인물 |
| 자멸형 | 자기 행동으로 자신을 파멸시킴 | 아들을 편애하는 어머니, 편집적인 가족 |

한 인물에 여러 태그를 붙일 수 있다.

**대비가 있는 인물**(`character_archetypes`에 집계): 신분(외부에 보이는 신분), 겉모습(드러내는 행동), 내면의 핵심(진짜 마음)의 세 층위를 채운다. 최소 한 층위가 나머지 둘과 반대이며 원문에 행동 대비가 하나 이상 있으면 한 명으로 센다(겉으로 순종하면서 몰래 녹음·증거 수집 등). 꼬리표만 있고 행동 대비가 없거나 세 층위가 일치하면 세지 않는다. 대비·동기·악역·관계를 자세히 분석할 때는 analysis-characters.md를 읽으며, 인원 집계만 할 때는 필요 없다.

#### A2. 인물 관계

사건 노드에서 관계와 변화를 추출한다.

| 필드 | 설명 |
|------|------|
| 관계 쌍 | A ↔ B, 전체 이름 |
| 관계의 본질 | 핵심을 한 문장으로 요약(예: 일방적 의존→대등한 거절) |
| 변화 경로 | N절:상태 A → M절:상태 B. 촉발 사건 표시 |
| 감정 기여 | 감정선에 미치는 기여 |

추출 전략:
- 직접 상호작용하거나 명시적 감정 묘사가 있는 쌍만 추출한다.
- 같은 쌍은 최종 상태를 남기고 과거 변화는 변화 경로에 쓴다.
- 관계 전환의 정확한 위치와 촉발 원인에 주목한다.

#### B–C. 도입과 결말

아래 출력 템플릿의 ‘B. 도입 분석’, ‘C. 결말 분석’을 따른다. 두 곳의 강도는 모두 세기만 보는 1-10 절대 척도이며 감정 곡선의 -9~+9를 쓰지 않는다.

#### D. 수미상관

도입과 결말의 요소가 호응하는 방식을 비교한다. 표는 출력 템플릿의 ‘D. 수미상관 분석’을 참조한다.

**재독에서 발견하는 점**: 도입의 어떤 말은 처음 읽을 때와 진실을 안 뒤 다시 볼 때 뜻이 완전히 달라진다. 어떤 문장이 그러하며 진실 공개 뒤 어떻게 의미가 바뀌는지 표시한다.

#### E. 훅 회수 점검

전체에 심은 훅과 회수 상태를 모두 나열한다(출력 템플릿 ‘E. 훅 회수 점검’ 참조). 미회수 훅에는 ‘여백’ 또는 ‘누락’을 표시한다.

### Stage 6: 종합 평가 보고서

모든 단계 데이터를 종합해 평가 보고서를 출력한다.
- 이야기 핵심 평가, 다섯 항목 점수(도입 흡인력·감정 견인력·반전 설계·리듬 조절·결말 여운), 폭발력+화제성, 공감 층위, 주 구조(analysis-short-patterns.md와 대조), 투고 측면(analysis-submission.md와 대조), 재사용 구조(각 적용 상황·실패 조건·그대로 옮길 수 없는 점, 실제 개수)를 쓴다. 원문의 약점을 판단할 때는 해당 구간을 더한다. 템플릿은 아래 ‘종합 평가’ 참조.

> **달콤한 로맨스/코미디의 대체 항목**: 주로 달콤한 사랑·코미디·반전 매력을 제공하고 전통적인 반전이 없으면 ‘반전 설계’를 ‘반전 매력의 밀도’로, ‘감정 견인력’을 ‘달콤함 곡선’으로 대체할 수 있다. 반전이 없다는 이유만으로 감점하지 않는다.

## 작법 기법 분석

### POV 전략

| POV 유형 | 효과 | 적합한 감정/서사 |
|----------|------|----------|
| 1인칭 | 강한 친밀감·몰입감, 정보 조절 가능 | 고통스러운 사랑·성찰·내면극 |
| 제한적 3인칭 | 몰입과 관찰 거리의 균형 | 일반 |
| 전지적 3인칭 | 전지적 시야·여러 서사 동시 진행 | 군상·미스터리 |
| 2인칭 | 극도의 몰입 | 실험적 서사·심리 공포 |
| 비인간 시점 | 새로움·낯설게 하기 | 시스템/귀신/동물 시점 |

분석 요점:
- 이 POV를 선택한 이점과 대가.
- 시점 안의 정보 조절이 있는가(불신할 화자 등).
- 시점 전환이 있다면 그 시점과 효과.
- **대리인 문제**: 영혼·혼수상태의 관찰처럼 시점 인물이 전개를 직접 추진할 수 없으면 행동할 ‘살아 있는 대리인’이 필요하다. 등장 시점과 행동력이 전개의 설득력에 직접 영향을 준다.

### 대화 기법

| 지표 | 계산 방식 | 설명 |
|------|----------|------|
| 대화 비중 | 대화 글자 수 / 전체 글자 수 | 텍스트를 설명하고 같은 소재·플랫폼 표본과 비교. 보편 합격선으로 삼지 않음 |
| 함축 의미 비율 | 함축을 담은 대화 수 / 전체 대화 수 | 인물의 회피·정보 조절을 설명. 통보·구조 요청·규칙 설정에서는 직설도 성립하므로 높을수록 좋다고 보지 않음 |
| 심판형 대화 | 주인공 질문→상대의 자백 횟수 | 선택 강요·모순 노출·관계 변화 여부를 기록하며 최소 횟수 없음 |
| 정보 격차 대화 | 독자는 알고 인물은 모르는 대화 | 고통 중심 서사/반전물의 핵심 |

**대화 유형 판별**:
- 심판형: 주인공의 질문 → 상대가 강제로 속내를 드러냄.
- 압박형: 짧고 강경한 대사로 계속 몰아붙임 → 상대의 격앙. 선을 넘는 대사는 흔히 ‘사실 진술 → 조언 추가 → 비난 → 비난과 명령 → 상대를 낮추고 자신을 높이는 비난’으로 고조된다. 예의·침묵·절제도 강한 압박이 될 수 있으므로 현장 권력과 함께 판단한다.
- 정보 격차형: 양측의 정보가 비대칭이고 독자가 그 사이에 놓임.
- 밀고 당기기형: 가까워졌다 밀어내기를 반복.
- 호칭 변화 추적: 같은 사람을 인물마다 다르게 부른다(‘아후’와 ‘린촨’ 등). 호칭 변화는 관계와 정체성 인식의 변화를 반영한다. 경로를 추적하고 촉발 사건을 표시한다.

### 시간 조절

| 기법 | 정의 | 판별 특징 |
|------|------|----------|
| 시간 도약 | 일정 기간을 건너뜀 | ‘3년 뒤’, ‘5년 뒤’ |
| 장면 압축 | 긴 시간을 몇 문장으로 요약 | 개괄 단락 |
| 교차 편집 | 두 시간선을 번갈아 제시 | A/B 서사 교대 |
| 역순 서술 | 결과를 먼저 말하고 과정 설명 | 결과 선행, 원인 회고 |
| 플래시백 | 회상 조각 삽입 | 과거 장면의 갑작스러운 삽입 |
| 실시간 전개 | 핵심 순간을 초 단위로 펼침 | 핵심 장면의 느린 동작 |

### 정보 조절

도입·반전 전·반전 후(또는 중간·결말)에 독자·주인공·상대가 각각 아는 것과 정보 격차를 비교한다. 표는 출력 템플릿의 ‘정보 조절’ 참조.

### 심상/물건 추적

표는 출력 템플릿의 ‘심상/물건 추적’ 참조. **주제 심상군**: 여러 물건·심상이 같은 주제를 가리키면 따로 분석하지 말고 연결을 판별한다. 예를 들어 권투 장갑(정체성의 어긋남)+문신(강제 표식)+창고(정신적 감금)는 모두 ‘정체성의 감금’을 가리킨다. 공통 주제, 각 물건의 관점, 전체 효과를 표시한다.

### 여백 기법

의도적으로 비워 둔 내용을 찾는다.
- 생략한 배경: 독자의 상상에 맡김.
- 입 밖에 내지 않은 말: 대화의 멈춤/말줄임표.
- 건너뛴 과정: 결과만 바로 제시.
- 여백 있는 결말: 이후를 설명하지 않음.

## 공감 분석

### 공감 층위 7개

| 층위 | 정의 | 분석 요점 |
|------|------|----------|
| 정서적 공감 | 인물의 현재 감정에 즉각 공감(안타까움·분노 등) | 공감 지점 |
| 가치관 공감 | 작품의 구체적 가치에 동의(‘여성을 함부로 규정해서는 안 된다’ 등) | 전달하는 가치관 |
| 경험 공감 | 독자 경험과의 유사성 | 대입하기 쉬운 경험 |
| 사회 현상 공감 | 사회적 화제/보편 현상과의 연결 | 반영하는 사회 현상 |
| 보편 가치 공감 | 자유·존엄·사랑 등 인류 공동 추구에 대한 넓은 동의 | 보편 주제 |
| 정서적 깊이의 공감 | 읽고 며칠 뒤에도 떠오르는 지속적 영향 | 감정의 깊이와 지속성 |
| 인물 깊이의 공감 | 인물의 복잡성을 이해하고 공감 | 인물의 깊이 |

각 층위에 강함/중간/약함/없음과 촉발 증거를 붙인다. 최소 3개 층위를 분석한다. 독자 피드백이 없으면 강도는 분석적 판단이므로 실제 확산 효과를 단정할 수 없다.

> **혼동하기 쉬운 구분**: 정서적 공감은 현재 감정에 대한 즉각적 공감, 정서적 깊이의 공감은 며칠 뒤에도 떠오르는 지속적 영향이다. 가치관 공감은 작품의 구체적 가치에 대한 동의, 보편 가치 공감은 자유·존엄·사랑 등 인류 공동의 추구에 대한 넓은 동의다.
