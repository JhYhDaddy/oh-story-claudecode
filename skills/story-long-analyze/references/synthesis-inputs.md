# Stage 3–5: 자료 추출과 사실 보존

Stage 3·4·5의 각 단계에서 읽습니다.

## 자료 추출

읽기 전용 `digest`로 장간 관찰·장별 필드를 필요한 만큼 뽑아 캐시의 장 본문을 반복해서 읽지 않습니다. 출력은 Markdown입니다.

```text
"{PYTHON}" "{story-long-analyze skill 根}/scripts/manage_analysis_run.py" digest --root "{拆文目录}" --part observations [--chapters 1-60]
"{PYTHON}" "{story-long-analyze skill 根}/scripts/manage_analysis_run.py" digest --root "{拆文目录}" --part chapters --chapters 1-60 --fields 三维节奏,涉及,状态变化 --points brief
```

- `observations`: 반영 완료 묶음의 장간 관찰을 장순으로 집계합니다. 사건 지점·핵심 사건과 공개 후보·관계 변화·3축 고저·묶음 간 상태를 포함하며 Stage 3–4의 주 자료입니다.
- `chapters`: 장별 요약에서 概要·关键事件·因果·局面结果·涉及·信息变化·状态变化·三维节奏·章尾钩子·证据 필드를 추출합니다. `--points brief`는 항목별 「标题｜类型｜基调」, `full`은 담백한 사실 묘사도 포함합니다.
- 전체가 한 맥락에 안 들어가면 `--chapters`로 창을 나눠 추출·그룹 병합합니다. 창 사이에는 줄거리 상태·핵심 후보·근거 참조만 넘기고 내용을 확장하지 않습니다. 핵심 근거가 충돌할 때만 `장별분석/제N장_요약.md` 한 장을 지정 Read하며 추가 확인은 최대 한 번입니다.
- 옛 프로젝트에 묶음 캐시가 없으면 기존 줄거리·리듬·감정·관계·장별 자료를 직접 재사용합니다. 형식 통일을 위해 옛 요약을 먼저 재압축하지 않습니다. 근거 부족·충돌은 모름·확인 필요로 표시합니다.
- Stage 3–5는 원문을 다시 읽지 않으며 같은 원문 묶음을 각각 읽지도 않습니다. Stage 6는 색인으로 문체 기준점 4–6구간을 지정 조회할 수 있지만 원문 전체를 다시 훑으면 안 됩니다.

## 근거 등급

줄거리 단위·리듬·감정 모듈·관계 등 기초 파일의 추론은 다음 세 등급입니다. 표식은 원문 유지합니다.

- `A 明确`: 입력 자료가 직접 제시.
- `B 强推断`: 여러 명확한 세부가 함께 뒷받침.
- `C 暂定`: 근거가 부족해 확인 대상으로만 유지.

작가 보고에서는 문자를 쓰지 않고 author-facing의 근거 강도 설명 규칙에 따라 쉽게 전달합니다.

## 단계 표시

Stage 3–5는 각각 한 번 실행하고 실패하면 부족한 부분만 재시도합니다. 파일 저장 성공 후 표시합니다.

```text
"{PYTHON}" "{story-long-analyze skill 根}/scripts/manage_analysis_run.py" mark-stage \
  --root "{拆文目录}" --stage stage3 --output "플롯/리듬.md"
```

`mark-stage`는 약속한 산출물이 존재하고 비어 있지 않은지만 확인합니다. Stage 3는 감정 모듈·리듬 둘 다 필요하며 위 `--output`을 사용합니다. Stage 4는 인물 카드 최소 하나(`인물관계.md` 제외)와 설정 하나, Stage 5는 보고서가 필요합니다. 의미 품질은 여전히 각 단계 규칙으로 검사합니다. Stage 1–2는 pipeline-ops.md, Stage 6는 style-profile-generator.md 참조.

## 종합 단계의 사실 보존(Stage 3-5: 줄거리·설정·인물·보고)

기존 사실을 재사용하며 상식으로 자료에 없는 정보를 채우면 안 됩니다. 예를 들어 두 계열 마법사의 두 번째 계열, 탈것·기수의 등급, 인물의 실제 등장 장은 각각 근거가 필요합니다.

1. **확정 사실은 출처 추적 가능해야 함**: 힘의 등급·수치·거리·속성·세력 수·발화자와 상대·등장 장은 먼저 묶음 근거나 기존 사실의 장·위치를 확인합니다. 찾지 못하면 ‘자료에 명시되지 않음’으로 바꾸거나 삭제하며 종합을 위해 원문을 두 번째로 읽지 않습니다.
2. **출처에 따라 누락 표시, 창작 금지**: 없는 필드는 출처에 맞춰 「原文未明确/节选未涉及/旧资料未提供」(원문 불명확/발췌에 없음/옛 자료에 없음)라고 씁니다. 유사 항목·다른 곳의 예시·관행으로 그럴듯한 값을 채우지 않습니다.
3. **다른 대상을 혼동하지 않음**: 이웃한 대상의 속성을 서로 가져오지 않습니다. 탈것 등급≠기수 등급, A 대사≠B 대사, 이번 장 수치≠옆 장 수치입니다.

저장 후 **사실 출처 자체 점검**을 한 번 합니다. 설정·인물·보고의 확정 사실을 표본 확인해 이번에 허용된 근거 출처에 하나씩 대조합니다. 원문 묶음은 저장된 사실·원문 구절·`source_locator`, 옛 결과 묶음은 계획에 명시된 옛 파일만 확인합니다. 옛 자료에 없는 세부는 「旧资料未提供」로 바꾸거나 삭제하며 확인을 핑계로 이미 분석한 원문을 다시 읽지 않습니다. 이 점검은 Stage 3 품질 임계값과 별개입니다. 임계값은 분류 품질, 이 검사는 사실의 진위를 확인합니다.
