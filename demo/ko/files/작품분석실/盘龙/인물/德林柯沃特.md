# 데린 코워트

**archetype**: supporting(조연)
**등장**: 약 26%(제18–23장)

<a id="档案"></a>

## 인물 기록

오천여 년 전 멸망한 푸앙 제국의 대지 계열 성역 마도사. 린레이의 판룡 반지(자신은 대지의 반지라 부름)에 잠든 영혼이다. 생전 가장 위대한 대지 계열 성역 마도사라 자부했고 자녀가 없었다.

경력: 위란력 4280년 숙적 성역 마도사 함린과 싸우다 다른 성역 강자의 기습으로 패해 죽었다. 함린의 영혼 고문을 피하려 죽은 뒤 정신력이 실체를 유지할 때 기운 없는 신기급 반지에 자신을 봉인해 오천여 년 숨었다(제18–19장). 린레이의 머리 피로 새 주인이 생겨 나와 달빛 흰 로브의 인자한 노인으로 아이를 깨운다(제18장). 과거·주인 인정을 설명하며 반지에서 3미터를 못 벗어나고 영혼 소멸만이 해방이라고 한다. 할아버지라는 호칭에 고독이 녹아 전수를 수락한다(제19장). 영혼은 주인·성역 강자만 감지하고 주종 마음 대화가 가능하다고 설명(제20장). 계열들은 비슷하지만 환경이 우열을 정해 지상에서는 대지가 유리하다고 자랑(제21장). 마력·정신력 원리와 주문 의존 오해를 고치고 7급~성역 전수를 약속(제22장). 친화력 천 명 중 하나·정신력 또래 열 배인 중간 수준을 확인해 8급까지 가르칠 자신을 보이고 어린 그림자 쥐를 알아본다(제23장).

성격: 인자하지만 가르치기를 좋아하고 대지 마법에 자부심이 지나쳐 의심받으면 불쾌해한다. 수천 년 외로움 뒤 계승·가족 정을 원한다. 능력: 7급~성역 대지 마법·각 계열 금기 일화, 영혼으로 주인 정신력 감지·원소 농도 조절 검사. 관계: 린레이의 마법 스승·반지 속 의지하는 할아버지, 린레이만 아는 비밀.

## character_arc

패배 후 수천 년 잠든 영혼이 피로 주인 인정되어 다시 나와 할아버지 호칭으로 가르치는 기쁨을 되찾는다. 잊힌 망령에서 운명의 스승으로 바뀌고 고독을 가족애·사제 정이 채운다.

<a id="关键情节时序"></a>

## 주요 사건(시간순)

1. **제18장**: 반지 빛이 커지고 노인 형상의 영혼이 나와 린레이를 깨움.
2. **제19장**: 4280년 기습·봉인, 3미터 제약·소멸만이 해방임을 설명하고 할아버지 호칭 뒤 전수 수락.
3. **제20장**: 주인·성역 강자만 볼 수 있음을 설명하고 마음 대화 확립.
4. **제22장**: 주문 의존 오해 수정·마력/정신력 설명·성역까지 전수 약속.
5. **제23장**: 친화력 천 명 중 하나·정신력 열 배 확인, 8급까지 교육 약속.
