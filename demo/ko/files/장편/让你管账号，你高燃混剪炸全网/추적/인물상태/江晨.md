# 장천｜현재 상태

- 상태 개정: 1
- 기준 장: 제21장
- 신분: 로켓군 문예단 홍보병, 군 홍보 최정상 창작자
- 위치: 로켓군 문예단 사무실
- 현재 목표: 14일 안에 공개행사 이별 주제 작품을 만들되 먼저 탄서우이를 찾아 이야기를 끝까지 듣고 작사하기
- 심신 상태: 〈소원대로〉 1억 돌파의 열기가 남은 가운데 과제 3과 상급자의 지명을 받아 압박과 창작욕이 함께 높아짐

<a id="能力与资源"></a>

## 능력과 자원
- 전생의 MCN 인기 콘텐츠 운영 경험
- 최정상 가수급 가창력과 목소리
- 거장급 연출 능력
- 전문가급 피아노 연주(연습실에서 처음 선보임)
- 〈이별이 꽃을 피우다〉 반주(가사 미작성)
- 시스템 현금 보상 약 40만 위안

<a id="关键关系"></a>

## 주요 관계
- 중자자와 썸이 깊어지고 새 노래에 관한 약속이 생김
- 장야오쭈가 처음 직접 속사정을 밝히고 권한을 주며 저우보썬은 편들어 보호함
- 탄서우이를 다음 날 방문하기로 약속함

<a id="已知信息"></a>

## 알고 있는 정보
- 공개행사는 14일 뒤이며 문예단이 홍보 영상과 현장 공연 하나를 맡음
- 자료는 준비팀 심사 목록 절차를 거쳐야 함
- 탄서우이는 약 200킬로미터 떨어진 이웃 도시 퇴직 간부 요양소 가족 사택에 거주

<a id="未结事项"></a>

## 미결 사항
- 과제 3 남은 시간 13일 남짓
- 탄서우이 이야기는 아직 듣지 못함
- 중자자의 절반만 맞혔다는 말은 아직 설명되지 않음
- 중자자와의 감정은 아직 명시적으로 말하지 않음
- 우웨이 기소 결과는 미확정
