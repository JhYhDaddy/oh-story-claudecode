# 장르 문체 묶음: 두 남자 주인공 / 운명적 유대

> 즈후 옌옌의 특징적인 대분류. 먼저 `short-craft.md`의 공통 토대를 읽고, 이 묶음의 장르 고유 분위기를 우선 적용한다.
> 한 문장 정의: **두 남자의 유대와 갈등. 숙적 / 지기 / 구원 / 미안한 빚으로 관계를 움직이며 강렬한 감정을 형제애, 운명감, 소유욕에 담는다.** 독자가 원하는 것은 「차가움과 뜨거움의 온도 차 충돌」+「말로는 적대하지만 속으로는 목숨까지 내주는」 엇갈림의 쾌감이다.

---

## 서술 말투

1인칭이 주도하며 「나」는 흔히 **관계에서 능동적이고 강하거나 소유하는 쪽**이다. 동생을 곁에서 키운 형, 상대를 개처럼 가지고 노는 회귀자, 냉담하게 의무를 이행하는 계약 남편. 다른 쪽의 뜨거움과 비굴함은 대화와 행동으로 대비한다.

말투의 바탕은 **말과 마음의 불일치**다. 생각과 말이 반대이며 말은 독하지만 마음은 쓰인다. 독한 내적 불평(「선저우가 이능력을 안 쓰는 건, 아마 머리가 이상해서겠지」)과 차가운 서술(「그의 죽음에 나는 별 감정이 없었다」)이 흔하다. 입을 열 때 동성 간 유대의 호칭을 기준점으로 삼는다. 「우리 형」「의붓동생」「앙숙」「숙적」「암위 십칠」.

**두 시점 / 짝사랑 인식 차이의 삽입 회상**을 허용한다. 「나」의 서술에 상대의 숨은 헌신(몰래 적은 공책, 능력을 무리해 만든 우연, 보내지 못한 편지)을 끼워 독자가 「나」보다 먼저 사랑의 깊이를 알게 한다. 장르의 주된 동력이며 전지적 작가 말투가 아니다.

## 도입 유형

마찬가지로 **결과부터 거꾸로 제시하는 도입문**을 쓰지만 배신 전모 대신 **엇갈린 관계의 비장의 패**를 미리 밝힌다. 누가 짝사랑하고, 누가 누구에게 빚졌고, 누가 누구를 파괴할지, 뒤늦은 후회를 예고한다. 1소절은 도입문이 멈춘 곳을 바로 잇거나 되돌아가 엇갈림을 구체적 장면에 담는다. 글자 수는 `설정.md`의 「平台基调」를 따른다.

| 도입 방식 | 실제 사례의 번역 |
|--------|----------|
| 사망 소식 회고 + 이해 못 함 | 《흐린 날도 행복하게》 셰수위는 나와 결혼한 지 3년째에 죽었다. 자살이었다. |
| 싸움으로 적대 확립 + 숨은 흐름 | 《앙숙이 나를 짝사랑한다》 나와 선저우는 앙숙이다. 종말 전부터 날을 세우며 복잡하게 얽혔다. |
| 소유 선언(형 / 의붓동생) | 《나와 우리 형》 나는 형이 싫다. 몸으로 더러운 돈을 버는 형이 싫다. |
| 계약의 족쇄 | 《그물에 걸리다》 선쩌, 3년 뒤 떠나고 싶으면 보내 줄게. 하지만 3년 뒤에야 알았다. 그는 처음부터 나를 보낼 생각이 없었다. |
| 회귀 / 책 속 빙의로 죽음 예지 | 《쌍생의 겁》 장군부 외아들로 태어난 나는 피가 섞이지 않은 형이 장차 내 말 한마디에 황성 사람들을 몰살할 것을 알았다. |
| 엉뚱한 대비 훅 | 《미친 황제와 성실한 암위》 황제가 암위를 뽑았다. 은 50냥, 숙식 제공. 그런데 지급된 장비는 투명한 얇은 옷과 수정 가슴 체인이었다. |
| 빚진 관계 회고 + 진단 뒤 반격 | 《버려진 장난감》 셰한저우는 수도에서 가장 범접하기 어려운 사람이었다. 나는 그가 곁에 둔 의붓동생이었다. 하지만 확진받은 날 그의 눈앞에서 낯선 남자를 집에 데려왔다. |

## 훅 모티프와 밀도

밀도가 높으며 **점점 떼어 놓기 어려워지는 관계**를 따라 심화한다. 대치→강제 동거→서로 진 빚→아무도 떠날 수 없음. 여러 서사 단위에서 온도 차, 인식 차이, 선택, 관계 결과가 모두 없으면 정체를 점검한다. 소절마다 실적을 채우려 설렘이나 폭로를 넣지 않는다.

- **짝사랑 인식 차이**(최우선 모티프): 겉으로 미움/싸움/냉담, 속으로 한쪽의 비밀 사랑. 들키는 순간이 최대 쾌감이다.
- **계약 / 빚 / 혼인으로 강제 결속**: 조수 계약, 차용증, 정략결혼, 암위 계약으로 헤어져야 할 두 사람을 묶고 벗어날 수 없는 동행을 만든다.
- **구원과 구원받음**: 한쪽이 더러운 돈, 자멸, 광기, 종말 속 능력 과용에 빠져 있고 다른 쪽이 손을 내민다. 함께하며 자신도 구원받을 수 있다.
- **미안한 빚의 반전(후회하며 재회를 구하는 변형)**: 도구 취급/무시/배신당한 쪽이 단호히 떠난다(아빠 없이 아이만 키우기, 재산 챙기기, 다른 사람과 결혼). 무시하던 쪽은 비굴하게 후회한다.
- **운명 예지**: 회귀/책 속 빙의로 상대의 미래 자살/흑화/자신의 파멸을 알고 운명을 바꾼다.
- **정체 대비의 정면충돌**: 범접 못 할 사람×매달리는 의붓동생, 황제×성실한 암위, 장군×늑대 같은 형, 두 알파 / 두 강자의 대등한 충돌.
- **신표 / 기록에 무게 싣기**: 몰래 쓴 공책, 보내지 못한 편지, 유일한 함께 찍은 사진, 옅어지는 각인으로 말 못 한 감정을 물건에 담는다.

## 감정 강도와 방식(강도 8)

**두 갈래의 온도 차**로 쓴다. 한쪽은 냉정·까칠·절제·말과 마음의 불일치, 다른 쪽은 뜨거움·비굴함·집착·전부 내던짐. 대비와 응답이 감정을 밀며 흔히 HE(행복한 결말)/구원으로 끝낸다.

- **차가운 갈래**: 「아무 감정 없다 / 신경 안 쓴다 / 귀찮을 뿐」을 직접 쓴다. 평탄할수록 뒤의 고통을 부각한다. 《흐린 날도 행복하게》 그의 죽음에 나는 별 감정이 없었다.
- **뜨거운 갈래**: 비굴함·집착·후회의 뜨거운 말을 독립 문단으로 강타한다. 《젠장, 네게 걸려 버렸네》 형, 잘못했어. 나 버리지 마.
- **차가움 속의 어색함**: 생각과 말이 반대이며 말이 독할수록 신경 쓰는 마음을 숨긴다(《앙숙이 나를 짝사랑한다》에서 매번 선저우를 도발하는 모습).
- **대비의 통증**: 차가운 서술과 뜨거운 디테일 하나를 병치한다. 평평한 말투로 무거운 내용을 받친다. 《흐린 날도 행복하게》 평범한 업무처럼 처리했다. 냉정하게 영정사진과 묏자리를 골랐다.

실제 사례의 번역:

- 《앙숙이 나를 짝사랑한다》 선저우가 말한 모든 우연은 이능력을 무리해서 쓴 결과였다는 것도 몰랐다.
- 《쌍생의 겁》 의식을 잃은 그는 내 손목을 꽉 쥐고 중얼거렸다. 더… 더 크게 욕해 줘…
- 《그대와 아침을》 그가 남긴 것은 수없이 많은 보내지 못한 편지뿐이었다. 편지마다 내게 말하지 못한 감정이 가득했다.

## 대화 문체와 실제 명대사

대화는 비교적 촘촘하며 까칠함, 집착, 계약상 입장을 드러낸다. 핵심 문장은 독립 문단으로 둔다. 흔한 대사 세 종류:

**① 까칠하고 공격적인 상대의 말(표면적 적대)**
- 보기 좋아? 이 변태!
- 걔가 있다고 하면 믿어? 내가 걔를 모르냐. 맨날 계집애처럼 굴고 남자답지도 못해서 누가 건드리기만 해도 울잖아.
- 멍청아! 창술 연습할 땐 기마자세를 해야지!

**② 비굴하고 집착하는 뜨거움(매달림 / 병적인 애착 / 후회)**
- 형, 잘못했어. 나 버리지 마. 누구 애야? 내가 아빠가 되면 안 돼?
- 사랑해. 너 없이는 안 돼.
- 자기야, 내 곁에 있어. 돈은 얼마든 줄게. 뭘 입으라든 입을게. 어디든 밟아도 돼.
- 더… 더 크게 욕해 줘…

**③ 계약 / 입장의 말(운명의 족쇄)**
- 선쩌, 3년 뒤 떠나고 싶으면 보내 줄게.
- 좋아. 대신 차용증 써.
- 얼마든 괜찮아. 원하는 액수를 말해. 다 줄게.

갈등은 **둘의 온도 차**로 관계 변화를 보여 준다. 초반엔 한쪽이 길게 도발하고 다른 쪽은 냉담하게 무시한다. 후반엔 차가운 쪽의 방어가 깨지고 까칠하던 쪽이 비굴해진다. 먼저 굽히는 사람이 마음을 드러낸다.

## 리듬 뼈대

```
도입문(결과 역순 + 짝사랑/빚/운명의 관계 비밀 예고)
→ 1소절은 도입 끝을 잇거나 돌아가 싸움/계약/소유 장면으로 적대와 숨은 흐름 형성
→ 관계의 잠금장치 강화(강제 동행/계약/운명의 족쇄)
→ 온도 차의 반복 충돌(까칠함 vs 뜨거움, 엇갈림 압박)
→ 인식 차이/숨은 사정 폭로(공책/능력 과용/못 보낸 편지)
→ 위기 또는 빚의 폭발(죽음 감수/배신/무시/흑화)
→ 쌍방 사랑 또는 후회하며 매달림
→ HE 마무리(운명과 화해/구원의 완결)
```

관계 연쇄를 따라 새 엇갈림과 폭로를 계속 실현한다. 소절 끝은 엇갈림, 부분적 확인, 관계 변화, 명확한 다음 단계에 둘 수 있으며 매번 같은 훅을 요구하지 않는다. 온도 차 충돌, 인식 차이 폭로, 위기 폭발은 자세히 느리게 쓰고 동행 일상은 관계 변화 가치로 취사선택한다.

## 마무리 유형

- **쌍방 사랑**: 까칠한 쪽이 마침내 인정하고 차가운 갈래의 방어가 깨져 온도 차가 0이 된다.
- **구원 완결**: 한쪽이 다른 쪽을 심연에서 끌어내고 「서로 빚 없음」에서 「서로 의지함」으로 간다.
- **후회하며 매달림(빚진 관계 하위 유형)**: 무시하던 쪽이 비굴하게 되찾으려 하고 버림받은 쪽은 차갑게 거절하거나 조건부로 돌아온다.
- **운명 다시 쓰기(회귀 / 책 속 빙의)**: 전생의 죽음을 바꾸며 이번에는 안 떠난다 / 죽으면 안 된다고 한다.
- 주류는 HE·화해·구원으로 마무리한다. 빚진 관계 유형은 아래 공식처럼 냉정한 거절도 가능하다.

줄거리 개요: 《다행히 우리는 늘 만나게 된다》 지쉰이 말없이 떠난 지 3년, 유일한 함께 찍은 사진이 재회를 이끈다. / 《그대와 아침을》 회귀해 샤오이가 버티다 죽는 결말을 바꾸고 곁에 가둬 말 못 한 감정을 보충한다.

## 장르 고유 조정(공통 AI 말투 제거 규칙과의 차이)

다른 맥락에서는 AI 말투나 과잉처럼 보여도 이 장르에서는 판매점이다. **잘못 지우지 않는다**.

- **두 시점 / 짝사랑 인식 차이 삽입**: 「나」의 서술에서 상대의 비밀 헌신을 예고하는 것을 남긴다. 공감의 주된 동력이며 전지적 작가 말투가 아니다. 비밀만 누설하고 계속 읽을 기대를 만들지 않는 무심한 전지성만 지운다.
- **말과 마음이 다른 츤데레 내적 독백**: 생각과 말의 반대를 남기며 일관된 표현으로 평탄화하지 않는다.
- **비굴함 / 집착 / 후회의 뜨거운 대사**: 매달리는 고백과 병적인 애착, 뒤늦은 후회의 고백을 과잉이라며 지우지 않는다.
- **계약 / 운명의 미래 예고**: 「3년 뒤 / 나중에 그는 후회했다 / 장차 그가 나를 파괴한다」로 의도적으로 기대를 끄는 것을 남긴다.

피할 진짜 AI 말투: 눈앞에 들어왔다, 속으로 생각했다, 낮은 목소리로 말했다, 입꼬리가 살짝 올라갔다, 눈빛이 횃불 같았다, 논문식 연결어(쉽게 알 수 있듯 / 이로써 알 수 있다), 구체적 귀결 없는 공허한 감정 요약(한 줄기 슬픔이 마음에 밀려왔다).

> 예문은 원문의 문장부호를 유지한다. 본문에서는 `short-craft.md` 제8절에 따라 멈춤을 짧은 문장, 행동, 줄바꿈으로 표현한다.

## 함께 쓰는 구조 공식(분량에 따라 선택)

- **숙적의 짝사랑 / 쌍방 사랑형(8-11소절)**: 1-2소절 싸움으로 적대와 숨은 흐름 → 3-4소절 강제 동행/계약 → 5-6소절 인식 차이 폭로(한쪽의 비밀) → 7-8소절 죽음의 위기/방어가 깨진 고백 → 쌍방 사랑 HE. 시점은 하나나 둘 모두 가능하다. 온도 차가 동력이며 차가운 쪽의 방어가 늦게 깨질수록 좋다.
- **구원 / 현대 감정형**: 한쪽의 심연(더러운 돈/계약/자멸/종말 속 능력 과용) → 다른 쪽의 구원 → 전생/계약의 족쇄로 묶임 → 족쇄를 깨고 서로 의지함. 차가운 서술을 바탕으로 대비 디테일이 마음을 찌른다.
- **빚진 관계·후회하며 재회 추구형**: 무시/배신(의붓동생/연인을 도구 취급) → 확진/임신/마음을 접음 → 단호한 이탈(아이만 남김/재산 챙김/다른 사람과 결혼) → 무시한 쪽의 비굴한 재회 추구 → 냉정한 거절 또는 조건부 복귀. 상처의 급소를 정확히 겨냥하며 욕설만 늘어놓지 않는다.
- **고대 권모술수·두 강자형**: 제왕·장수·재상/형제 성장, 회귀나 책 속 빙의로 죽음 예지 → 운명 다시 쓰기 → 가둠/구함/입맞춤 → 강산과 사람 모두 원함. 권모술수와 감정선이 서로의 협상 카드다.
