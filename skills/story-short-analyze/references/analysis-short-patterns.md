# 단편 원문의 구조 패턴 기준

> 원문과 대조해 압박·정보·관계를 어떻게 진행하고 결산하는지 관찰한다. 패턴은 실제 구조를 비교하는 데 사용하며, 장 위치·비율·단서 수는 원문대로 기록한다.

## 판별 원칙

먼저 원문의 실제 기능에 따라 구간을 나누고 어느 패턴에 가까운지 판단한다. 패턴이 성립하려면 선행 조건, 독자의 판단이나 감정을 바꾸는 전환, 전환 이후 행동이나 관계의 결과라는 세 종류의 증거가 필요하다.

## 흔한 패턴

| 패턴 | 관찰 가능한 기능 연결 | 성립 증거 | 흔한 실패 |
|---|---|---|---|
| 압박 형성—반격—결산 | 부당함 구체화 → 주인공이 행동 조건 획득 → 책임자에게 결과 귀속 | 압박·능동적 선택·결산이 같은 인과 사슬에 속함 | 외부 조력자가 반격을 대신하고 주인공은 구경만 함 |
| 이상—증거 수집—판단 수정 | 작은 이상 등장 → 여러 해석 경쟁 → 새 증거가 책임 판단을 바꿈 | 증거마다 다음 행동을 바꿈 | 단서는 분위기만 더하고 진술로 진실을 보충 |
| 단계적 답—재검토—최종 결론 | 믿을 만한 답이 잠시 성립 → 그 답에 따라 새 행동 → 재검토로 해석은 뒤집되 사실은 보존 | 다음 층위가 앞선 층위를 믿을 만했던 이유를 설명 | 진술만 연속 번복하고 중간 행동의 결과가 없음 |
| 동맹—의존—재평가 | 관계가 자원·안전감 제공 → 도움 속 균열 → 주인공이 관계를 다시 판단 | 초기 행동이 진실 공개 뒤 새 의미를 얻음 | 동맹이 결말에서 갑자기 입장을 바꿈 |
| 전생 정보—다른 선택—새 대가 | 옛 정보로 현재 선택 변화 → 이점이 미지의 역작용 초래 → 새 인생 결산 | 현생의 핵심 인과가 실제로 다름 | 전생만 되풀이하고 현생도 같은 길을 감 |
| 악행—대응 반격—보이는 결과 | 각 피해의 책임 확정 → 관련 증거·자원으로 반격 → 악행에 호응하는 결과 | 응보가 우연이 아니며 인물 선택으로 촉발됨 | 참상과 최후만 나열하고 인과 연결이 없음 |
| 규칙—검증—대가 | 이상 규칙 관찰 → 인물의 시험 또는 오판 → 제약·대가로 해법 변화 | 규칙의 경계가 앞뒤로 일관됨 | 임시로 새 능력을 추가해 당장의 곤경을 해결 |
| 능력 체험—증거 진전—능력 포기 | 특수 능력으로 부분 문제 해결 → 능력의 부족으로 현실의 대가 감당 → 마지막 선택으로 승리 정의 | 능력이 주 서사에 기여하되 최종 선택을 대신하지 못함 | 보상만 계속 커져 주 서사가 능력 설명서로 변함 |
| 관계 접근—장애—확인 | 상호작용으로 특별함 형성 → 내외부 장애로 관계 검증 → 선택으로 관계 규정 | 공동 경험과 선택에서 진전이 나옴 | 신체 접촉이나 오해만으로 기계적으로 관계를 진전 |
| 죽음/부재—다시 읽기—여파 | 부재로 정보 공백 형성 → 산 사람이 옛 행동 재해석 → 돌이킬 수 없는 사실로 관계 판단 변화 | 옛 세부를 되짚을 수 있고 결말이 상실을 감당함 | 유서 하나로 모든 진실을 설명 |
| 공개된 장—증거 귀속 변화—심판 | 사적 갈등을 공개 공간으로 옮김 → 증거 소지자·해석권 변화 → 사회적·관계적 결과 감당 | 공개가 구경에 그치지 않고 권력을 바꿈 | 군중 반응으로 사실 증명을 대신함 |
| 단일 목표—대가 상승—절제된 마무리 | 목표 유지 → 매 전진에 더 어려운 선택 요구 → 결말은 주된 미결 사항만 결산 | 대가가 목표에 직접 연결됨 | 후반에 더 큰 이야기를 열어 절정을 빼앗음 |

## 구조 관찰표

```markdown
실제 기능 구간: {개수를 미리 정하지 않고 원문대로 나열}
가장 가까운 패턴: {이름}
선행 조건의 증거: {위치}
핵심 전환의 증거: {위치}
행동/관계의 결과: {위치}
원문의 이탈: {어떤 기능을 더하고 빼고 재배치했는가}
이탈의 효과: {어떤 기대를 개선/약화했는지 증거와 함께}
```

## 흔한 패턴과 비교할 때

- 실제 단락과 절로 구조를 설명한다. 각 구간이 전체에서 차지하는 실제 비율은 보고할 수 있으나 권장 비율로 합격 여부를 판단하지 않는다.
- ‘더 이르다/늦다’는 원문의 단서가 충분한지, 공개 후 결과를 다룰 여유가 있는지를 기준으로 판단하며 고정 백분율을 기준으로 삼지 않는다.
- 단서 수는 관찰 결과만 기록한다. 공정성은 되짚어 확인할 수 있는지, 인물의 판단에 들어간 적이 있는지에 달려 있다.
- 여러 패턴이 혼합될 수 있다. 어떤 절정과 최종 결산을 주 패턴이 담당하는지 밝힌다.
- 재사용 가능한 구조에는 실패 조건도 붙인다. 원작의 구체적인 신분·물건·대사를 템플릿으로 복사하지 않는다.

## 금지되는 오용

- 장편의 권·무대·성장 단계·장기 도입 모델을 호출하지 않는다.
- ‘모든 장에 필수’, ‘고정 절 위치’, ‘고정 단서 수’를 원문 품질의 결론으로 쓰지 않는다.
- 사용자가 명시적으로 편집 제안을 요청하지 않으면 개요 수정안을 출력하지 않는다. 기본적으로 관찰·효과·실패 유형만 설명한다.
