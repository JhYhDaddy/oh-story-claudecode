# 장야오쭈｜현재 상태

- 상태 개정: 1
- 기준 장: 제21장
- 신분: 로켓군 문예단 단장
- 위치: 로켓군 문예단 본부
- 현재 목표: 공개행사로 문예단 홍보 성과를 높이고 상급자의 전략 의도를 이어받기
- 심신 상태: 처음 직접 장천에게 홍보 영상과 현장 공연을 맡기며 의심하다가 이별 주제를 승인함

<a id="能力与资源"></a>

## 능력과 자원
- 문예단 최고책임자의 의사결정권
- 치 지휘관 보고 및 공식 군 홍보 자원 조정 권한
- 상급자가 지명해 맡긴 공개행사 홍보 임무

<a id="关键关系"></a>

## 주요 관계
- 장천을 높이 평가해 직접 권한을 주고 중자자와의 협력을 물밑에서 추진함
- 저우보썬과 장천을 보호하는 관리 연대 형성
- 치 지휘관의 홍보 요구를 이어받음

<a id="已知信息"></a>

## 알고 있는 정보
- 상급자가 문예단에 공개행사 홍보 영상·현장 공연 하나를 맡기며 장천을 지명함
- 장천은 장비 과시 대신 이별을 행사 주제로 주장함

<a id="未结事项"></a>

## 미결 사항
- 더 윗선의 장천 육성·활용 계획은 아직 미공개
- 작품이 심사 목록을 통과하고 기한 안에 실현될지 여부
