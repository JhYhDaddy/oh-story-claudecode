# 중자자｜현재 상태

- 상태 개정: 1
- 기준 장: 제21장
- 신분: 군보 기자, 아직 완전히 공개되지 않은 군 인사 집안 배경
- 위치: 로켓군 문예단
- 현재 목표: 공개행사 보도를 따라가며 장천이 노병 이야기를 무게 있는 군 홍보물로 만들도록 계속 돕기
- 심신 상태: 행사 일정을 알리고 참석하겠다 함. 시범 연주 뒤 다 쓰면 알게 될 거라는 말을 수첩에 적음

<a id="能力与资源"></a>

## 능력과 자원
- 군보 지면과 취재 자원
- 군보가 확보한 공개행사 일정
- 노병 위문·취재 자료
- 할아버지가 제공하는 군 인맥

<a id="关键关系"></a>

## 주요 관계
- 장천과 장기 협력에서 썸으로 발전하며 새 노래 약속이 생김
- 할아버지는 장천을 인정하고 홍보 활동을 물밑에서 도움

<a id="已知信息"></a>

## 알고 있는 정보
- 장천의 두 차례 작품 모두 군 안팎에서 인정받음
- 장천은 피아노를 치며 새 노래 제목은 〈이별이 꽃을 피우다〉
- 군의 장천 육성에는 별도의 미공개 계획이 있음

<a id="未结事项"></a>

## 미결 사항
- 절반만 맞혔다는 말의 진짜 뜻은 아직 미공개
- 장천과의 감정은 아직 명시적으로 말하지 않음
- 할아버지가 약속한 더 큰 지원은 아직 완전히 실현되지 않음
