# 판체: 수집과 분석

먼저 `/browser-cdp`로 Chrome을 시작한다.

## 기본 명령

`--channel`은 Phase 1 채널에 따른다. 1=남성향, 0=여성향, all=둘 다 수집.

```bash
node scripts/fanqie-rank-scraper.js --channel all --type 2 --outdir {outdir}   # 남녀 채널 읽기 순위
```

작가가 신작 중 떠오르는 것을 보려면 신작 순위와 서고의 「最热」(최고 인기)를 추가한다.

```bash
node scripts/fanqie-rank-scraper.js --channel all --type 1 --outdir {outdir}             # 남녀 채널 신작 순위
node scripts/fanqie-rank-scraper.js --source library --channel all --outdir {outdir}     # 서고: 연재 중·30만 자 미만, 남녀 각 첫 3페이지
```

## 선택 매개변수

- 순위: `--type 2` 읽기 순위, `--type 1` 신작 순위, `--type all` 둘 다 수집. 스크립트는 장르별 상위 20권을 수집하며 `--top N`으로 조절한다. 채널마다 `番茄{频道}{榜单}_全题材_{日期}.md` 하나를 작성한다.
- 서고 「最热」: 페이지당 18권, 인기순. `--channel mix`는 남녀 구분 없이 수집한다. `--pages N`으로 페이지 수, `--stat 1|0|any`로 연재/완결/무관, `--count 0-4|any`로 30만 자 미만/30–50만/50–100만/100–200만/200만 이상/무관을 선택한다. 기본 필터(연재 중·30만 자 미만)일 때만 목록명에 「新书」가 붙고 신작 표본으로 집계한다.

## 필드와 인기 측정 기준

순위·제목·작가·장르·상태·현재 읽는 수(핵심 지표이며 집계의 인기 기준)·글자 수·태그(소개 첫머리의 `【种田+慢热+西幻】`처럼 세부 장르를 보여 주는 실제 신호)·최신 갱신·작품 페이지 링크·소개를 수집한다. 페이지에 평점은 없다.

**장르별 동일 수 표집**: 순위에서 장르마다 상위 20권을 가져오므로 장르 권수와 비율은 표집 상한의 영향을 받으며 장르 규모를 나타내지 않는다. 집계에도 이를 명시한다. 장르 인기는 인기 중앙값과 플랫폼 P75로, 새 흐름은 신작 순위와 서고 신작으로 본다.

## 수집되지 않을 때

파일 머리말 「数据质量」에 `[标题解析异常]`가 표시되고 제목이 주로 `（标题待解析）`라면 로그인·인증 페이지에 막혔거나 페이지가 개편되었을 가능성이 크다. 로그인된 Chrome에서 아무 `https://fanqienovel.com/page/{bookId}`를 직접 열어 정상 페이지이며 인증 페이지가 아닌지 확인한다. `CDP 无响应`이면 browser-cdp에 따라 Chrome을 재시작한다. 정상임을 확인한 뒤 다시 수집한다.

## 분석 차원

| 차원 | 확인할 내용 |
|---|---|
| 읽기 순위 | 유입과 독자 규모. 현재 읽는 수가 핵심 지표 |
| 신작 순위·서고 최고 인기 | 새 장르 표본을 읽기 순위와 대조. 같은 기준의 두 시점을 비교해야 증가세라고 말할 수 있음 |
| 장르 인기 | 장르별 인기 중앙값을 플랫폼 P75와 비교. 권수로 판단하지 않음 |
| 현재 읽는 수 격차 | 같은 장르 상위권과 중위권의 유입 차이 |
| 인기 태그 | 【】 안의 태그 조합으로 세부 매력 확인 |

## 플랫폼 독자

무료 읽기이며 독자층이 넓다. 빠른 리듬·강한 쾌감·분명한 목표와 인과를 원한다. 통쾌함은 상대의 콧대 꺾기·능력 과시·뜻밖의 기회 획득에 치우친다. 목표가 늦도록 불분명하거나 주인공이 오래 고통받거나 해설이 플롯을 압도하는 것은 기피 요인이다. 기발한 발상과 강한 감정의 장르가 많지만 획일화도 심하므로 소재를 정할 때 차별점을 명시한다.
