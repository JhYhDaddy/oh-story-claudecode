# 문체 정리 검사 범위와 실행 인터페이스

이 문서는 호출자의 범위·역할 분담을 이어받으며 별도의 수정법을 저장하지 않습니다. 표현은 [style-resolution.md](style-resolution.md)에 따라 판단하고 세부 판단 방법은 아래 세 파일에서만 관리합니다.

## 세 층위의 진입점

| 층위 | 읽을 자료 | 검사 대상 |
|---|---|---|
| 표현 | [expression.md](expression.md) | 어휘, 문장 형식, 목소리, 문장·문단 구성, 정형화된 반복 |
| 서술 | [narrative-focus.md](narrative-focus.md) | 상세함의 정도, 핵심 과정, 세부 기능, 감정 연결, 마무리 |
| 이야기 | [story-logic.md](story-logic.md) | 행동 근거, 인과, 인물 입장, 결과, 정보를 아는 순서 |

독립적인 문체 정리나 전체 문체 검토에서 범위가 제한되지 않았다면 세 층위를 모두 진단합니다. 각 층위에 문제가 없을 수도 있습니다. 호출자가 문제·문단·탐지 분류를 지정했다면 해당 범위에 필요한 방법만 검사하며 이를 구실로 전체를 다시 쓰지 않습니다. 장 끝 스크립트는 탐지 가능한 표현 문제만 알립니다. 탐지 0건을 근거로 나머지 두 층위가 정상이라고 추론할 수 없습니다.

## 탐지 분류나 문제로 범위 제한

탐지 분류를 전달받으면 expression.md 마지막 「스크립트 알림을 의미 판단에 연결하기」 색인에서 판단 대상과 넘길 층위를 찾습니다. 문제 이름을 받으면 아래 표를 따릅니다. 범위는 검사 대상만 정하며 경중 등급이나 작가의 줄거리 변경 허용 여부를 결정하지 않습니다.

| 문제 | 해당 방법 |
|---|---|
| 상투어, 문장 형식 | 표현 층위의 어휘·문장과 정형화 판단 |
| 감정 | 서술 층위의 심리 과정·삭제 시험, 표현 층위의 직접 서술·정형화된 반응 |
| 호흡 | 서술 층위의 상세함·반복·핵심 과정, 표현 층위의 문장·문단 구성 |
| 대화 | 서술 층위의 대립·인물 요구, 표현 층위의 목소리 |
| 마무리 | 서술 층위의 정보·약속 이행·여운, 표현 층위의 공허한 요약 |
| 설명과 작위성 | 표현 층위의 설명·서술자, 서술 층위의 정보 전달, 이야기 층위의 인과·지식 경계 |

분류가 불명확하면 표의 표현·서술 항목을 모두 검사합니다. 호출자가 전체 세 층위 진단을 요청하면 이야기 층위도 전부 검사합니다. 범위 밖의 뚜렷한 설계 빈틈은 따로 알릴 수 있지만 수정 범위를 임의로 넓히지 않습니다.

## 실행과 재검사

표현 방식의 표본 검사는 서술 층위의 장면 중심, 삭제·압축·확대 시험을 따릅니다. 질문마다 문제를 억지로 찾거나 고정 문장 길이·상세 서술 비율·최소 핵심 장면 분량으로 검수하지 않습니다. 일반 문체 정리와 줄거리 재작성의 실행 경계는 이야기 층위의 「진단 깊이와 실행 권한은 따로 결정하기」만 따릅니다.

검토 호출은 보고만 하고 파일을 바꾸지 않습니다. 수정 호출은 승인된 수정을 파일에 저장하고 미승인 설계안은 보고에 씁니다. 부모 절차가 최종 스크립트 검사를 맡으면 실행자는 의미 수정만 수행하고 실제 수정·보존·미해결 항목을 반환하며 문체 정리 전체를 반복하지 않습니다.
