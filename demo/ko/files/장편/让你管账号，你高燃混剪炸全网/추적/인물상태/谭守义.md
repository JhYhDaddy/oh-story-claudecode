# 탄서우이｜현재 상태

- 상태 개정: 1
- 기준 장: 제21장
- 신분: 78세 제대 노병, 옛 제2포병 고비 미사일 시험기지 복무
- 위치: 이웃 도시 퇴직 간부 요양소 가족 사택
- 현재 목표: 50년간 눌러 둔 이야기를 장천에게 끝까지 들려주기
- 심신 상태: 내일 온다는 답장을 받고 주소와 녹음 장비 지참 당부를 회신함

<a id="能力与资源"></a>

## 능력과 자원
- 고비 시절의 또렷한 기억
- 휴대전화 개인 메시지와 영상 시청 가능

<a id="关键关系"></a>

## 주요 관계
- 장천과 개인 메시지 초대에서 확실한 방문 약속으로 발전
