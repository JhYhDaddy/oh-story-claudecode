# 줄거리 디렉터리 색인

> 현재 계약(Stage 3+ 기준 산출물 완비). 이 디렉터리는 《판룡》도입 제1–23장 발췌를 바탕으로 하며 전체 작품의 결론을 대표하지 않는다.

| 파일 | 기준 자료의 범위 | 하위 단계 활용 |
|---|---|---|
| `节奏.md` | 핵심 정보 전개·쾌감 순환·감정 자극 지점·폭발 리듬 | `rhythm_reference` 생성 |
| `情绪模块.md` | 독자 욕구·감정 엔진·패턴 구조·재현 가능한 모듈 카드 | `selected_emotion_module` 생성 |
| `故事线.md` | 이야기 구조·줄거리 요약 | 기준 자료에서 뽑은 요약이며 기준 파일을 덮어쓰지 않음 |
| `拆文报告.md` | 사람이 읽는 보고서 | 기준 자료에서 뽑은 요약이며 기준 파일을 덮어쓰지 않음 |

충돌하면 `节奏.md` / `情绪模块.md`을 따른다. 두 기준 파일은 EM/RH/TR ID로 서로 참조한다.
