# 외부 비교 작품 연결(장편 가져오기)

장편 구조 이전 시 가져오기 기록에 외부 `{对标书名}`가 연결되어 있을 때만 읽습니다. `{对标书名}`는 작가가 따로 선택하고 독립 분석한 참고 작품이어야 하며 출처는 `작품분석실/{对标书名}/`로 고정합니다. `작품분석실/{导入书名}/`, 프로젝트 `설정/` 또는 이들에서 생성한 파일을 `비교작품/`로 복사하면 안 됩니다. `{导入书名}`를 비교 작품으로 등록해서도 안 됩니다.

## Step 1：登记对标

비교 작품을 등록합니다. `설정/소재방향.md`의 「题材框架」 앞에 아래 두 절을 추가하며 장편 집필의 포지셔닝 형식을 따릅니다. 주 비교 작품은 최대 1개, 보조·참고 작품은 수 제한이 없습니다. 모두 `작품분석실/{对标书名}/`로 출처를 추적할 수 있어야 합니다. 템플릿의 중국어 제목·필드는 후속 조회 표식입니다.

```markdown
## 对标分析（概要）
> 전체 비교 자료는 `비교작품/` 참조. 이 표는 빠른 개요이며 공식 등록은 다음 절을 따릅니다.

| 对标书 | 相似点 | 差异点 | 可借鉴 |
|--------|-------|-------|-------|
| {对标书名} | {유사점} | {차이점} | {참고할 점} |

## 对标登记
- 主对标书：{对标书名}
- 对标书列表：

| 书名 | 题材类型 | 引用强度{主/辅/参考} | 用途 |
|------|---------|--------------------|------|
| {对标书名} | {장르} | 主 | 문체+핵심 구조 |
```

## Step 2：同步资料

`작품분석실/{对标书名}/`의 구조화 자료를 프로젝트 `비교작품/{对标书名}/`로 동기화해 장편 집필에서 우선 읽게 합니다.

| 원본 경로 | 대상 경로 | 동기화 의미 |
|-------|---------|----------|
| `작품분석실/{对标书名}/플롯/리듬.md` | `{项目}/비교작품/{对标书名}/플롯/리듬.md` | 일일 연재의 `rhythm_reference` 선택에 필요한 권위 파일. 없으면 해당 작품 등록 안 함 |
| `작품분석실/{对标书名}/플롯/감정모듈.md` | `{项目}/비교작품/{对标书名}/플롯/감정모듈.md` | 일일 연재의 `selected_emotion_module` 선택에 필요한 권위 파일. 없으면 해당 작품 등록 안 함 |
| `작품분석실/{对标书名}/플롯/*.md` | `{项目}/비교작품/{对标书名}/플롯/*.md` | 줄거리 단위·이야기선·흩어진 사건 등의 자료. 권위 리듬·감정 파일과 충돌하면 후자를 따름 |
| `작품분석실/{对标书名}/장별분석/*.md`(제N장_요약.md + 도입 3장 제1-3장_심층분석.md) | `{项目}/비교작품/{对标书名}/장별분석/*.md` | 대응 장의 근거. 요약에서 개요·핵심 사건·상황 결과·관련 요소·상태 변화·사건 순서(유형·주제 태그·기조 포함)를 읽으며 도입 3장은 심층 작법도 포함 |
| `작품분석실/{对标书名}/인물/*.md` | `{项目}/비교작품/{对标书名}/인물/*.md` | 인물의 기능적 자리·관계·반응 층위 참고 |
| `작품분석실/{对标书名}/설정/` | `{项目}/비교작품/{对标书名}/설정/` | 세계관·세력·특전 능력 등 설정 제약 참고 |
| `작품분석실/{对标书名}/작품분석보고서.md` | `{项目}/비교작품/{对标书名}/작품분석보고서.md` | 사람이 빠르게 훑는 종합 보고 |
| `작품분석실/{对标书名}/문체.md` | `{项目}/비교작품/{对标书名}/문체.md` | 일일 연재 문체 조회 필독 |

- `플롯/리듬.md`·`플롯/감정모듈.md` 중 하나라도 없으면 해당 비교 작품 조회를 중지하고 빠진 자료를 알립니다. `/story-long-analyze`로 필요한 분석을 보강한 뒤 연결하도록 권합니다. 빈 껍데기로 채우거나 현재 작품 프로젝트를 되돌리지 않습니다. 두 파일이 모두 있으면 새 내장 필드가 없어도 동기화를 막지 않습니다.
- `문체.md`가 없으면 작가에게 `/story-long-analyze`로 이 비교 작품의 문체 분석을 보충하도록 요청합니다. 본문 전 검사가 누락을 차단합니다. `비교작품/{对标书名}/`에 옛 문체가 있으면 최신 분석 산출물로 덮어쓰고 보고합니다.
- 그 밖의 하위 디렉터리가 없으면 가져오기 완료 보고에서 쉽게 설명하되 프로젝트 생성을 막지 않습니다.

충돌 규칙: `비교작품/{对标书名}/플롯/감정모듈.md`·`플롯/리듬.md`가 권위 자료이며 `작품분석보고서.md`·`플롯/이야기선.md`는 요약일 뿐입니다. 요약과 충돌하면 설명을 남기고 권위 파일을 따릅니다. 권위 파일 하나라도 없으면 불완전한 비교 디렉터리를 만들지 말고 해당 작품의 분석 산출물부터 복구합니다.

## 자체 점검

- [ ] `작품분석실/{对标书名}/`·`비교작품/{对标书名}/`의 이름·출처가 일치하고 권위 파일 둘 다 동기화됨. 불일치하면 복구 조치를 보고하되 현재 작품 프로젝트를 되돌리지 않음
- [ ] `작품분석실/{导入书名}/`가 `비교작품/`로 복사되지 않았으며 `{导入书名}`가 비교 작품 등록에 없음
