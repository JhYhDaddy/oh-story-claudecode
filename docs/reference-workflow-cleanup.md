# 참조 자료 읽기와 검사 책임

## 동작 수정과 근거

- **문체는 특성별로 우선 적용합니다**: #395(`1e2488b`)는 문체의 읽기 중지 표를 참조 파일 전체를 건너뛰라는 지시로 바꿨습니다. 이제 그 변환을 제거하고 문체 전문 입력을 유지합니다. 파일은 작업 조건에 따라 읽고 충돌하는 표현 규칙은 #412의 우선순위로 판단합니다. 회귀 테스트는 구체적인 파일, 와일드카드 경로, 부분 판독 표가 조립된 프롬프트를 바꾸거나 문체 파일을 수정하지 않는지 확인합니다.
- **신체 관련 단어는 기능으로 판단합니다**: `d2cad637`(2026-05-04)은 단편에서 같은 신체 부위 단어를 전체 5회 이하로 제한했습니다. 실행 기록에서는 모델이 `s.count()`로 휴대전화(手机)·수속(手续)의 글자까지 세어 “손(手)=28”로 판단했습니다. 한도를 맞추려고 “휴대전화를 내 앞으로 가져왔다”를 “송금 화면을 내 앞으로 가져왔다”로, “먼저 손을 들어 시험해 봐”를 “먼저 들어 시험해 봐”로 바꿨습니다. 이를 main에 이미 있는 집필자 기준으로 교체합니다. 횟수 상한 없이 서사 기능으로 판단합니다. 같은 변경 묶음의 글자 수·절 수·스캔 기준은 유지합니다.

## 검사 책임

집필자는 내용 반영, 구성, 형식을 담당합니다. 품질 단계에서는 한 실행자가 의미 기반 AI 문체 제거를 수행하고, 주 세션이 최종 파일에 스캔과 전달 검수를 실행합니다. 이 분담을 장편·단편 집필, 원고 검토, 수동 대체 실행 프롬프트에 전달합니다. 책임이 지정되지 않은 독립 호출에서는 기존 집필자 자체 검사를 유지합니다.

#403의 호출자 지정 검사 범위, #406의 감정 직접 서술과 기능적인 신체 세부 묘사, #412의 문체 우선순위를 유지합니다. 내부 재작성 순서, 대화 검사, 일관성 검사, 최종 재검사도 계속 수행합니다. #395의 8개 슬롯 조립, 묶음별 전달, 시공간 표, 새 요소 3단계 분류, 분량 처리, 추적 트랜잭션은 원래 계약을 유지합니다.

## 예산과 검증

진입 문서가 짧아진 것은 필요할 때 자료를 읽도록 옮겼기 때문이며, 옮긴 파일도 같은 단계 예산에 포함합니다. 라우팅·책임 설명의 예산 증가는 `scripts/doc-budget.json`에 명시했습니다. 장편 +200/+900, 단편 +500이며 에이전트 경로에는 전체 범위 파일을 추가 계수합니다. 이 기준은 전체 세션의 토큰 사용량을 뜻하지 않습니다.

검증은 집필자 파이프라인, 문체 우선순위, 집필 전 필수 자료, 파일 접근 가능성, 공유 복사본, 문서 예산, 스캐너, 추적, 여러 호스트 배포를 포함합니다. 이 문서의 개선 효과는 읽기·검사 동작의 수정이며 전체 완성 원고 품질은 실제 사용으로 평가해야 합니다.
