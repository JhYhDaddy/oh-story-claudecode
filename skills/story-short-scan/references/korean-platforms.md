# 한국 플랫폼 조사: 공개 자료와 제공 자료

한국 플랫폼 또는 미정이면 이 분기를 사용한다. 중국 플랫폼을 명시한 경우에만 기존 수집기·집계 절차로 돌아간다. 국내 자동 수집기와 API 연동은 미검증이며 지원한다고 표시하지 않는다.

## 대상 결정

- 직접 연재: 문피아·네이버 웹소설(챌린지/베스트리그 구분)·노벨피아.
- 시장 조사: 네이버 시리즈·카카오페이지·리디도 포함한다. 등록·투고 가능 여부는 별도 확인한다.
- 단편·개인 발행: 포스타입. 장편 순위를 단편 시장 순위로 바꿔 부르지 않는다.
- 특정 플랫폼을 자동 선택하지 않는다. 플랫폼·장르·무료/유료·신작/전체·관찰 기간을 정한다.

## 자료 수집과 보고

사용 가능한 웹 도구로 공개 순위·작품 정보를 확인한다. 로그인이나 페이지 구조 때문에 읽지 못하면 사용자 제공 텍스트·스크린샷·파일을 받는다. URL만 받았고 읽지 못했다면 관측했다고 쓰지 않는다. 제공 자료임을 구분하고 날짜가 없으면 미상으로 기록한다. 자료가 없으면 조사 계획만 제공하고 최신 추세를 만들지 않는다.

`순위조사/{YYYYMMDD}/`에 같은 날 중복 시 `-2`를 붙인 새 폴더를 만든다. `한국시장표본.md`에는 플랫폼, 순위명/추천목록명, 장르·연재 구분, 조회 시각과 시간대, 원문 URL 또는 제공 파일, 확인 범위를 기록한다. 작품별로 순위(없으면 없음), 제목, 작가, 작품 URL, 회차 수, 공개된 지표의 원문 이름·값, 태그, 소개 요약을 표로 보존한다. 추천 목록을 순위로 취급하지 않는다. 안 보이는 값은 미상이며 0으로 채우지 않는다.

`1.2만` 등 원문 숫자는 보존하고 환산값을 병기할 수 있다. 조회·추천·선호작·관심·별점은 서로 합산하거나 대체하지 않는다. 플랫폼·순위 종류·관찰 시점이 같은 지표만 비교한다. 유료 매출·완독률·전환율은 공개 근거 없이 추정하지 않는다.

`순위조사집계.md`는 표본을 직접 읽어 작성한다. 국내 자료는 중국어 형식 전용 `aggregate-rank.js`에 넣지 않는다. 보고에는 출처·수집 범위·누락, 반복 소재와 근거 작품, 비교 가능한 지표, 표본 수·불확실성, 작가가 시험할 소재를 포함한다. 단일 시점의 인기도는 추세로 단정하지 않으며 시계열 자료가 있을 때만 변화 방향을 말한다. 이후 기존 스킬의 소재 선정·보고 단계로 연결하되 중국 시장 기본값은 적용하지 않는다.
