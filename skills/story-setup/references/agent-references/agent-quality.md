# 에이전트 공통 품질 핵심

> 이 파일은 장르 공통 판단 기준을 제공한다. 검토 시 반드시 `agent-reference-profiles.md`에 따라 현재 profile의 품질 보완 문서를 읽고, 분량·밀도·공개 위치는 해당 profile로 판단한다.

## 서사 단위의 전진

- [ ] 이번 단위에서 목표·위험·정보·관계·자원·신분·감정적 입장 중 적어도 하나가 변한다.
- [ ] 이 단위를 삭제하면 인과·인물·기대에서 구체적으로 짚을 수 있는 손실이 생긴다. 이를 답하지 못할 때만 분량 채우기일 가능성이 있다고 판정한다.
- [ ] 도입은 현재 목표를 이어받거나 유효한 이상 징후를 제시한다. 기능 없는 날씨·풍경·일상으로 자리를 채우지 않는다.
- [ ] 끝은 결정·발견·결과·관계 변화·미완의 행동에 놓인다. 변화를 작가의 요약으로 대체하지 않는다.
- [ ] 전진 강도는 현재 profile·장르·이미 확립한 기대 충족 리듬에 따른다. 장르를 가로지르는 고정 글자 수를 적용하지 않는다.

## 정보와 장면

- [ ] 장면마다 목표·장애물·종료 후 상태 변화가 있다.
- [ ] 설정은 행동·갈등·증거를 따라 등장하며 설명문이 계속 이어지지 않는다.
- [ ] 인물은 선택하거나 행동하거나 결과를 감당한다. 여러 문단 동안 같은 감정만 반복해서 느끼지 않는다.
- [ ] 새 개념 수는 현재 장면의 이해 부담에 맞는다. 필요한 개념에는 확인 가능한 적용 조건을 제시한다.

## 언어와 형식

- [ ] 대화는 신분·관계·현재 권력 위치에 맞고 인물별로 구분된다.
- [ ] 추상적 감정에는 선택·대사·물건·실제 결과의 뒷받침이 있다. 직접 서술하는 편이 더 정확하면 직접 써도 된다.
- [ ] 공허한 요약·연속된 상투적 수사·세련되어 보이려 쌓아 올린 신체 반응이 없다.
- [ ] 제목 행 외에는 ‘이번 장·상세 개요·복선·독자’ 같은 집필 작업 메타 정보를 섞지 않는다. 이야기 안의 실제 맥락은 예외다.

## 다섯 차원 평가

각 차원은 0–100점이며 근거와 문제의 영향을 덧붙인다. 전체 인상만으로 점수를 주지 않는다.

### 핵심 일관성

주요 갈등·행동·인물 동기·성과 귀속이 앞뒤로 일치하는지 확인한다.

| 문제 | 심각도 | 수정 |
|---|---|---|
| 계기 없이 인물 동기가 갑자기 변함 | critical | 계기를 보충하거나 행동 조정 |
| 핵심 갈등의 앞뒤 불일치 | high | 거슬러 검토하여 갈등 설정 통일 |
| 주요 행동이 확립한 인물상과 모순 | high | 행동 조정 또는 눈에 보이는 이유 보충 |
| 부차적 갈등을 잊음 | medium | 회수하거나 연기하고 흔적을 남기거나 명시적으로 약화 |

### 표현의 재작성 정도

표현이 자연스러운지, 입력 형식을 복제하거나 만능 표현을 끼워 넣었는지 확인한다. 정상적인 원문을 ‘재작성률’을 위해 억지로 바꾸지 않는다.

| 문제 | 심각도 | 수정 |
|---|---|---|
| 개요나 참고 원문을 그대로 옮겨 말투가 부자연스러움 | medium | 사실은 유지하고 서사 형태를 재구성 |
| AI 표지어·동형 문장·설명 꼬리가 무더기로 등장 | high | 구체적 행동·증거·관계상의 결과로 변경 |
| 미사여구·비유·신체 반응을 쌓음 | medium | 기능 없는 부분을 지우고 인물다운 세부 유지 |

### 형식 일관성

문단이 극적 단위에 따라 자연스럽게 나뉘는지, 인용부호와 장 표기가 프로젝트 규약을 따르는지, 목표 글자 수에 현재 절차의 결정적 측정 기준을 쓰는지 확인한다.

### 가독성

장황함·뒤섞인 정보 순서·제자리도는 심리 묘사·화려한 표현에 가려진 주요 인과를 확인한다. 새 정보·결단·감정 전환을 담은 독백을 문장 수만으로 줄이지 않는다.

### 논리적 연결

설정·시간선·인물의 지식·증거 사슬과 ‘원인 → 행동 → 결과 → 여파’가 맞물리는지 확인한다. 근거가 부족하면 명시하고 작가 대신 설정을 채우지 않는다.

## 심각도와 수정 전략

| 등급 | 판정 | 조치 |
|---|---|---|
| blocking / critical | 핵심 계약·인과·사실이 성립할 수 없음 | 필수 수정: 먼저 고친 뒤 후속 집필 진행 |
| high | 계속 읽을 동기·인물의 설득력·핵심 매력을 뚜렷하게 해침 | 필수 수정: 이번 회차에 수정 |
| medium | 국소적 지연·반복·불명확한 표현 | 검토 권장: 효과 순서로 수정 |
| low / optional | 성립에는 영향 없으나 강화 가능 | 알림만: 필수 관문으로 포장 금지 |
