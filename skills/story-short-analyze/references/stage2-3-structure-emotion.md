# Stage 2–3: 구조·사건 노드·감정선·폭발 지점

Stage 2–3에서 읽는다. 앞부분은 방법, 뒷부분은 출력 템플릿이다. 각 Stage를 마치면 [quality-checklist.md](quality-checklist.md)의 해당 절로 자체 점검한다. 소재·훅·서스펜스·핵심 작동 원리에는 각각 관찰 기준이 있으며, 읽을 파일은 진입 문서의 ‘시점별 읽기’를 따른다.

## 단편과 장편 분석의 중점

흔한 차이를 요약한 표다. 구체적인 분량·인물 수·구조는 원문을 기준으로 한다.

| 항목 | 장편 | 단편 |
|------|------|------|
| 분량 | 수십만 자·수백 장까지 가능 | 한정된 전체 분량에서 주요 갈등을 완결 |
| 변화 곡선 | 여러 서사·권에 걸칠 수 있음 | 보통 소수의 곡선에 집중 |
| 인물 | 큰 군상을 담을 수 있음 | 인물의 기능이 비교적 집중됨 |
| 세계관 | 복잡한 설정을 점차 펼칠 수 있음 | 현재 갈등을 중심으로 설정을 펼침 |
| 핵심 동력 | 지속적인 반복·성장 가능 | 한 차례의 완결된 감정·인식 변화 |
| 독자 유지 | 다음 연재를 기다림 | 한 번에 끝까지 읽음 |
| 분석 중점 | 구조 완결성·복선 관리 | 감정 설계·작법 기법·리듬 |

**핵심: 단편은 공감과 폭발 지점으로 움직인다. 분석은 이야기의 핵심, 사전 축적 방식, 폭발 위치를 살피는 일이다.**

## 방법

### Stage 2: 구조 분석 + 사건 노드 추출

- 장/소절 구분 표식(`###01`, `第一章`, `01` 등)을 판별한다.
- 제목을 추출하고 절별 글자 수를 기록한다.
- **이야기 핵심**을 세 층위로 요약한다.
  - **설정**: 전제/발동 조건(예: ‘세 번 회귀했지만 어머니와 남동생에게 살해됨’).
  - **주제**: 핵심 갈등/가치관 충돌(예: ‘극단적인 남아 선호’).
  - **핵심 행동**: 주인공이 한 일(예: ‘어머니와 남동생이 자멸하게 내버려 둠’).
  - 한 문장으로 합친다. 예: ‘세 번 회귀하고도 어머니와 남동생에게 살해된 소녀가 네 번째 생에서는 그들이 자멸하게 내버려 둔다.’
- **줄거리**를 200-500자로 요약한다.
- POV를 판별한다(1/3인칭, 전지적 시점).
- 서사 시간선을 판별한다(시간순/삽입 회상/역순/두 서사의 교차).
- 전체를 기능별로 나눈다. 최소 발단/전개/절정/결말을 포함하며 원문에 실제 전환·연결 구간이 있을 때만 추가한다. 각 구간의 글자 수 범위와 비율을 표시한다.

> **유연한 절 구분**: 2-3장뿐이지만 숫자로 된 소절이 들어 있는 이야기에서는 물리적인 장보다 서사 기능 단위를 ‘절’로 본다. 장이 적으면 소절/번호 구간을 분석 단위로 삼는다.

**비정형 텍스트의 구간 구분**: 대화체·채팅 기록·게시글·서간체처럼 표준 장 형식이 아니면 시간/발화자 전환/정보 공개 지점으로 먼저 나눈 뒤 발단·전개·절정·결말에 대응시킨다. 자연 단락 수로 기계적으로 나누지 않는다.

#### 사건 노드 추출

사건 노드 = 이야기 전개를 추진하는 핵심 사건 또는 정보 공개.

의미 변화를 경계로 추출한다. 위험·정보·관계·자원·결정·행동·독자 이해가 바뀌면 노드 하나로 기록한다. 같은 행동 사슬이 연속해서 여러 기능을 수행하면 한 노드로 묶고 설명에 밝힐 수 있다. 글자 수나 소절별 할당량으로 나누지 않는다. 전체의 실제 변화를 포괄하고 목표 수량을 채우려고 같은 사건을 반복하지 않는다.

각 노드에서 추출할 내용:

| 필드 | 설명 |
|------|------|
| 번호 | 텍스트에 사건이 등장하는 순서. 역순 서술의 이야기 속 시각은 별도 표시 |
| 위치 | 절 번호 + 전체에서 대략 몇 번째 글자인지(예: ‘3절, 약 3200자’). 후속 단계가 새 이야기의 리듬을 설계하는 근거 |
| 기능 | 감정/정보/갈등/전환/대화/분위기 노드 |
| 설명 | 일어난 일만 객관적으로 묘사. 서사 해설 용어 금지 |
| 원문 인용 | ≤300자 직접 인용 |
| 감정 표시 | 감정 유형 + 강도(-9~+9) |
| 관련 인물 | 전체 이름 |
| 기법 표시 | 사용한 기법이 있을 때 기록 |

### Stage 3: 감정선 + 폭발 지점 분석

#### A. 情感曲线

감정 곡선을 기록하는 출력 계약 제목이다.

사건 노드 데이터로 감정 곡선을 만든다. 감정적 입장·기대·압박이 실제로 바뀌는 곳만 점으로 잡고 도입과 결말에는 하나씩 둔다. 완결된 과업·추론·기술·기다림의 사슬에 독립적인 감정 전환이 없으면 해당 절에 점을 억지로 추가하지 않는다. 수량을 채우려고 보충하지 않는다.

곡선 특징:
- 시작 감정.
- 흐름(상승/하강/파도형/V형/역 V형/계단형/절벽형/압축된 스프링).
- 극값(최고·최저점과 백분율 위치).
- 방향 차이(시작에서 끝까지의 순변화).
- 반전 횟수(양수와 음수의 교대 횟수).

#### B. 폭발 지점 분석

감정 폭발의 설계를 분석한다.

| 항목 | 질문 |
|------|------|
| 사전 배치 | 무엇이 독자의 관심을 끄는가? 처음 몇 자 안에 완성되는가? |
| 축적 | 무엇이 감정을 쌓으며 얼마나 오래 쌓는가? |
| 지연 | 해소를 늦추는가? 정보 격차/오해/서스펜스인가? |
| 폭발 지점 | 어느 순간 모든 감정이 풀리는가? 문장 단위로 특정 |
| 여파 | 해소 뒤 여진이나 여러 인물의 반응이 있는가? |
| 인상 | 해소 뒤 무엇이 남고 독자는 무엇을 기억하는가? |

**겹친 폭발 지점**: 표면의 폭발(죽음/이별 등) 직후 그 여파 속에서 심층의 폭발(진실 공개/인식 전복 등)이 다시 터지는 작품도 있다. 다음을 표시한다.
- 겹친 폭발 지점이 있는가?
- 표면과 심층의 폭발은 각각 무엇인가?
- 중첩 효과는 무엇인가(1+1>2가 되는 지점)?

**여러 폭발의 연쇄**: 명문가 복수·여론 반전 등의 이야기에는 독립적인 폭발이 차례로 일어나며 각각 완결되면서 서로 호응할 수 있다. 다음을 표시한다.
- 독립적인 폭발은 몇 개이며 각각 무엇인가?
- 점층형(갈수록 더 통쾌함)인가, 병렬형(서로 다른 측면의 만족)인가?
- 간격이 적절한가(너무 멀면 감정 단절, 너무 가까우면 피로)?

#### C. 기대감 분석

절마다 기대 상태를 추적한다. 표는 아래 출력 템플릿의 ‘C. 기대감 분석’을 참조한다.

새 기대를 형성하는 시점과 핵심 기대가 진전하는 시점을 기록한다. 멈춤의 효과는 그동안의 선택·정보·결과와 함께 판단한다.

## 사건 노드 추출 규칙

### 노드 기능: 6종, 임의 추가 금지

| 기능 | 정의 | 판별 특징 |
|------|------|----------|
| 情绪节点(감정 노드) | 인물의 내면 감정이 뚜렷하게 바뀜 | 감정어·행동 변화·내면 독백 |
| 信息节点(정보 노드) | 새 정보 공개로 독자나 인물이 새로 앎 | 공개·발견·전달받음 |
| 冲突节点(갈등 노드) | 인물끼리 정면 대립 | 직접 대립·거절·위협 |
| 转折节点(전환 노드) | 이야기 방향이 꺾임 | 전개 방향 변화 |
| 对话节点(대화 노드) | 핵심 정보나 함축을 담은 대화 | 새 정보 전달 또는 관계 변화 |
| 氛围节点(분위기 노드) | 환경/분위기의 큰 변화 | 장면 전환·시간 도약·계절 변화 |

### 품질 요구

1. **객관적 묘사**: ‘무슨 일이 일어났는가’만 쓰고 주관적 평가를 금한다.
   - 금지: ‘선무웨는 가슴이 찢어지는 심정으로 진실을 들었다.’
   - 올바름: ‘선무웨는 “사생아일 뿐”이라는 말을 듣고 허공에서 손을 멈췄다.’
2. **서술 순서**: 텍스트에 나타난 순서를 따르고 역순 서술을 이야기 내부의 시간순으로 바꾸지 않는다.
3. **정확한 감정 표시**: 모든 노드에 감정 유형과 강도를 쓴다.
4. **정보 충실도**: 맥락을 바꾸는 핵심 세부를 빼지 않는다.
5. **높은 압축도**: 한 노드를 한 문장으로 요약한다.
6. **복합 병합**: 같은 감정/서사 목적의 연속 미세 행동은 한 노드로 묶어 N 번호 하나를 공유한다. ‘노드 수’는 최종 N 번호의 총수로 센다.

### 묘사와 평가의 구분

- 금지: ‘이 대화로 그녀의 강인함을 보여 준다.’
- 올바름: ‘그녀는 훠팅위를 똑바로 보며 “당신에게 맞춰 줄 의무는 없어요”라고 말한다.’
- 금지: ‘분위기가 긴장되었다.’
- 올바름: ‘훠팅위의 눈빛이 갑자기 차가워지고 온몸에서 위압감이 뿜어졌다.’

## 감정선 분석

### 감정 유형

| 유형 | 신호 |
|------|--------|
| 안타까움 | 행동 세부·참고 견디는 묘사 |
| 분노 | 악역의 행동·부당한 대우 |
| 경악 | 반전·진실 공개 |
| 만족 | 쾌감 해소·악인 처벌 |
| 긴장 | 서스펜스·위기 |
| 먹먹함 | 놓아줌·아쉬움·성장 |
| 치유 | 보살핌·재회·이해받음 |
| 억눌림 | 자신을 굽혀 타협함·참고 견딤 |

### 감정 강도 척도

| 값 | 대응 감정 | 설명 |
|----|------|------|
| +9 | 극도의 통쾌함 | 응징·압도·최종 반전·악인의 처벌 |
| +7 | 강한 만족 | 핵심 증거 공개·기대 충족 |
| +5 | 뚜렷한 긍정 | 작은 승리·다정한 순간 |
| +3 | 약한 긍정 | 작은 진전·일상의 온기 |
| 0 | 중립 | 연결·사전 배치 |
| -3 | 약한 불편 | 작은 좌절·서러움 |
| -5 | 뚜렷한 부정 | 모욕·오해·협박을 받음 |
| -7 | 강한 고통 | 버림·배신·아이가 겪는 서러움 |
| -9 | 극도의 고통 | 생사 위협·정신적 짓밟힘·신념 붕괴 |

> **척도 설명**: 감정 곡선용으로 방향(고통/쾌감)과 강도를 구분한다. 범위는 -9~+9이며 ±9, ±7, ±5, ±3과 0만 사용한다. 도입/결말 분석은 별도의 1-10 절대 강도 척도를 사용해 양·음이 아닌 세기만 본다.

### 감정 곡선 형태

| 형태 | 특징 | 적용 소재 | 전형적 효과 |
|------|------|----------|----------|
| V형 | 고통 뒤 쾌감 | 응징/복수 | 극도의 대비 |
| 역 V형 | 달콤함 뒤 고통 | BE 고통 중심 서사 | 아쉬움과 풀리지 않는 여운 |
| 파도형 | 양·음 교대 | 후회·재결합물 | 감정의 밀고 당김 |
| 계단 상승 | 점차 고조 | 통쾌한 서사/응징 | 강한 리듬감 |
| 절벽 하강 | 갑작스러운 반전 | 죽음·부재 서사/반전 | 경악 |
| 압축된 스프링 | 오랜 억눌림 뒤 한 번에 해소 | 인내하며 계획함 | 극도의 해소 |
| 쌍봉형 | 두 절정 | 복합적인 단편 | 풍부한 층위. 두 절정이 모두 고통일 수도(두 차례 작별), 서로 성격이 다를 수도 있음(해방 뒤 깨달음) |
| **혼합형** | 위 형태의 조합 | 조합에 따라 다름 | 주 형태와 보조 형태를 표시한다. 달콤한 로맨스/코미디는 음수 없이 양수만 유지할 수 있으며 계단 상승의 변형이다 |

## 사건 노드

<!-- output to: 사건노드.md (독립 문서) + 작품분석보고서.md (사건 노드 목록 구간에 같은 내용) -->

> 추출 방법과 경계는 위 ‘사건 노드 추출 규칙’만을 최종 기준으로 삼는다.

### 노드 템플릿

아래 출력 레이블은 연계 호환을 위해 원형을 유지한다. `位置`는 위치, `功能`은 기능, `情绪`는 감정, `涉及`는 관련 인물, `手法`는 기법이다. 事件概括는 사건 요약이다. 기능값은 감정/정보/갈등/전환/대화/분위기에 대응한다.

```markdown
N{번호} **{事件概括}**：位置{N절, 약 X자} | 功能{情绪/信息/冲突/转折/对话/氛围} | 情绪{유형}{강도-9~+9} | 涉及{전체 이름} | 手法{있을 때}

원문 인용(≤300자)
```

### 출력 예시

직접 인용은 원형 보존 원칙을 보여 주기 위해 중국어 예시 원문을 유지한다. N1은 ‘아직 모자를 집안에 들이지 않을 것인가 / 사생아일 뿐이라는 말을 듣고 손을 멈춤’, N2는 ‘자신과 아들 모두 사생아이며 사랑받지 못함을 깨닫고 손을 거둠’이라는 내용이다.

```markdown
## 사건 노드 목록

N1 **대화를 엿들음**：位置{1절, 약 200자} | 功能{信息} | 情绪{경악}{-7} | 涉及{선무웨} | 手法{정보 격차}

> "霍总还不打算让沈暮月母子进门吗？"
> "没必要，私生子而已。"
> 我正准备推门而入，听到这话，手停在了半空。

N2 **자기 인식**：位置{1절, 약 350자} | 功能{转折} | 情绪{먹먹함}{-5} | 涉及{선무웨}

> 我是沈家的私生女，生了个儿子，也是私生子。
> 霍庭煜对我没有爱。
> 我默然抽回了手。
```

### 품질 자체 점검

- [ ] 전체 핵심 변화를 포괄하고 같은 행동 사슬을 중복 분할하지 않았다.
- [ ] 각 노드를 객관적으로 묘사했다(서사 해설 용어·주관적 평가 없음).
- [ ] 각 노드에 위치(절 번호 + 대략 몇 번째 글자인지)와 감정 표시(유형 + 강도)가 있다.
- [ ] 노드는 텍스트에 사건이 등장하는 순서다.
- [ ] 원문 인용은 연속된 ≤300자다.
