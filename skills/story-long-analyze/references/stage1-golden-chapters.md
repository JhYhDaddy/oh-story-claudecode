# Stage 0–1: 개요 초안·도입 세 장

시작 단계(Phase 1부터 Stage 1 확인 정지까지)에 읽습니다. 작가용 `빠른미리보기.md`·확인 문안은 [author-facing.md](author-facing.md) 참조.

## Stage 0 기계적 색인·개요 초안

신규·부분 완료 상태에서 원문을 읽어야 하면 먼저 색인을 만듭니다. 원문 배치는 SKILL.md의 실행 규칙 참조.

```text
"{PYTHON}" "{story-long-analyze skill 根}/scripts/build_chapter_index.py" --source "{拆文目录}/원문/원문.txt" --output "{拆文目录}/chapter_index.csv" --locator-path "원문/원문.txt"
```

완전한 옛 결과 직접 사용·단순 보강에는 색인을 만들지 않습니다. 원문 변경·번호 불일치로 멈추고 `author_message`를 반환하면 [index-rebuild.md](index-rebuild.md)를 따릅니다.

초안은 장 제목·권 구간 구조·시작과 끝 표본만으로 약 200자 작성합니다. 읽은 범위가 부족하므로 500–1000자 줄거리·인과를 쓰지 않습니다. Stage 5가 완성본으로 교체합니다([stage5-report.md](stage5-report.md)). 장별 제목·글자 수는 `chapter_index.csv`에 있으므로 개요에 나열하지 않습니다. 중국어 제목·필드는 파싱·조회 표식입니다.

```markdown
# 概要：{书名}

总章数：{N}
总字数：{X}万
题材：{장르}

| 卷/段 | 章节范围 | 章数 | 预估字数 |
|-------|----------|------|----------|
| {卷名} | 第1-X章 | {N} | {W}万 |

## 首版概要

{약 200자. 장 제목·제1장·마지막 장 표본에서 핵심 동력·주인공 이름·대략의 설정을 정리하며 사건 전환을 억지로 채우지 않음}
```

「总章数：N」은 독립 행으로 씁니다. 검사기가 이 행으로 전체 장 수를 읽습니다. Stage 5는 「首版概要」만 교체하고 기본 정보·권 구간 표는 보존합니다.

## Stage 1 도입 세 장

`장별분석/제1장_심층분석.md`·`장별분석/제2장_심층분석.md`·`장별분석/제3장_심층분석.md`에 장마다 하나씩 아래 형식으로 출력합니다. 원문이 세 장 미만이면 있는 장만 분석하고 없는 장을 만들지 않습니다. 굵은 중국어 필드명은 후속 조회가 사용하는 표식입니다.

글자 수 약 {X}자 | 核心事件: {한 문장}.

**开篇钩子**(제1장은 첫 500자): 유형{悬念/冲突/反差/信息差/代入感} | 기법{설명} | 효과{强/中/弱}—{이유}.

**人物出场**: {목록} | 주인공 구축{직접 묘사/대사/행동/타인 평가} | 첫인상{설명}.

**世界观铺设**: 공개{정보} | 숨김{정보} | 방식{대사/서술/사건}.

**结构拆解**: | 문단 범위 | 기능{铺垫/冲突/爽点/收尾} | 글자 수 |.

**爽点分析**: 유형{装逼打脸/逆袭反转/获得机缘/信息差碾压/情感满足/扮猪吃虎} | 준비 {X}자 / 실현 {Y}자 / 비율 {Z:1} | 감정 곡선.

**反应层拆解**(있으면):

| 층위 | 인물 | 반응 | 분량 |
|------|------|------|------|
| 의심·경시 | | | |
| 충격·망신 | | | |
| 강자의 재평가 | | | |
| 확산·전파 | | | |

반응 분량 비율 {N:1}, 분모는 실력 시연 분량입니다. 1.5 미만이면 반응이 통쾌함을 충분히 이어받는지 확인합니다.

**释放后追证**(있으면): 실현 후 악역의 실제 태도는? {행동+원문 인용}.

**冲突升级**(있으면): {행동} | 고조 층위{언어→경제→폭력} | 인물상에 미치는 영향.

**背景信息揭示**(있으면): 공개{무엇} | 서사 기능{기존 가정 뒤집기/재해석/새 이야기선 준비/인식 편향} | 주선 영향.

**章尾钩子**: 유형{悬念/反转/新信息/新角色} | 내용{설명} | 기대도{强/中/弱}.

**可借鉴要素**: {재사용 기법}.

> 제2·3장은 정보 밀도·앞 장 대비 갈등 고조·리듬 변화·통쾌함 사이 글자 수를 추가 확인합니다.
> 악역이 비인간형인 영기 부활·종말·국운 등 추상 대항물은 「爽点分析」를 추상 대항 방식으로 바꿉니다. 핵심 대항면{설명} | 긴박함 출처{설명} | 고조 원리{설명} | 서사 대체{전통적 망신 주기를 대체한 요소}.
> 감정 중심·여성향(로맨스·가문 암투·달달물 등)은 관계 방식으로 바꿉니다. 감정 긴장 출처{오해/신분 차이/옛 원한/계약 등} | 관계 진전{무엇에서 무엇으로} | 고통·달콤함 배치{고통 후 달콤함/달콤함 속 아픔 등} | 독자 기대{누가 누구에게 마음을 표현하길 원하는지}. 「反应层拆解」는 주변인의 관계 반응을 봅니다. 미리보기의 「爽点设计」는 감정 실현으로 채점합니다.

같은 세 장을 읽을 때 `_style-sample.txt`도 우선 작성해 Stage 6 지정 표본 추출을 줄입니다. 옛 프로젝트에 캐시가 없으면 Stage 6가 색인에서 4–6장을 고르고 해당 행만 읽을 수 있습니다.

```text
<!-- STYLE_SAMPLE:v1 -->
## 片段 A
source_locator: 원문/원문.txt:L{起始行}-L{结束行}
基调: {紧张/压抑/轻松/温馨/热血}
示范点: {문장 길이 리듬/구두점/대사 속뜻/행동·반응 등}
{연속 원문 300—500자}
```

총 4—6구간을 고릅니다. 같은 장의 여러 구간도 가능하나 범위는 겹치면 안 됩니다. 표현 분석에 필요한 최소 표본만 보관하고 별도 줄거리 사실 체계를 만들지 않습니다.

## 빠른 미리보기

Stage 1 정지 지점 산출물은 `작품분석실/{书名}/빠른미리보기.md`이며 템플릿은 [author-facing.md](author-facing.md) 참조. Stage 0/1의 개요요약.md·도입 세 장 분석만 사용하고 Stage 2-6에서야 계산할 수 있는 내용을 넣지 않습니다. 「基本信息」·「黄金三章评分」은 최종 `작품분석보고서.md`와 이름·구조가 같습니다. 최종 보고 후에도 삭제하지 않습니다.

## 공통 빠른 참고

### 통쾌함 유형

| 원문 유형 | 의미 | 예 |
|------|------|------|
| 装逼打脸 | 자신을 깔보는 사람을 실력으로 압도 | ‘네가 감히?’ |
| 逆袭反转 | 절망에서 역전 | 무능력자의 각성 |
| 获得机缘 | 남에게 없는 기회·자산 획득 | 신기 획득 |
| 信息差碾压 | 독자·주인공만 아는 정보로 압도 | 회귀의 선지식 |
| 情感满足 | 관계 진전 | 고백·재회·인정 |
| 扮猪吃虎 | 숨긴 실력의 갑작스러운 공개 | 약자인 줄 알았던 강자 |

### 후킹 유형

| 유형 | 의미 | 예 |
|------|------|------|
| 궁금증 | 풀리지 않은 수수께끼 | ‘검은 왜 그를 주인으로 인정했을까?’ |
| 갈등 | 직접 대항 | 시작부터 추격 |
| 대비 | 상식에 어긋남 | ‘다른 세계로 간 첫날 파산’ |
| 몰입 | 독자 공감 | 비슷한 곤경 |
| 정보 격차 | 독자만 알고 인물은 모름 | ‘그는 눈앞의 사람이 …인 줄 몰랐다’ |

### 장르별 실현 형태

준비 층위는 감정 결핍, 실현 층위는 충족, 반응 층위는 주변 반응을 담당합니다. 연결 층위·전체 분석법은 Stage 3 리듬 절 참조.

| 장르 | 실현 | 반응 출처 | 준비의 결핍 |
|------|-----------|-----------|-----------|
| 현환·수선 | 실력 압도·경지 돌파 | 동문·상대·장로의 충격 | 불완전 공법·자원 부족·혈통 억압 |
| 현대물 | 정확한 예측·신분 공개 | 사업 상대·전 연인·권력층 | 파산·해고·파혼 |
| 시스템물 | 희귀 기술 해제·과제 보상 | 시스템 희귀도 표기 | 실패 벌칙·기술 재사용 대기 |
| 역사 | 약자가 강자 제압·선지식 | 책사·황제·적장 충격 | 정보 비대칭·낮은 신분 |
| 미스터리 | 진실 공개·역공 | 폭로 대상 붕괴·독자 깨달음 | 오도 단서·용의자 결백 암시 |
| 로맨스·가문 암투 | 공개 지지·감싸기·진실 규명 | 연적·어른·구경꾼 | 오해·신분 차이·경시 |
