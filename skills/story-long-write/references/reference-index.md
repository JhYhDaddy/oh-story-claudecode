# 장편 참고 자료 색인

계획하거나 작가가 특정 기법을 물을 때 아래 표를 확인한다. 본문 집필에서는 SKILL.md의 이번 장 기법에서 지정한 자료 하나만 읽고 이 표를 근거로 추가하지 않는다.

## 시점별

| 시점 | 흐름 | 방법 |
|---|---|---|
| 방향 결정 | `references/workflow-setup.md` Phase 1 | `references/genre-readers.md`(시장·플랫폼). 장르 틀은 남성향 `references/long-genre-catalog.md`, 여성향 `references/female-audience-writing.md` |
| 설정 결정 | `references/workflow-setup.md` Phase 2 | `references/long-genre-mechanics.md`(핵심 아이디어·특전), `references/character-basics.md`, `references/character-relations.md`(관계·감정선), `references/reader-contract-and-progression.md` |
| 권 개요 작성 | `references/workflow-volume.md` | `references/outline-methods.md`(권 구조·리듬), `references/artifact-protocols.md`(템플릿), `references/emotional-arc-design.md`(감정 곡선), `references/long-reversal.md`(반전) |
| 상세 개요 작성 | `references/workflow-outline.md` | `references/plot-core-methods.md`(상세 개요·장 단위), `references/long-chapter-hooks.md`(장 시작·끝 후킹). 처음 3장은 `references/opening-design.md`의 도입 계획 추가 |
| 한 장 집필·일일 연재 | `references/workflow-chapter.md`, `references/workflow-daily.md` | `references/writing-craft.md`, `references/long-format.md`, 이번 장 기법 자료 하나. 1-3장은 `references/opening-design.md`의 도입 집필. 장르 카드는 `references/genre-prose-cards.md` |
| 재작업 | `references/workflow-revision.md` | 작가가 증상만 말하면 `references/revision-diagnosis.md` |
| 완성 원고 검사 | `references/long-chapter-quality.md` | `references/banned-words.md`, `scripts/check-ai-patterns.js` |

## 증상별

| 증상 | 먼저 읽을 자료 |
|---|---|
| 늘어짐·분량 부풀림·기대 단절·연독 하락·답답한 주인공·집필 막힘·좋고 나쁨을 설명하기 어려움 | `references/revision-diagnosis.md` |
| 도입에서 독자를 붙잡지 못함 | `references/opening-design.md` |
| 플롯 단위가 평탄하고 높낮이가 없음 | `references/emotional-arc-design.md` |
| 반격이 통쾌하지 않고 과시가 어색함 | `references/style-combat-face.md` |
| 반전 충격이 없거나 쉽게 예측됨 | `references/long-reversal.md` |
| 서스펜스가 흩어지고 단서가 불공정함 | `references/long-suspense.md` |
| 감정선 진전이 없고 주인공이 일방적으로 매달림 | `references/character-relations.md` |
| 특전 통제 실패·전투력 체계 붕괴 | `references/long-genre-mechanics.md` |
| 감정이 공허하고 반응이 틀에 박힘 | `references/emotion-on-page.md` |
| 대화가 평탄하고 인물 말투가 같음 | `references/dialogue-mastery.md` |
| AI 말투 | 검사기의 안내에 따라 수정. 전체 3계층 정리는 `/story-deslop` |
