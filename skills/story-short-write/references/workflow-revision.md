# Phase 4: 단편 정밀 퇴고

`scripts/`와 `references/`는 이 스킬 루트 기준입니다. 퇴고 전 이 파일과 `short-format.md`의 빠른 서식 검사·글자 수 기준을 반드시 읽습니다. 새 대화에서 퇴고해도 먼저 읽습니다.

본문 집필 중에는 사건 포함 여부와 서식만 확인합니다. Phase 4에서 주 세션이 직접 고치면 `references/short-deslop.md`와 `references/deslop-gates.md`를 읽고, 집필자에게 맡기면 agent-calls.md를 따릅니다. 탐지 결과와 아래 점검표로 필요한 부분을 먼저 고친 뒤 앞뒤 일관성을 확인합니다. 전체 3층위 진단 요청은 별도 `/story-deslop`으로 갑니다. 최종 스캔·전달 검증은 주 세션이 하며 수정 후에는 바뀐 곳과 영향받는 검사만 다시 확인합니다.

문제는 두 등급입니다.
- **blocking(필수 수정)**: 탐지기의 blocking과 점검표의 필수 수정 항목. 고쳐야 전달할 수 있습니다.
- **advisory(검토 권장)**: 탐지기의 advisory와 나머지 점검표 항목. 맥락상 기능이 있으면 유지하고 없으면 고칩니다. 어휘·문장 신호는 banned-words의 「需确认的语义问题」(확인이 필요한 의미 문제)로 판단하며 발견 즉시 삭제하지 않습니다. 불확실하면 전달 설명에 적어 작가 판단을 요청합니다. 보조 에이전트의 `[需复核]` 표식은 반환 설명에만 두고 본문에는 넣지 않습니다.

파일 모드에서는 `node scripts/check-ai-patterns.js --check --fail-on=blocking 본문.md`, `node scripts/check-outline-copy.js --outline 구간개요.md 본문.md`, `node scripts/normalize-punctuation.js 본문.md`, `node scripts/check-degeneration.js --check 본문.md`를 순서대로 실행합니다. 구두점 기본값은 `--quote-mode keep`으로 기능 없는 말줄임표·줄표·이중 하이픈·독립 구분선을 정리하되 옌옌의 「」는 유지합니다. blocking은 본문을 고친 뒤 재검사합니다. 개요 복사 검사에서 서약·핵심 원문 대사처럼 기능이 있으면 유지하고 `구간개요.md` 끝의 「复沓锚句」에 등록한 뒤 다시 검사합니다. 나머지는 현장에서 다시 씁니다.

모든 파일 저장 후 `node scripts/check-delivery-contract.js --json --min-chars {MIN} --max-chars {MAX} --sections {N} {短篇目录}`를 실행합니다. exit 0만 전달 가능합니다. exit 1이면 `repair_scope`에 따라 최소 수정하고 영향받는 품질 검사와 이 명령을 최대 2회 다시 실행합니다. 계속 실패하면 멈추고 미달 항목·차이를 아래 전달 설명으로 알립니다. exit 2, 스크립트 누락·실행 불가에서는 전달 계약 통과를 주장하지 않습니다. 이 검사는 글자 수·절 수·서식만 검증합니다.

#### Agent 调用：narrative-writer（去AI味）+ consistency-checker

한국어 안내: 집필자의 AI 문체 제거와 일관성 검사자 호출. SKILL 첫머리의 현재 호스트 역할 출처에서 사용 가능함을 확인한 뒤 배정합니다. 집필자 프롬프트는 [agent-calls.md](agent-calls.md)의 「精修去味」, consistency-checker에는 `项目目录：{dir}\n检查范围：{正文文件}\n检查类型：事实冲突+伏笔断线+角色属性不一致`를 전달합니다. 에이전트가 없으면 주 세션이 직접 수행합니다.

**깨끗한 본문 규칙**: 자체 검사 결과는 대화로만 설명하고 별도 저장하거나 본문에 붙이지 않습니다. `<!-- 自检 -->` 같은 검사 표식도 본문에 넣지 않습니다.

**작가에게 전달할 설명**:
1. 쓴 내용: 제목, 핵심 훅·반전 한 문장, 총 글자 수, 절 수.
2. 작가가 결정할 내용: 항목마다 질문 한 문장과 권장 기본값(예: 끝에 작은 반전을 더 둘까요? 기본은 추가하지 않음). 없으면 생략.
3. 선택 가능한 다음 단계: 특정 구간 퇴고, AI 문체 제거, 다른 플랫폼용 재작성 등.

자체 검사 결과는 ‘글자 수·소절·흔한 AI 문체를 확인했고 모두 통과했습니다’ 같은 한 문장만 씁니다. 미통과면 항목과 차이를 알립니다. 스크립트명·검사 ID·필드명·인수·표 형식은 쓰지 않습니다. 보조 에이전트 대체·버전 알림 등 실행 세부는 마지막 「技术备注：」(기술 참고) 한 줄에만 둡니다.

## 精修清单

한국어 안내: 정밀 퇴고 점검표. 반전 항목은 반전 작품에만 적용하며 반전이 없으면 핵심 보상·관계 진전을 봅니다. 장르별 항목은 해당 장르에만 적용합니다. 삭제는 SKILL.md 실행 규칙 3을 따릅니다.

```
### 앞뒤 일관성(필수 수정)
- [ ] 동기 변화에 계기가 있고 핵심 행동이 인물 설정에 부합함
- [ ] 핵심 갈등·설정·시간선·인물 정보가 일관되고 설정.md와 맞으며 복선이 회수됨
- [ ] 약속의 물건을 사용했다면 의미 반전이 완결됨. 등장 위치를 바꾸면 설정의 추적 표도 갱신
- [ ] 글자 수·절 수가 고정 범위 안. 부족하면 승인 사건의 누락만 보충하고 분량용 갈등·대화·사건은 추가하지 않음. 초과하면 전개 기능 없는 내용 삭제

### 도입과 완성 원고 형태
- [ ] 첫 문장은 날씨·풍경·배경 소개가 아니라 사건·행동·정보로 시작하며 첫 100자에 사건 3개 이상
- [ ] 도입문은 맨 앞에 두고 ‘导语’라는 표제는 쓰지 않음. 핵심 갈등을 알리되 비밀을 남김. 제1절 연결은 설정의 플랫폼 기조, 없으면 workflow-draft의 도입문 규칙 적용
- [ ] 제목·도입문·숫자 소절 본문으로 구성. 유료 전환점은 설정에 기록한 절 끝의 미완료 행동·증거·정체 변화·딜레마에서 끊으며 핵심 쾌감을 미리 소진하지 않음

### 진행과 훅
- [ ] 절마다 행동·증거·임무·대화·물건·기다림·관계 선택으로 최소 한 상태가 변함. 설정은 갈등과 함께 드러내고 긴 설명 없음
- [ ] 같은 감정을 세 문단을 넘겨 연속 작성하지 않음. 회상은 짧고 새 관점이 있으며 현재 장면과 대응
- [ ] 대화가 정보·전략·권력·관계·다음 행동을 바꾸고 말투가 신분에 맞음. 작은 문답의 연속·말만 바꾼 반복 없음
- [ ] 훅이 독자 기대·행동 방향·관계 판단의 변화에 놓이고 연속 질문 사이 부분 보상 존재
- [ ] 절 끝은 미완료 행동·새 정보·부분 보상·관계 변화·여운·명확한 다음 행동 중 하나를 남김

### 감정과 반전
- [ ] 감정 곡선 방향이 명확함. 고통과 쾌감 장르는 ‘고통, 고통, 작은 쾌감, 고통, 큰 쾌감’처럼 배치하고 고통만·쾌감만이면 조정. 다른 장르는 목표 감정 기준
- [ ] 반전은 되짚을 준비가 있고 오도 정보 자체는 사실임
- [ ] 최대 보상은 원인이 합쳐지고 증거가 충분한 곳에 두며 뒤에는 후속 영향 분량을 남김. 반전 뒤에는 보상과 여운만 작성
- [ ] 결말이 작품의 약속에 답하고 감정의 도착점이나 부분 보상이 있음

### 통쾌한 반격·복수
- [ ] 증거마다 앞의 단서가 있고 공개마다 행동·독자 판단이 바뀌며 마지막 증거가 전체 인식을 바꿈. 사전 확보 증거가 주인공 능력·시간선·수집 조건에 부합
- [ ] 냉정함은 증거 확보·선택·지연 응답·자원 배치로 표현하며 물컵 들기·정장 정돈·펜 돌리기를 상징 동작으로 붙이지 않음. 통제 상실은 행동·관계·대가를 바꿔야 함
- [ ] 악역의 반응은 가진 수단·오판·손실이 결정하고 응보는 이전 행동과 인과로 연결
- [ ] 대사 길이·중단·침묵은 양측의 수단 변화에 따름. 심판식 질문은 선택을 강요하거나 모순을 드러낼 때만 사용

### 떠난 아내를 붙잡는 서사·감정 중심 서사
- [ ] 여주인공의 마음이 식으면 완전히 떠나 남주인공을 돌보지 않으며 늦어도 유료 전환점 전까지 마음이 식고 떠남
- [ ] 남주인공에게 외모·능력·지위의 매력이 있어 독자가 재회를 기대할 수 있고 여주인공이 떠난 후에야 깨달음
- [ ] 상처가 깊으면 쉽게 용서하지 않음. 악역에게 실제 동기가 있고 인물을 멍청하게 만들어 전개하지 않음

### AI 문체
- [ ] 비유·감정어·반응은 맥락 기능으로 판단. ‘밀물처럼’, ‘가슴이 철렁했다’, ‘눈시울이 붉어졌다’ 같은 표현만으로 오류 판정하지 않음. 공허한 요약·상투 수사는 구체적 행동으로 변경
- [ ] 새 정보 없는 신체·감정 묘사 반복은 삭제하며 부위·동의 행동만 바꾸어 채우지 않음. 내면 독백은 헛도는 부분만 줄임
- [ ] 「像/好像/仿佛/如同」(마치·같이 등의 비유 표식)을 몰아쓰지 않음. 10회 초과 또는 탐지기 밀도 알림이면 각각 기능을 확인하고 기능 있는 것은 유지. 고정 상한·기계적 전체 삭제 금지
- [ ] 과한 수식·문어체를 구어·구체적 행동으로 바꿈. 관련 행동은 연결하며 3–5글자의 조각 문장으로 나누지 않음
- [ ] 감정 구현은 short-craft 2절의 맥락 지원으로 확인하고 정확한 직접 표현은 유지. 단편 매력 보호는 short-deslop 참조

### 서식
- [ ] short-format 끝의 문단 작성 후 빠른 검사 항목을 모두 확인하고 지나치게 긴 문단의 연속도 검사
```

### 비주류 장르 공식 대조

설정의 장르 참조가 `genre-writing-formulas.md`이면 「题材招式」에 적은 요점으로만 검사하며 전문을 다시 읽지 않습니다. 감정 박자가 빠지거나 뒤섞이지 않고 필수 장면·규칙이 모두 구현되며 무관한 공식을 혼용하지 않아야 합니다.
