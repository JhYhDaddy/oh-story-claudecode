# 단편 원문의 투고 측면 관찰 기준

> 인물·도입·결말 분석과 종합 평가에서 읽는다. 원문의 도입 요약, 유료 전환 지점, 제목·소개글, 플랫폼 문체를 기록한다. 원문이 어떻게 했는지만 보고하며 플랫폼은 출처 정보를 우선한다. 실제 과금 위치나 유입량을 추측하지 않는다.

## 도입 요약

도입 요약은 첫 소절 표식 이전의 몇 단락이다. 먼저 경계를 정한다. 원문에 없거나 1절과 구별할 수 없으면 그대로 적는다.

| 관찰 대상 | 기록 내용 |
|---|---|
| 네 요소 | 발단·핵심 갈등·인물의 바탕(주인공에게 숨긴 수가 있는지)·감정 전환이 각각 어느 문장에 있는가 |
| 시선을 잡는 요소 | 충격적인 물건, 독자는 알지만 가해자는 모르는 정보, 여백으로 남긴 마지막 반 문장 |
| 멈추는 지점 | 진행 중인 순간에 멈추는가, 이미 결말이나 결과까지 쓰는가 |
| 1절과의 연결 | 그대로 이어지는가, 사건의 시작으로 돌아가 도입 요약의 순간까지 오는가, 도입 요약을 재연하는가 |
| 공개한 비장의 수 | 본문에서 실현할 비장의 수를 남겨 두었는가 |

## 유료 전환 지점

분석 보고서의 ‘감정선과 폭발 지점 분석’에서 훅 기준으로 이미 기록했다. 여기서는 위치와 결론만 인용하고 다시 판단하지 않는다.

## 제목과 소개글

| 소개글 유형 | 구조 | 독자에게 약속하는 경험 |
|---|---|---|
| 성공형 | 상황 → 갈등 → 행동 → 성공 | 안전감, 확실한 승리 |
| 행동형 | 상황 → 갈등 → 행동에서 멈춤 | 서스펜스 |
| 미스터리형 | 상황 → 반전 또는 의문 하나 | 호기심 |
| 실패형 | 상황 → 갈등 → 행동 → 실패 | 고통과 분노 |
| 짧은 성공형 | 상황 → 전환 → 성공 | 경쾌함, 달콤함 |

제목·소개글·본문이 같은 핵심 경험을 제공하는지 대조한다. 제목이 신분 대비, 반대되는 말, 서스펜스, 감정적 약속 중 무엇으로 관심을 끄는지 그대로 기록한다. 제목이나 소개글 자료가 없으면 ‘원문에 제공되지 않음’이라고 쓴다.

## 플랫폼 문체

대상 플랫폼은 즈후 옌옌, 미니프로그램(뎬중 등), 헤이옌, 판체, 치마오, 훙궈다. 출처에 플랫폼이 있거나 작가가 플랫폼 비교를 요청할 때만 작성한다.

| 플랫폼 | 흔한 시점과 갈등 | 흔한 형식 |
|---|---|---|
| 즈후 옌옌 | 몰입형 1인칭, 일상의 어긋난 세부에서 시작, 심리전과 정보 격차, 여운 중심 결말 | `1.`로 절 구분, `「」` 따옴표 |
| 미니프로그램(뎬중 등), 헤이옌 | 강한 감정의 1인칭 또는 전지적 시점, 갈등을 대사·행동으로 드러냄, 공개적인 응징, 악역의 실질적 대가 | `###1.`로 절 구분, `""` 따옴표. 헤이옌은 한 문장 한 단락이며 소절이 짧은 편 |
| 판체, 치마오, 훙궈 | 매끄러운 1·3인칭, 분명한 목표, 악역의 도발이 빠르게 주인공의 발판으로 변함, 원만한 결말 | 판체·치마오는 보통 `###第N章`, 훙궈는 `###1.`, `""` 따옴표 |

원문이 실제로 쓴 시점·절 구분·따옴표, 갈등을 외부 행동으로 드러낸 정도, 결말의 느낌을 기록한다. 위 표와 어디가 가깝고 다른지 비교하되 합격 기준으로 삼지 않는다.

## 보고 형식

```markdown
도입 요약: {경계·네 요소의 위치·멈춘 지점·1절과의 연결}
유료 전환 지점: {훅 절의 결론 인용}
제목과 소개글: {유형·약속·본문과의 일치 여부; 또는 원문에 제공되지 않음}
플랫폼 문체: {출처 플랫폼과 관찰한 문체; 플랫폼 정보가 없으면 알 수 없음}
```
