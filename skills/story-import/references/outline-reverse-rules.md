# 상세 개요 역추론 규칙·템플릿(장편 가져오기)

이 파일은 묶음별 역추론 과제 패키지의 본문입니다. `build_outline_brief.py`가 전문을 패키지에 넣으므로 따로 로드하지 않습니다.

## 역추론 원칙

- 묶음의 각 장에 대해 패키지의 요약 요점에서 `개요/상세개요_제XXX장.md`를 역추론합니다. 요점에 「摘要未写」(요약에 없음)라고 돼 있는데 실제 내용을 써야 한다면 해당 장 본문의 관련 문단에서 근거를 보충합니다. 본문은 수정하지 않습니다.
- 목표 글자 수는 패키지에서 측정한 과거 길이(`visible_chars_v1` 실제 길이)를 씁니다. 창작 목표를 새로 정하거나 직접 추산하지 않습니다.
- 단위 ID는 패키지의 「卷纲剧情单元」 중 해당 장을 포함하는 범위의 카드를 사용합니다. 단위의 몇 번째 박자인지 모르겠으면 `[待补充]`.
- 후킹·관계 변화·보조선/감정선·행동 대가/이익 귀속 등 원문 요약으로 안정적으로 판단할 수 없는 필드는 `[待补充]`로 표시합니다. 근거 있는 설계도만 역추론하고 필드를 채우려고 관계·지선을 만들지 않습니다. 이미 쓴 과거 장의 「本章禁止提前释放」는 「无」. 목표 감정·주인공 목표/핵심 선택은 `[待补充]`를 허용하지 않습니다.

## 필드 대응

중국어 필드명은 실제 산출물의 계약 표식입니다.

| 요약 필드 | 상세 개요 필드 | 변환 |
|---------|---------|---------|
| 关键事件 + 局面结果 | 核心事件 | ‘누가 어떤 행동 → 상황 변화’로 합침. 옛 요약에 `局面结果`가 없으면 `关键事件`만 사용 |
| 章节字数 | 字数目标 + 字数口径 | 패키지에서 측정한 `actual`·`visible_chars_v1` 기록 |
| `基调：` + 状态变化 | 目标情绪 | 각 사건의 기조(긴장/편안함/슬픔/열혈/통쾌함/달콤함/온기/공포/억압/기타)와 상태 변화를 ‘이전→이후’로 정리. 실제 내용 필수 |
| 关键事件 + 主角行动 | 主角目标/关键选择 | 원문에서 이 장의 주인공이 원하는 것·판단·선택. 실제 내용 필수 |
| 所属剧情单元 | 单元ID/位置 | 해당 장을 포함하는 카드의 단위 ID. 단위 박자로 순서를 정하고 모르면 `[待补充]` |
| 과거 장 | 本章禁止提前释放 | 이미 쓴 장은 「无」 |
| 앞 장의 章尾钩子 | 章首钩子 | 앞 장 끝이 남기고 이번 시작이 이어받은 기대. 묶음 첫 장은 패키지의 앞 장 후킹 사용. 제1장·근거 없으면 `[待补充]` |
| 통쾌함 유형 사건 | 爽点 | 사건 유형에서 추론. 해당 사건이 없으면 「无显性爽点」 |
| 사건 기승전결 + 인과 | 内容概括（起因/发展/转折/高潮/结尾） | 사건 순서로 정리하고 인과 연쇄로 발단·전환 보정. 근거 부족이면 `[待补充]` |
| 주선·지선·과제 단서 | 情节安排（主线/辅线/事件线/感情线/逻辑线） | 단위 색인·요약에서 역추론. 근거 없는 보조선·감정선은 「无」 또는 `[待补充]`, 창작 금지 |
| 涉及 + 状态变化 | 人物关系和出场顺序 | `涉及`는 인물 후보, `状态变化`는 근거 있는 이전→이후만. 핵심 물건은 근거·옛 사건 항목에서 보완하고 없으면 `[待补充]` |
| 모든 사건 항목 | 情节细化 / 情节点序列 | 패키지의 「标题｜类型｜基调」를 항목별로 정리해 # / 情节点 / 功能标签 / 执行边界 표에 입력. 원래 순서 유지, 모르면 `[待补充]`. 항목별 글자 수 할당량을 역산하지 않음 |
| 승패·반전·득실 | 行动成本（可无）/收益归属 | 명확한 근거가 있어야 작성. 행동 대가는 없어도 되며 만들지 않음. 근거 없으면 `[待补充]` |
| 章尾钩子 + 局面结果 | 结尾设定和钩子 | 끝 설정은 원문의 마지막 구체적 행동·장면. 끝 후킹은 이미 남긴 기대. 요약에 없을 때만 `[待补充]` |

## 상세 개요 템플릿

```markdown
## 细纲（第 N 章）

### 第 N 章：{장 제목}
- 核心事件：{요약에서 추출}
- 字数目标：{패키지의 actual} 字
- 字数口径：visible_chars_v1
- 单元ID/位置：{역추론 권 개요의 소속 단위 ID; 단위 내 박자, 모르면 [待补充]}
- 目标情绪：{기조·상태 변화에서 이전→이후 정리. 감정 단어 하나만 쓰지 않고 실제 내용 필수}
- 主角目标/关键选择：{원문에서 주인공이 원하는 것·내린 판단·선택. 실제 내용 필수}
- 章首钩子：{앞 장 끝이 남기고 이번 시작이 이어받은 기대. 제1장·근거 없음이면 [待补充]}
- 爽点：{사건에서 추론. 해당 사건 없으면 「无显性爽点」}
- 本章禁止提前释放：无

#### 内容概括（五段式）
- 起因：{사건 항목에서 정리, 모르면 [待补充]}
- 发展：{사건 항목에서 정리, 모르면 [待补充]}
- 转折：{사건 항목에서 정리, 모르면 [待补充]}
- 高潮：{사건 항목에서 정리, 모르면 [待补充]}
- 结尾：{원문의 마지막 행동·장면·대사, 모르면 [待补充]}

#### 情节安排（多线）
- 主线推进：{단위 색인·요약에서 역추론}
- 辅线推进：{근거 없으면 “无” 또는 [待补充]}
- 事件线 / 任务线：{외부 사건 연쇄}
- 感情线 / 关系线：{근거가 있을 때만 작성. 없으면 “无显性” 또는 [待补充]}
- 逻辑线：原因 → 行动 → 结果 → 后果/新问题

#### 人物关系和出场顺序
- 出场顺序：{요약의 인물·세력·핵심 물건 등장 순서}
- 人物关系变化：{이 장 이전 → 이후, 모르면 [待补充]}
- 视角/信息差：{누가 무엇을 아는지·독자가 아는 것·주인공의 오판, 모르면 [待补充]}

#### 情节细化
- 情节点序列（요약의 사건을 역추론해 아래 표에 행별 입력）:

| # | 情节点（谁做了什么） | 功能标签 | 执行边界 |
|---|---|---|---|
| 1 | {} | {기능을 모르면 [待补充]} | {원문에서 이 항목이 공개하지 않은 것을 확인, 모르면 [待补充]} |
- 行动成本（可无）/收益归属：{근거가 있을 때만 작성. 행동 대가는 없어도 되며 만들지 않음. 모르면 [待补充]}

#### 结尾设定和钩子
- 结尾设定：{원문의 마지막 구체적 행동·장면, 미해결 문제, 다음 장 추진력. 모르면 [待补充]}
- 章尾钩子：{이 장 끝이 이미 남긴 기대. 요약에 없으면 [待补充]}
```

장마다 `개요/상세개요_제XXX장.md` 파일 하나를 만듭니다. 번호는 앞을 0으로 채운 세 자리이며 `본문/제XXX장_*.md`와 같습니다.
