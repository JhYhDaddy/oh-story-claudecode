# 장편 집필 전 검색

workflow-chapter.md의 3단계에서 이어진다. 주요 산출물이 없으면 해당 분기로 처리한다. 파일 위치는 [project-files.md](project-files.md)를 참조한다.

- **벤치마크 없음:** 장르 방향의 벤치마크 등록이 없음이고 `비교작품/`·`작품분석실/`에도 다른 작품이 없을 때다. (a)(b)(e)(f)는 건너뛰고 누락을 보고하지 않는다. (c)는 정상 실행한다. (d)는 `설정/문체.md`가 있으면 사용하고 없으면 기본 작법을 적용하며 오류를 내지 않는다. 감정·리듬은 상세 개요와 단위 카드에서 가져온다.
- **모듈·장르 카드·문체 검색:**
  - **성숙한 프로젝트의 짧은 경로(검색 축소):** `custom_style=true`이고 장르 카드에 내용이 있으며, 상세 개요의 목표 감정과 단위 카드의 감정/박자가 모두 유효하면 **(a)(b)(e)(f)를 건너뛴다**. 감정·리듬은 상세 개요/단위 카드에서 가져오고 (c)(d)는 정상 실행하며 (g)는 축소된 집합을 출력한다. 조립 스크립트가 판단해 검증 보고서에 기록하며 조건이 부족하면 전체 검색을 한다. 축소 시 벤치마크 감정/리듬 주요 산출물을 검사하거나 그 즉시 중단 조건을 적용하지 않는다. 대신 일치한 장의 확장 기법과 원문 근거 조각은 얻지 못한다. 목표 감정을 대충 적었으면 축소하면 안 된다.
  - ① 이번 장의 목표 감정은 무엇인가? ② 어느 참고 파일의 어떤 기법을 빌리는가? ③ 어느 문단에 쓰는가? 답할 수 없으면 참고 자료를 먼저 다시 읽고 집필한다.
  - (a) **감정 모듈 검색:** 벤치마크 작품 경로 찾기 규칙에 따라 `{对标书路径}/플롯/감정모듈.md`를 읽고 목표 감정에 가장 가까운 `selected_emotion_module` 1개를 고른다. 필드는 `读者想看什么`(독자 기대), `情绪链`(감정 사슬), `戏剧单元`(극적 단위), `可替换项`(교체 가능 항목), `不可照搬`(차용 금지 요소)다. 파일이 없으면 `missing_primary_contract: true`와 명확한 `repair_action`을 반환하고 준비를 멈춘다.
  - (b) **리듬 검색:** `{对标书路径}/플롯/리듬.md`를 읽고 `rhythm_reference` 1개를 고른다. 핵심 정보 → 확장 방식 → 감정 자극점 → 폭발 지점 → 여파/냉각의 흐름이다. 없으면 `missing_primary_contract: true`와 명확한 `repair_action`을 반환하고 준비를 멈춘다.
  - (c) **장르 본문 지침 카드 검색:** `설정/소재본문안내.md`를 우선 읽는다. 없으면 조립 스크립트 검증 보고서의 장르 카드 행이 지정한 카드를 읽는다. 주 장르는 전체 카드, 보조 장르는 흔한 장면/이탈 금지 항목 1-2개만 발췌한다. 낮은 확신도 카드는 의도 확인에 표시하고 같은 장르의 벤치마크로 보정하도록 요구한다. 보고서가 일치 카드 없음으로 표시했을 때만 `references/style-genre-modules.md`의 장르 본문 지침 카드 절과 가장 가까운 장르 절을 읽으며 색인·모듈 전체를 읽지 않는다. 짧은 `genre_prose_card`를 만들어 `설정/소재본문안내.md`에 저장하고 후속 장은 이를 바로 읽어 다시 만들지 않는다. 카드에는 장르 경계·핵심 논리·독자 기대·핵심 쾌감/감정·본문 적용 지점·초중후반 전략·리듬 밀도·장면 세분도·이탈 금지·이번 장 선택·카드 확신도를 담는다. 장르 카드는 본문의 장르 감각만 제약하며 상세 개요의 플롯을 바꾸거나 `selected_emotion_module` / `rhythm_reference` / `설정/문체.md`를 덮어쓰지 않는다. 내부 선택 보정에만 쓰고 본문에 카드명·태그·확신도·항목·준수 자체 평가를 넣지 않는다.
  - (d) **문체 검색:** explorer를 거치지 않고 `설정/문체.md`를 먼저 직접 읽는다. 실행 가능한 표현 요구가 있으면 `custom_style=true`로 하며 최소 글자 수는 없다. 공백·제목만 있음·보충 예정은 해당하지 않는다. 전문에 `style-resolution.md`를 적용해 유효 문체를 정한다. `설정/_文风摘要.md`는 색인일 뿐이며 집필·AI 말투 제거에 모두 전문 경로와 같은 `style_resolution`을 전달한다. 맞춤 문체가 있으면 벤치마크는 미지정 차원만 보충한다. 없으면 경로 찾기 규칙으로 `{对标书路径}/문체.md`를 읽되 `{项目}/비교작품/{书名}/`를 우선하고 `작품분석실/{书名}/`로 대체한다. 여러 작품이 있으면 `설정/소재방향.md`의 `主对标书` 필드를 읽는다. 필드가 현재 작품 자체를 가리키거나 없으면 현재 작품과 같은 이름의 디렉터리를 제외한 `비교작품/`의 사전순 첫 작품을 쓰고 필드 보충을 알린다. 제외 후 비면 벤치마크 없음으로 처리한다. **맞춤 문체 모드가 아닌데** 문체 파일이 없으면 **즉시 오류로 중단**한다. ‘벤치마크 《X》에 문체 분석이 없습니다. `/story-long-analyze`로 문체 분석을 보충한 뒤 이 장을 써 주세요.’ 보충 후 첫 참조 때 `비교작품/`로 동기화한다. 즉석에서 생성하지 않는다. 맞춤 문체 모드에서는 문체 누락으로 멈추지 않지만 전체 검색의 감정/리듬 축 `missing_primary_contract`는 독립적으로 차단한다.
  - (e) **일치한 장 선택:** `{对标书路径}/장별분석/*_요약.md`에서 전각 콜론을 사용하는 `基调：(紧张|轻松|悲伤|热血|爽|甜|温馨|恐怖|压抑|其他)` 패턴을 검색하고 목표 감정에 맞는 K장을 고른다. 같은 기조의 장이 여러 개면 먼저 쾌감 유형이 가까운지, 다음으로 플롯 지점 수/원문 장의 추정 글자 수가 이번 장 목표와 가까운지 보고 마지막으로 가장 작은 장 번호를 고른다. `{对标书路径}/장별분석/제K장_요약.md`는 반드시 읽고 같은 장의 `제K장_심층분석.md`가 있으면 추가한다. 없으면 초반 3장 심층 분석/문체 파일의 활용 가능한 기법으로 돌아간다. 초반 3장이 아닌 장에 심층 분석이 없다는 이유로 실패하지 않는다.
  - (f) **구조화 모듈 검색:** 벤치마크의 인물/플롯/설정 하위 디렉터리에서 이번 장 플롯과 관련된 모듈을 검색한다. `플롯/감정모듈.md` / `플롯/리듬.md`와 충돌하면 권위 파일을 우선하고 `conflict`를 기록한다.
  - (g) 주 벤치마크 검색 요약 + `副对标召回摘要` + `selected_emotion_module` + `rhythm_reference` + `genre_prose_card` + 문체 검색 지시 + 원문 근거 조각 참조를 narrative-writer 입력으로 출력한다. **벤치마크가 여럿일 때** 작품 간 검색 매뉴얼을 별도로 읽을 필요는 없다. 주 벤치마크는 문체·원문 근거 조각·사용 가능한 감정/리듬 값을 제공한다. 보조 벤치마크는 (f)에서만 모듈 예산에 따라 인물/플롯/설정 항목을 보충한다. 같은 장르는 작품당 ≤2, 약한 관련성은 0, 합계 ≤8이며 `설정/소재방향.md`의 `对标书列表` 참조 강도로 정렬한다. 보조 작품의 `문체.md`와 원문은 읽지 않는다. 예산 초과 시 항목을 줄이고 작품 목록은 유지한다. 출력에 `副对标召回摘要` 표를 첨부하며 작품명/참조 강도/관련성/검색 항목 수/사용 방식을 담는다.
  - **바로 가기:** story-explorer가 배치되었으면 문체·모듈 자료를 한 번에 검색할 수 있다. 호출과 `gaps` 분기는 agent-calls.md의 story-explorer 집필 전 벤치마크 검색을 참조한다.
