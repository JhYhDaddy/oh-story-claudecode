# 장편 본문 형식

> 표현의 기본값은 [style-resolution.md](style-resolution.md)를 따른다. 파일 구조와 사실 제약은 면제되지 않는다.

> 장편 각 장의 문단·대화·문장부호·작업 메타정보만 규정한다. 단편 전체의 소절 구조는 적용하지 않는다.

## 장과 문단

- 장 제목·번호·파일명은 프로젝트의 기존 형식을 따른다. 본문 안에 장 번호를 다시 쓰지 않는다.
- 극적 단위·장면 전환·새 행동·새 정보·새 대화에 맞춰 자연스럽게 문단을 나누고 고정 글자 수로 자르지 않는다.
- 짧은 문단은 리듬 도구이며 기본 템플릿이 아니다. 완결된 추론·분위기·감정 인과에는 긴 문단을 써도 된다.
- 쾌감 지점·전환·핵심 선택은 촘촘하게, 전환 장면·이동·이미 아는 정보의 연결은 성기게 쓴다. 모든 beat를 같은 길이로 만들지 않는다.
- 필요하면 문단 첫머리에서 인물 이름을 밝히고 중간에는 대명사·생략·행동으로 이어 간다. 문장마다 이름을 기계적으로 반복하지 않는다.
- 본문의 인접 문단 사이는 줄바꿈 `\n` 하나만 허용한다. 빈 줄이나 연속 줄바꿈 `\n\n`은 금지한다.
- 본문은 들여쓰지 않으며 `　　`(전각 공백)이나 반각 공백으로 시작하지 않는다.

## 대화

- 따옴표는 프로젝트·플랫폼 규칙을 따르고 장 전체에서 통일한다. 지정하지 않았으면 반각 큰따옴표를 쓴다.
- 대화는 독립된 행에 쓰고 연결 행동은 같은 인물의 말 앞뒤에 둔다. 모든 문장에 그가 말했다·그녀가 말했다를 붙이지 않는다.
- 물음표는 실제 질문·추궁·반문에 쓴다. 느낌표는 폭발의 정점에만 쓰고 연속 사용하지 않는다.
- 멈춤·망설임·삼킴·말 끊김·늘임은 행동·짧은 문장·줄바꿈·미완성 문장으로 표현한다. 본문과 대화에서 말줄임표·대시를 만능 멈춤 표식으로 쓰지 않는다.
- 대사는 정보·관계·전략·권력 위치를 바꿔야 한다. 긴 설정 설명은 문답·탐색·반박·행동의 결과로 바꾼다.

## 장편의 장 단위 제약

- 장 글자 수는 `visible_chars_v1`으로 잰다. 작가가 명시한 범위를 우선하며 지정하지 않으면 내부 허용 범위는 ±12%, 사용자 범위는 ±15%다.
- 글자 수가 부족하면 상세 개요에서 승인한 플롯 지점이 모두 구현됐는지 먼저 확인한다. 분량을 채우려고 독립 사건·인물·규칙·반전·복선을 추가하지 않는다.
- 초과하면 반복 설명·반복 반응·절차·기능 없는 미세 동작부터 삭제한다. 승인된 플롯 지점·인과·선택·보상·후킹은 삭제하지 않는다.
- 한 장에 여러 장면이나 beat가 있어도 되며 수는 상세 개요와 인과가 결정한다. 단편 전체의 소절 수 기준을 적용하지 않는다.

## 작업 메타정보 분리

- 제목 행을 제외한 본문 서술·대화·심리 묘사에는 이번 장·이전 장·앞부분·뒷부분·복선·상세 개요·독자 같은 집필 작업 용어를 넣지 않는다. 기존 중국어 검사 신호는 `本章、上一章、前文、后文、伏笔、细纲、读者`다.
- 연결이 필요하면 인물이 인지할 수 있는 사건 기준점이나 상대 시간으로 바꾼다. 인물이 이야기 세계 안에서 실제로 장이나 독자라는 신분을 논할 때는 예외다.
- 본문에는 굵게·기울임·구분선·검사 보고서를 사용하지 않는다. 유효한 장 제목은 예외다.
