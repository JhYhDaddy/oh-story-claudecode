# 한국어 프로젝트 경로 전환

새 프로젝트는 `설정/`, `개요/`, `본문/`, `추적/`을 사용합니다. 기존 중국어 경로는 새 목적지로 복사 변환합니다. 원본은 그대로 남습니다. 변환 후에는 새 목적지에서 story-setup을 실행하고 집필을 이어갑니다. 이전 폴더에서 새 버전으로 집필하지 않습니다.

| 이전 | 한국어 |
|---|---|
| `.story/work/제001장/前组.md`, `后组.md` | `.story/work/제001장/전반.md`, `후반.md` |
| `.story/work/排纲/核心设定.md` | `.story/work/개요작성/핵심설정.md` |
| `导入细纲_第001-012章.md` | `가져오기상세개요_제001-012장.md` |
| `设定/关系.md` | `설정/관계.md` |
| `大纲/大纲.md` | `개요/개요.md` |
| `大纲/卷纲_第一卷.md` | `개요/권개요_제1권.md` |
| `大纲/细纲_第001章.md` | `개요/상세개요_제001장.md` |
| `正文/第001章_제목.md` | `본문/제001장_제목.md` |
| `追踪/上下文.md` | `추적/문맥.md` |
| `追踪/逐章记录/` | `추적/장별기록/` |
| `追踪/角色状态/` | `추적/인물상태/` |
| `追踪/伏笔.md` | `추적/복선.md` |
| `追踪/时间线/作者真相.md` | `추적/시간선/작가용진실.md` |
| `追踪/时间线/读者已知.md` | `추적/시간선/독자가아는사실.md` |

`_tracking-state.json`과 JSON 키·상태 값은 유지합니다. 작품명·인물명·장 제목과 원고 내용은 재번역하지 않습니다. 본문과 원문 파일은 바이트 단위로 보존합니다. 본문 밖 UTF-8 Markdown·JSON·CSV·YAML·TOML·활성 작품 포인터에서는 실제 존재하는 경로 참조를 갱신합니다.

## 실행

사용 가능한 Python을 `python3` → `python` → `py` 순서로 실행 확인하여 `{PYTHON}`에 사용합니다. 아래 `{SCRIPT}`는 이 스킬의 `scripts/migrate-project-paths.py` 절대 경로입니다. 원본과 새 목적지는 절대 경로로 지정합니다.

```text
{PYTHON} "{SCRIPT}" --source "{기존 프로젝트}" --destination "{새 프로젝트}"
{PYTHON} "{SCRIPT}" --source "{기존 프로젝트}" --destination "{새 프로젝트}" --apply
```

첫 명령은 변경 예정 목록만 출력합니다. 두 번째 명령은 검증 후 새 목적지를 만듭니다. 새 목적지는 없어야 하며 상위 폴더는 있어야 합니다. 작품 한 개 또는 `长篇/短篇`을 포함한 작업 공간 전체를 지정할 수 있습니다.

이름 충돌, 원본·목적지 중첩, 심볼릭 링크·정션, 진행 중 잠금, `.git`이 있는 원본은 자동 변환하지 않습니다. Git 프로젝트는 `.git` 없는 별도 작업 복사본을 준비합니다. 변환 중 원본이 바뀌거나 복사가 실패하면 목적지를 공개하지 않습니다. 두 버전을 동시에 수정하지 말고 새 목적지의 추적 검사와 호스트 배포 검사를 마친 뒤 사용합니다.

전체 경로 대응표는 같은 스킬의 `scripts/project-paths-ko.json`입니다.
