## 공식 출처

- [도움말: 작품 정보 요구 사항](https://fanqienovel.com/writer/zone/help/article?rank1=10006&rank2=10140&rank3=10144)(2026-10-29 열람): 장편 제목은 중국어·영어·아라비아 숫자와 중국어 느낌표·쉼표·물음표·대괄호·콜론만 허용합니다. 중복될 수 없고 계약 신청 후에는 변경할 수 없습니다. 표지는 600×800, 5MB 이하이며 제목과 필명을 포함해야 합니다. 소개는 500자 이내입니다.
- 짧은 이야기 제목은 최대 25자이며 반각 문자는 0.5자로 계산합니다. 공백을 허용하지 않고, 책 제목 부호나 이모지가 있으면 계약 불가 안내가 나옵니다. 2026-10-29 관리 화면 스크립트를 읽어 확인했으며 실제 입력 테스트는 하지 않았습니다. 2022-12-14의 [이전 공지](https://fanqienovel.com/writer/zone/article/7176894591558221861)는 30자로 적혀 있으나 더 이상 유효하지 않습니다.
- [계약 방식 조정 공지(2026-10-12)](https://fanqienovel.com/writer/zone/article/7695623157880733758): 신규 작품의 경우 Lv.0/1은 완결 후 계약만 가능하고 Lv.2 이상은 연재·완결 계약을 선택할 수 있습니다.
- [작품 태그 안내(2026-03-16)](https://fanqienovel.com/writer/zone/article/7617805652965982232): 독서 태그의 주 분류는 필수입니다.
