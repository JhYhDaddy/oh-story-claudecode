# Agent Note: 단편 일반 기법과 서스펜스 자료를 기존 주제에 통합

Status: implemented
Related: [작가의 작업 시점별로 단편 자료 로드](../architecture/2026-09-26-short-write-by-moment.md)

## Problem

`story-short-write`의 `genre-writing-techniques.md`와 `short-suspense.md`에는 장편의 후속 줄거리, 성장 순환, 관계 단계를 길게 늘리는 기법이 섞여 있었다. 조건부 기법·이론 분류·상충하는 규칙도 일반 검수 요구로 묶여 있었다. 두 종합 문서에 예외를 계속 보태면 로드·관리 비용이 커진다. 사용자는 고유하고 유효한 내용만 옮긴 뒤 두 파일을 삭제하라고 요청했다.

## Decision

- `hooks-chapter.md`가 작품 전체의 핵심 질문, 부분적 보상, 최종 마무리를 맡는다. 같은 곳의 무료/VIP 연재기 순환, 장 수와 후킹 글자 수 할당은 삭제한다. 품질 빠른 참조는 충격 수준, 감정 점수, ‘긴 것 둘·짧은 것 하나’ 검수를 반복하지 않는다.
- `short-reversal.md`의 응보형 기법은 기존 복선 재확인 목록으로 가해 장면·대사·사물을 기록하고 회수할 때 공수를 뒤집을 수 있게 한다. 모든 항목을 하나씩 그대로 되갚도록 요구하지 않는다. `scene-craft.md`에 대결의 득실·우위·사용 가능한 조건·약자가 강자를 이기는 과정을 보완한다.
- 원래 두 파일과 배포 측 공유 서스펜스 사본을 삭제한다. 색인, 다른 작품의 기법 불러오기, 장르 묶음, 에이전트 profile과 템플릿을 기존 주제로 연결한다. 공유 목록에서 해당 동기화 그룹과 집필 측 구성원이 사라진 파생 그룹을 제거하고 단편 분석의 독립 관찰 자료는 유지한다.
- OpenCode·Codex 에이전트는 원본에서 재생성하고 Antigravity는 임시 디렉터리에 생성해 검증한다. 중복 설명을 대체해 이전 내용을 수용하며 파일·호출 예산은 높이지 않는다. ClawHub는 영향을 받는 패키지의 버전·정확한 의존성·지문을 함께 갱신한다.

## Alternatives considered

- 두 파일을 남겨 문장별로 고치면 기존 진입점을 유지할 수 있다. 그러나 주제별 자료와 별개인 두 번째 규칙 세트를 계속 관리하고 사용자가 삭제하라고 명시한 두 파일도 남게 되므로 채택하지 않는다.
- 내용을 전부 바로 삭제하면 변경은 가장 적다. 그러나 여전히 가치 있는 단편 의사결정 방법이 빠지므로 기존 자료와 대조해 고유한 부분을 먼저 이전한다.

## Consequences

단편 집필과 에이전트가 주제별로만 읽게 되어 장편 후속 줄거리와 중복 이론의 간섭이 줄어든다. 대신 기존 기법 종합 문서 진입점과 옛 자료 경로가 사라지며 현재 호출·배포 사본도 함께 이전해야 한다.

## 검증

저장소 정적 검사, 워크플로 번호, 문서 예산, 공유 자료·소비자 도달성, 공유 자료 회귀, 현재 계약, 참조 로드 검사, 의사결정 기록, 배포 검사, OpenCode/Codex/Antigravity 어댑터 검사를 통과했다. ClawHub는 워크플로가 고정한 중앙 스크립트 `c584f3c`와 CLI `0.23.3`을 사용해 기준 버전 및 배포 패키지 12개의 SDK 목록 비교를 통과했다.

skill-creator의 일반 `quick_validate.py`는 저장소에 원래 있던 frontmatter `version` 키를 허용하지 않는다. 이번에는 두 스킬의 frontmatter를 바꾸지 않았으며 저장소 자체의 구조화 정적 검사와 어댑터 검사를 통과했다.
