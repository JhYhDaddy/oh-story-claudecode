# 한국어 현지화 완료 기록

**최신 상태:** 사용자 노출 문구 추가 번역 후 Windows 전체 61개 검사와 Chromium 데스크톱·모바일 UI 24개 검사가 통과했다. 이전의 실패 7개는 해소했다. 원인 분류 정정과 검증 범위는 [Windows 검증 기록](WINDOWS_VALIDATION.md)을 참고한다. 아래 초기 검증 수치는 당시 이력이다.

2026-11-07 기준으로 문서·주석·예시 번역의 수동 원문 대조와 반영을 완료했다. 이번 작업에는 코드 리뷰를 포함하지 않았다.

## 완료 범위

- 루트·운영 문서 25개, 변경 이력, 기존 결정 기록 96개를 한국어로 정리했다.
- 스킬·참조·배포 템플릿·명령 안내의 수동 번역 대기 목록은 0개다. 검수 사본 352개는 수동 문서 252개, 공유 사본 78개, 생성물 22개로 구분한다.
- 장편 장르 카드 32개와 단편 참고문서의 남은 17개를 포함해 전체 대상의 원문을 대조했다.
- 주석·docstring 3,482개를 번역했다. 실행 문자열·경로·기계 지시문은 번역 대상과 구별했다.
- 예시 129개를 완료했다. 직접 번역 README 1개와 원본을 보존한 한국어 열람본 128개다. [한국어 예시 색인](../demo/ko/README.md)에서 열 수 있다.
- 라이선스 원문은 유지하고 [한국어 참고 번역](../LICENSE_KO.md)을 제공한다.

## 호환성 처리

최초 문서 번역 단계에서는 파일명·경로를 보존했다. 후속 요청에 따라 프로젝트 운영 경로도 한국어로 전환했다. 설정 키·열거값·출력 스키마·배포 식별 표식은 원형을 유지한다. 스크립트가 절을 추출하는 제목 25개와 `新增物三级` 표식에는 한국어 설명을 함께 둔다. 원문 자체의 사건·수치 불일치는 번역 과정에서 임의로 고치지 않았다.

공유 참조와 공유 자산을 동기화하고 Codex·OpenCode·ZCode·Antigravity 에이전트 및 Codex 훅을 다시 생성했다. Antigravity 생성기는 한국어 템플릿에서도 기존의 CDP 실패 처리와 웹 검색 대체 금지 정책을 적용한다. 번역된 문장을 검사하는 계약 검사는 중국어·한국어의 동등 표현을 지원하며 부정 사례도 검증한다.

한국어 번역의 실측 길이에 맞춰 문서 예산을 조정했다. 최초 통합 때 269개 예산을 조정하고 마지막 단편 카드 두 개의 파일·분기 예산을 각각 4개씩 재측정했다. 파일 목록·조건 분기·동시 읽기 조합은 늘리지 않았다. 전역 35,000자 기준은 유지하며 이를 넘는 경로 9개만 사유와 실측량을 적어 명시적 예외로 등록했다. 예외 경로도 개별 예산 검사를 받는다.

## 검증

정적 검사, 번호, 현재 스킬 계약, 인계 계약, 공유 파일·참조, 문서 예산, 장편 분석, 집필 파이프라인 45개, 작가 기억, 배포, 게시 형식, 훅 및 스캔 정책 검사를 실행했다. 대시보드 검사는 23개 통과·4개 건너뜀·실패 0개다.

문서 번역 단계의 CI 명령 59개 중 52개가 통과했고 아래 환경 제약 7개는 실패 상태로 남겼다. 전체 CI 통과를 뜻하지 않는다. 최종 정적 검사는 14개 스킬 모두 통과했으며 경고는 0개다.

예시 원본 128개는 Git 원본과 동일함을 확인했고 한국어 예시의 깨진 파일 링크는 0개다. 코드 보존은 승인된 주석 치환과 별도로 기록한 생성기·문서 계약 검사 변경을 구분해 확인했다. 예외 밖 실행 코드 변경은 없다.

수정 전 Windows 환경에서는 다음 검사를 통과하지 못했다. OpenCode의 후속 경로 변경에는 기대 문구 오류도 추가되어 있었으므로 모두 환경 제약이라고 단정한 분류는 정정한다. 이를 통과로 표시하거나 원래 검사를 느슨하게 바꾸지 않았다.

| 검사 | 확인한 제약 |
|---|---|
| `test-agent-permissions.py`, `check-antigravity-adapter.sh` | 관리 디렉터리 교체의 `rename EPERM`. 원본에서도 재현했다. 새 디렉터리에 생성한 Antigravity 출력의 본문·권한 검사는 통과했다. |

| `test-doc-budget.py` | 테스트가 만든 CRLF 문서의 절명 추출 사례가 실패한다. 원본에서도 동일하다. 실제 번역 문서의 예산 검사는 통과했다. |
| `test-scan-runtime.js` | 모의 Chrome 자식 프로세스의 CDP 포트 소유 확인 사례가 실패한다. 원본에서도 같은 사례가 실패한다. |

## 작업 증거

세부 로그와 원문 대조 자료는 저장소 밖의 작업 폴더 `F:/Novel/.localization-work/`에 보관한다. 이전 초벌 적용 스크립트는 후속 교정을 덮어쓸 수 있으므로 무조건 다시 실행하지 않는다.

- `examples-validation.json`: 원본 보존·한국어 예시 링크 검사
- `skills-reviewed-final-audit.json`: 스킬 검수 사본 및 분류 정합성
- `preservation-final-mechanical.json`: 실행 코드·원본 자료의 기계적 보존 검사
- `validation-final/`: 전체 CI 명령별 실행 로그
- `FINAL-STATUS.json`: 후속 예산 재검사와 어댑터 진단을 반영한 최종 집계
- `validation-baseline/`: Windows 실패 사례의 원본 비교
- `doc-budget-last.log`, `dashboard-final.log`: 마지막 예산·대시보드 검사

번역·통합 검증을 완료한 상태이며, 위 환경 제약의 해소와 별도 코드 리뷰는 이번 현지화 완료 범위에 포함하지 않는다.

## 프로젝트 경로 현지화 후속 작업

새 프로젝트의 실제 생성·조회 경로와 스킬·템플릿·훅·대시보드를 한국어 경로로 맞췄다. [전환 안내](../skills/story-setup/references/korean-project-paths.md)에는 이전 프로젝트를 원본 보존 방식으로 새 폴더에 복사하는 명령과 전체 주요 경로 대응이 있다. 한국어 예제 124개의 경로도 변경했으며 원본 데모는 보존했다. 파일명 길이에 따른 예산 66개를 실측 조정했고 기존 35,000자 기준과 예외 목록은 유지했다.

경로 변경 직후 검증은 61개 중 54개 통과였다. 이후 Windows 후속 수정과 재검증에서 61개 모두 통과했다. 변환 독립 테스트 10개, 대시보드 23개 통과(플랫폼 조건 4개 제외), 한국어 예제 색인의 누락 링크는 0개다.


## 사용자 노출 문구 추가 번역

대시보드 전체 표시·오류·접근성 안내, 집필 프롬프트, storyctl 도움말·분량 승인 안내, Chrome CDP 준비 도구의 안내·오류, README 실행 예시를 한국어로 바꿨다. 구간 임시 파일도 `전반.md`와 `후반.md`로 통일하고 경로 이전 규칙에 추가했다. 한국어 장 제목의 접두·접미 형식을 프롬프트가 그대로 이어받는다.

실제 브라우저 검사는 `demo/ko/files`의 임시 복사본으로 실행한다. 저장·삭제·검색·충돌·줄바꿈·상태 복원·모바일 보기 24개가 통과했다. 한국어 탭 이름이 글자 중간에서 나뉘는 표시도 보정했다. Windows 회귀 명령 61개는 모두 통과했으며, 공유 파일과 문서 예산 제한은 유지했다. 세부 로그는 `F:/Novel/.localization-work/remaining-localization/`에 있다.

### 남아 있는 중국어의 구분

- 유지 대상: 원본 데모·인명·작품명, 외부 사이트 원문을 읽는 패턴, 기존 상태 스키마·열거값·절 추출 표식, 호환 링크 앵커, 중국어 입력을 검사하는 테스트 자료.
- 남은 번역 대상: 순위 수집·집계 보고서와 일부 세션 시작·배포 안내. 추적 파생 문서·분석 실행 상태의 중국어 표제는 다른 도구가 읽는 계약과 연결되어 유지한다. 따라서 **모든 실행 출력의 한국어화가 완료된 상태는 아니다**.


## 개요·분석·추적·훅 추가 수정

개요·핵심 설정 작업 묶음과 가져오기 상세 개요 묶음의 지시문·요약 표시·오류를 번역했다. 기존 분석의 장 번호 충돌과 장 목록 재구성 안내, 영감 카드 오류도 한국어로 표시한다. 추적 수정 초안의 작성 요령·예시·길이 오류와 공통 훅의 본문 차단·상태 리비전·연속성·품질·커밋 경고를 번역하고 Python·JS·Bash 출력 검사를 맞췄다.

기존 중국어 입력과 파서 필드는 유지한다. 생성 안내의 길이 증가에 따라 해당 문서 예산 21개만 실측 조정했으며 전역 상한과 기존 예외 목록은 바꾸지 않았다. 검증 로그는 `F:/Novel/.localization-work/runtime-localization/final/`에 저장한다. 대시보드는 이번 추가 수정 대상이 아니므로 앞선 브라우저 24개 통과 결과를 유지한다.

최종 결과: Windows 전체 명령 61/61 통과. 개요 작업 경로를 `.story/work/개요작성/`, `핵심설정.md`, `가져오기상세개요_…`로 바꾼 뒤 관련 명령 10/10을 추가 확인했다. 경로 이전 테스트 11개가 통과했으며 `第001-012章` 같은 범위형 파일명도 원본을 보존하면서 변환한다. 호스트 에이전트 생성 결과를 갱신했다. 커밋·푸시는 하지 않았다.
