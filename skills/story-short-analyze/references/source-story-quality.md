# 원문의 약점과 독자 거부 요소

> 종합 평가에서 원문의 장단점을 판단할 때만 읽는다. 고통·쾌감의 분포, 대사, 증거 사슬, 독자 거부 요소를 중점적으로 본다. 원문만 평가하고 모든 판단에 위치와 증거를 붙인다. 보고서 자체의 표현은 [analysis-report-style.md](analysis-report-style.md)를 따른다. 결론은 분석 보고서의 ‘원문의 약점’에 쓴다.

## 고통과 쾌감의 리듬

고통 뒤의 통쾌함을 약속하는 원문은 다음 예시 분포와 비교할 수 있다. 비극·치유물·순수 코미디에는 적용하지 않는다.

```
이상적 분포: 고통1 → 고통2 → 고통3 → 쾌감1(작음) → 고통4 → 쾌감2(큼)
피할 분포: 고통1 → 고통2 → 고통3 → 고통4 → 고통5(쾌감이 없어 독자가 이탈)
피할 분포: 쾌감1 → 쾌감2 → 쾌감3 → 쾌감4(사전 축적이 없어 쾌감에 피로)
```

분석 규칙:
- 장면·소절이 위험·정보·관계·자원·결정·행동·독자 이해 중 실제로 무엇을 바꾸는지, 앞선 선택의 결과가 어디서 나타나는지 표시한다.
- 직접 갈등과 과업·증거·기다림·기술·공간·관계 등에서 오는 압박을 구분한다. 고정 글자 간격으로 좋고 나쁨을 판단하지 않는다.
- 가장 큰 쾌감에 어떤 선행 원인·선택·증거가 모이는지, 그 뒤 결과를 다룰 지면을 얼마나 남겼는지 기록한다. 고정 백분율로 판단하지 않는다.
- 결말이 감정의 최종 도달점, 부분적인 약속 이행, 명시적인 여파 또는 다른 마무리 방식을 사용하는지와 그 효과를 기록한다.

## 대사의 기능

| 분석 항목 | 기록 내용 | 피할 오판 |
|--------|----------|----------|
| 대사 기능 | 정보·전략·권력·관계·다음 행동을 바꾸는가 | 전체 비중으로 장면별 기능 판단을 대신하지 않음 |
| 대사 없는 장면 | 과업·물건·증거·공간·기다림·기술 중 무엇이 추진하는가 | 대사가 없다고 바로 ‘너무 건조하다’고 판단하지 않음 |
| 대화 리듬 | 발화 길이가 인물의 권력과 현장의 압박을 어떻게 드러내는가 | 효과적인 짧은 대사와 잘게 쪼갠 미니 문답을 구분 |
| 대사 비중/개수 | 이 텍스트 및 같은 소재·플랫폼 표본을 설명하는 데이터 | 소재를 초월한 통과 기준을 두지 않음 |

## 주인공의 협상 자원: 응징·복수물

| 분석 항목 | 기록 내용 |
|--------|----------|
| 주인공의 냉정함은 어떻게 보이는가? | 증거 수집·선택·응답 지연·자원 배분을 기록한다. 컵 들기·정장 정리·펜 돌리기를 보편 기준으로 삼지 않는다 |
| 감정 폭발은 어떤 결과를 낳는가? | 누적 압박·위치·행동과 관계와 대가의 변화를 기록하고 횟수·백분율로 판단하지 않는다 |
| 주인공과 악역의 대비는 어디서 오는가? | 협상 자원·판단·행동 결과·정보 격차를 기록하며 악역이 반드시 히스테릭해야 한다고 전제하지 않는다 |
| 대사 길이는 어떻게 권력을 드러내는가? | 끼어들기·침묵·회피·현장의 협상 자원과 함께 분석하고 고정 비율을 두지 않는다 |
| 심판하듯 묻는 대화가 효과적인가? | 질문이 상대에게 선택을 강요하고 모순을 드러내거나 관계를 바꾸는지 기록하며 개수로 판단하지 않는다 |

## 증거 사슬: 응징·복수물

| 점검 항목 | 기준 |
|--------|------|
| 증거를 어떻게 공개하는가? | 매 공개가 행동·독자 판단을 어떻게 바꾸는지 기록한다. 완전한 증거 사슬을 한꺼번에 제시해도 성립할 수 있다 |
| 각 증거에 사전 단서가 있는가? | 출처와 획득 조건이 제시되었는지, 핵심 반전을 되짚을 수 있는지 검사 |
| 악역 반응에 인과가 있는가? | 협상 자원·오판·손실을 기록하고 ‘먼저 우쭐하다 응징당함’의 기계적 반복인지 판별 |
| 최종 증거가 가장 치명적인가? | 그것이 바꾸는 판단·행동을 기록한다. 마지막 등장이라고 반드시 효과가 가장 큰 것은 아님 |
| ‘시한폭탄’ 증거를 사용하는가? | 미리 세운 계획이 주인공의 능력·시간선·증거 수집 조건에 맞는지 분석하며 필수로 요구하지 않음 |

## 독자 거부 요소와 읽는 느낌의 빠른 점검

판단에는 반드시 원문 증거를 인용하고 원문을 대신 고치지 않는다.

| 점검 항목 | 기준 |
|--------|------|
| 통쾌해야 할 이야기가 통쾌하지 않음 | 약속한 능력·반격 효과가 실제로 나타나는가 |
| 목적 없는 억압 | 억압이 선택·대가·후속 기대를 바꾸는가 |
| 악역의 최후가 주인공과 무관함 | 앞선 원인·인물 선택이 결말을 어떻게 만들며 주인공이 핵심 선택을 갖는가 |
| 여주인공/여성 조연을 억지로 어리석게 만듦 | 핵심 행동이 당시 정보·동기·능력에 맞는가 |
| 독자 기대를 오래 충족하지 않음 | 적절한 시점에 충족하거나 새 기대를 도입하는가 |
| 주인공 행동을 이해할 수 없음 | 동기의 이해 가능성·정서적 공감·가치 동의를 각각 검사한다. 셋이 같을 필요는 없음 |
| 갑작스러운 유머가 분위기를 깸 | 분위기 > 갑작스러운 유머(웃음 중심 작품은 제외) |
| 훅을 회수하지 않음 | 근거 있는 여백과 누락을 구분하고 응답하지 않은 약속을 설명 |
| 경악 반응의 층위 | 반응이 전문 정보·관계·행동 변화를 가져오는가 |
| 경악 반응의 단계적 상승 | 층마다 무엇이 추가되며 경악하는 말만 반복하는 것은 아닌가 |
| 경악 반응의 폭 | 여러 측의 반응이 각기 기능하는가. 전체 관계망의 반응은 요구하지 않음 |
| 구체적인 결말 | 행동·대사·이미지·성찰이 마무리를 완성하는가 |
| 여운 있는 결말 | 독자가 더 읽고 싶어 하는가 |
| 상응하는 감정 해소 | 해당 약속 아래 압박과 이행이 같은 인과 사슬에 속하는가 |
| 기대 관리 | 핵심 질문·부분 응답·후속 행동이 지속적으로 연결되는가 |
