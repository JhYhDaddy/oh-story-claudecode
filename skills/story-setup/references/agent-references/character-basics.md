# 인물의 기본 설계

> 주인공·조연·악역을 설계할 때 읽는다. 판단 경로로 템플릿을 고른 뒤 순서대로 실행한다. character-designer의 주 출력 참조다.

<a id="1절-주인공-카드"></a>
## 第1节：主角卡

1절: 주인공 카드 (절명은 자료 추출 계약 원형 유지).

### 빈칸 템플릿

```
이름:
성별:
역할: (이야기에서 하는 기능을 한 문장으로)
신분 태그: (무능한 대학생·전직 특수부대원·몰락한 황자 등)
외모: (기억할 특징 3–5개)
  예: 키 크고 마름, 늘 낡은 재킷, 왼손 흉터, 나른한 눈빛
성격 핵심어: (모순되는 면을 포함해 3–5개)
  예: 독설하지만 여림, 차가워 보여도 자기편을 감쌈, 충동적이지만 선은 지킴
핵심 목표: (작품 끝에 이루려는 것)
핵심 동기: (반드시 이뤄야 하는 이유. 이성보다 감정의 동력)
치명적 약점: (실수하게 만드는 성격 결함, 능력 결함이 아님)
말버릇/특징적 행동: (즉시 알아볼 표지)
```

### 설계 요점

- 동기는 감정 차원이어야 한다. 최강이 되기보다 어머니의 복수가 낫다.
- 약점은 중요한 플롯에서 실제 실수를 일으켜야 한다. 아니면 약점이 아니다.
- 외모와 말버릇은 기억의 기준점이므로 반드시 쓴다.
- 이름은 시대·지역·문화에 맞춘다. 설정과 어긋나는 현대적/정치적 이름은 피한다. 팬픽/기존 세계관에서는 공식 본명·번역명을 유지하고 새 이름을 만들지 않는다. 새 인물은 해당 지역의 작명·번역 관행을 따르며 같은 지역에 언어 계통을 섞지 않는다.

## 2절: 조연 카드

### 빈칸 템플릿

```
이름:
성별:
기능: (스승/동료/정보원/희생자/거울 같은 대비 인물)
주인공과의 관계:
핵심 특성: (핵심어 1–2개)
대표 특징: (한 문장으로 기억하게 하기)
퇴장: (언제/어떻게 이야기에서 나가는가)
```

### 설계 요점

- 기능을 명확히 한다. 기능 없는 인물은 등장시키지 않는다.
- 퇴장을 미리 계획하며 쓰다가 잊지 않는다.
- 같은 장면에서 대사 있는 조연은 3명 이하로 한다.
- 이름은 시대·지역·문화를 따른다. 팬픽/기존 세계관에서는 엑스트라와 새 조연도 해당 지역의 원작 작명 방식을 따르며 언어 계통을 섞거나 설정에 안 맞는 현대적/정치적 이름을 넣지 않는다.

<a id="3절-악역-설계"></a>
## 第3节：反派设计

3절: 악역 설계 (절명은 자료 추출 계약 원형 유지).

### 3.1 악역 단계표

버틸 플롯 길이로 단계를 고르고 표에 따라 설계한다.

#### 작은 악역(플롯 단위 하나 안에서 해결)

| 차원 | 요건 |
|------|------|
| 기능 | 한 단위의 장애 |
| 설계 | 거만함·탐욕·약자에게 강함 등 뚜렷한 특징 1–2개 |
| 퇴장 | 패배/폭로로 깔끔하게 |

#### 중간 악역(한 권의 주된 상대)

| 차원 | 요건 |
|------|------|
| 기능 | 한 권의 주요 상대 |
| 동기 | 왜 맞서는가. 순수한 악만으로는 안 됨 |
| 수단 | 무력·권모술수·자원 |
| 위상 | 최소 한 번 주인공을 이겨 독자가 이를 갈게 함 |
| 퇴장 | 정면으로 패배하며 쾌감 제공 |

#### 큰 서사 구간의 보스(한 권~여러 권)

| 차원 | 요건 |
|------|------|
| 기능 | 한 단계의 핵심 갈등 대표 |
| 인물 변화 | 자기 목표·논리가 있는 완전한 변화 곡선 |
| 갈등 | 이익뿐 아니라 이념 충돌 |
| 대결 | 최소 한 번 주인공을 절망적 상황에 빠뜨림 |
| 다른 면 | 미워할 수만은 없는 면 하나 |
| 퇴장 | 의식 같은 무게가 있는 최종전+여운 있는 퇴장 |

#### 최종 보스(작품 전체)

| 차원 | 요건 |
|------|------|
| 기능 | 전체 핵심 갈등의 구체화 |
| 복선 | 첫 장부터 존재 |
| 대립 | 주인공 목표/동기와 직접 대립하며 주제의 반대편 대표 |
| 실력 | 주인공을 압도하여 변모해야만 승리 가능 |
| 신념 | 단순한 광인/괴물이 아닌 신념 보유 |

### 3.2 절대 원칙

- 악역의 지능/실력이 주인공 승리의 가치를 정한다. 약하면 이겨도 의미가 없다.
- 악역 시각에서 납득할 내적 논리가 있어야 한다.
- 주인공을 이기게 하려고 악역을 멍청하게 만들지 않는다.

### 3.3 네 구축 요소

하나도 빠뜨리지 않고 순서대로 한다.

1. **실력 시연**: 등장부터 능력/수단을 보여 준다.
2. **믿을 만한 동기**: 자기 시각에서는 행동이 말이 된다.
3. **실제 위협**: 최소 한 번 주인공을 이긴다.
4. **최종 의도 공개 시점**: 진짜 목적은 핵심 반전까지 남긴다.

### 3.4 성격 확립의 네 단계

| 단계 | 실행 |
|------|------|
| 1. 악역도 꿈이 있음 | 자기 눈에는 자기 이야기의 주인공 |
| 2. 상처 입은 과거 탐색 | 누가 키우고 사랑하고 해쳤는가? 피하려는 고통은 무엇인가? |
| 3. 성격 결함 강화 | 역경에서 좋은 특성 대신 결함을 벼림. 장점 자체가 치명적 결함 |
| 4. 주인공의 거울 | 악역 장점이 주인공 약점을 비춤. 정반대이므로 만날 때마다 마찰 |

### 3.5 무게감 표현의 핵심

- 장애는 악역의 인물상에서 나와야 하며 주인공을 막으려고 억지로 만들지 않는다.
- 명확한 동기→동기에서 행동→행동이 장애→악역의 무게가 장애 강도를 만든다.
- 유난히 강한 악역은 더 높은 수준·지혜·뜻밖의 방식으로 돌파해야 한다.

## 4절: 동기 설계

### 4.1 동기 사슬 템플릿

```
원인(Cause)       → 겪은 일
의도(Intent)      → 하려는 일
제약(Constraint)  → 막는 것
위험(Risk)        → 실패의 대가
```

**예**:
```
원인: 어머니가 원수에게 살해됨
의도: 범인을 찾아 복수
제약: 범인은 당대 권신이고 주인공은 평민
위험: 실패하면 가문이 몰살되고 성공하면 현재 생활 전부를 잃음
```

### 4.2 설계 요점

- 원인은 구체적이어야 한다. 괴롭힘보다 모두 보는 앞에서 뺨을 맞음이 좋다.
- 제약은 강해야 한다. 없으면 계속 압도해 긴장이 없다.
- 위험은 실제여야 한다. 중요한 것을 잃을 수 있다고 독자가 믿어야 한다.
- 동기는 플롯에 따라 변해도 되지만 갑자기 바뀌면 안 된다.
- 원인은 세계의 압박(힘 없이는 자위 불가)·특전의 이익·가족/친구의 처지에서 찾는다.
- 외부 동기 외에 내적 꿈도 준다. 목표는 신분에 맞춘다. 종문의 성녀가 종문을 구하려는 것은 자연스럽지만 잡역 제자라면 설득력이 부족하다.

### 4.3 동기 충돌 유형

내적 갈등이 필요하면 다음에서 고른다.

| 유형 | 정의 | 예 |
|------|------|------|
| 목표 vs 도덕 | 원하는 일과 해야 할 일 | 복수하되 무고한 이는 해치기 싫음 |
| 감정 vs 이익 | 감성과 이성의 줄다리기 | 믿을 수 없는 줄 알지만 놓지 못함 |
| 단기 vs 장기 | 당장 이익과 큰 목표 | 타협해 생존 vs 원칙으로 미래에 걸기 |
| 자신 vs 타인 | 개인 욕구와 타인 기대 | 평온을 원하지만 가문의 사명 부담 |

## 5절: 인물 구축 방법 빠른 참조

### 5.1 핵심 원칙

**주인공 행동의 세 필수 조건**:
1. **이해 가능**: 왜 하는지 알아야 한다.
2. **공감 가능**: 생각에 자신을 대입할 수 있어야 한다.
3. **수용 가능**: 가치관을 받아들일 수 있어야 한다.

**설명보다 보여 주기**:
- 목적은 서술자의 해설 대신 행동으로.
- 행동은 형용사 나열 대신 구체적 움직임·결정으로.
- 태도는 내적 독백 대신 대화·반응으로.

### 5.2 대비 설계

중요 인물마다 세 층을 쓰고 최소 한 층을 나머지 둘과 반대로 만든다.

| 층 | 뜻 | 예 |
|---|---|---|
| 신분 | 밖에서 보는 신분 | 재벌가에서 버림받은 아내 |
| 겉 행동 | 밖에 보여 주는 행동 | 욕에도 대꾸하지 않고 쫓겨나도 저항 없음 |
| 내면 핵심 | 진짜 계획·성격 | 몰래 녹음·증거 수집·재산 사전 이전 |

- 대비는 행동의 대조로 쓰고 서술자가 짚지 않는다. 내면은 핵심 선택 때 공개하며 늦을수록 충격이 크다.
- 외모·신분·취미·성격을 어긋나게 짝짓는다. 험악하지만 여림, 꽃꽂이 잘하는 킬러, 지하방의 재벌 자제 등.
- 주인공과 핵심 조연은 강한 대비 한 층을 준다. 기능성 조연은 태그 한두 개면 되며 억지로 입체화하지 않는다. 신비·압박감을 지킬 고수는 평면적으로 남겨도 된다. 내력과 약점을 다 쓰면 오히려 약해 보인다.
- 큰 대비는 일부 독자를 밀어낼 수 있으므로 목표 취향에 맞게 조절한다.

### 5.3 특성 표현법

| 방법 | 실행 | 예 |
|------|------|------|
| 민감성 | 약점을 건드려 반응 관찰 | 당황·급히 도주·주의 돌리기가 다른 성격 |
| 회피 | 피하는 행동으로 약점 암시 | 무엇을 안 하는지가 더 깊은 성격을 드러냄 |
| 장점 먼저, 결함 나중 | 먼저 매력을 주고 결함 공개 | 좋아해야 결함도 용인 |

### 5.4 조연 활용

- 대변인: 주인공이 하기 어려운 말·독한 태도·굴욕을 충성스러운 조연/동료에게 맡겨 격을 지킨다.
- 임무 거점: 단기·장기 일을 여럿 지닌 조연을 둔다. 단위를 끝낼 때마다 돌아와 새 일을 받고 그가 퇴장할 때 더 큰 이익을 얻는다.
- 인물로 인물 연결: 좋아하는 인물의 가족·절친·적을 써 호감을 잇는다. 관심 없는 인물은 적시에 퇴장시킨다.

### 5.5 과거·현재·미래의 세 시간선

| 시간 | 내용 |
|--------|------|
| 과거 | 출신·변고·성격의 원인 |
| 현재 | 주인공과의 관계·상호작용 방식 |
| 미래 | 강해질 동력/위기. 스승 납치·여주 체포·악역의 비밀 폭로 등 |

### 5.6 조연의 집착 설정

곁가지 조연을 빨리 받아들이게 하는 방법이다.

- 집착 하나를 주고 행동·취미·성격을 그 주위에 배치한다.
- 매번 연결할 필요는 없다. 충돌하는 내용을 피하고 중요할 때 밝히면 된다.
- 지나치게 극단적이면 친근한 작은 특징을 더해 공감을 돕는다.
- 곁가지 조연용이며 자주 나오는 핵심 조연에는 맞지 않는다.

### 5.7 행동의 반복점

장편에서 인물 일관성을 유지하는 핵심 방법이다.

- 행동 특성 하나를 붙잡고 반복한다.
- 독자가 좋아하는 유형→구체적 행동→여러 장면에서 반복 순으로 만든다.
- 인물의 볼거리+핵심 볼거리로 층위를 만들고 순환하며 차별화한다.
- 악역·조연도 반복 볼거리가 필요하다. 사랑할 만한 악역은 신선함을 더한다.

### 5.8 인물 설정 중심의 행동

행동·언어·사고 모두 인격을 중심으로 한다. 플롯 때문에 설정에 안 맞는 행동이 필요하다면 인물보다 플롯을 먼저 고친다.

### 5.9 인물이 사건을 미는 경우와 사건이 인물을 미는 경우

| 방식 | 특징 |
|---------|------|
| 인물→사건 | 성격·동기·선택의 자연스러운 결과가 플롯이 되어 변화 곡선 심화 |
| 사건→인물 | 외부 사건이 균형을 깨 진짜 자아를 드러내게 함 |

막히면 사건을 억지로 짜지 말고 인물 동기에서 방향을 찾는다.

## 6절: 주인공의 특수 문제

### 6.1 주인공의 격

- 독자의 몰입 기반이므로 격이 있어야 한다.
- 지능을 낮춰 보이는 내적 독백과 욕설을 너무 많이 쓰지 않는다.
- 완벽하지 않아도 되지만 깔보게 만들지는 않는다.
- 도발 대응은 실력·경험에 따른다. 강하면 담담하게, 부족하면 참고 준비한다. 발끈해 이성을 잃은 반격은 독서 경험을 해친다.

### 6.2 성장 곡선

네 단계마다 눈에 보이는 사건을 둔다.

1. 촉발: 현상태가 깨지고 기존 방법/신념이 통하지 않는다.
2. 변화 준비: 새 방법을 시도하고 대가를 낸다. 반복해도 되지만 매번 행동 변화의 증거를 하나 남긴다.
3. 전환점: 핵심 선택에서 처음 새 방식으로 고른다.
4. 새 상태: 이후 비슷한 상황에서 안정적으로 새 방식으로 행동한다.

- 힘뿐 아니라 정신과 선택에도 성장을 쓴다.
- 웹소설 주인공은 반드시 내적으로 성장할 필요는 없다. 처음부터 가치관이 완성되고 설정이 안정적이면 몰입하기 쉬우며 곡선을 실력·지위에만 두어도 된다.

### 6.3 주인공의 금지선

다음 유형은 쓰지 않는다.

| 금지 | 설명 |
|------|------|
| 과도한 선인형 | 원한을 은혜로 갚고 자기편 이익으로 명성을 삼. 독자는 시원함을 원함. 원칙 준수·보상 있는 선행은 해당하지 않음 |
| 생각 없는 전투 기계 | 감정 공감 어려움 |
| 내면이 악함 | 몰입 불가 |
| 어리석음·무분별한 선의·실력에 안 맞는 기초 실수 | 용서받기 어려움. 불가항력/정보 차이로 인한 실수는 가능 |
| 자포자기 | 괴롭힘당하는 것보다 더 싫어함 |

### 6.4 출발 수준이 너무 높을 때

**위험 신호**:
- 능력·지위·자원이 상한에 닿아 성장 공간이 없다.
- 쉽게 쓸어버리는 반복으로 긴장이 사라진다.
- 독자가 다음 회차를 기다릴 동력을 잃는다.

**해결**:
- **기세는 낮추되 사람은 깎지 않기**: 기세와 기대를 낮추고 능력·존엄은 억누르지 않는다.
- **차원별 격차**: 한 면이 강해도 다른 차원에는 약점이 있다.
- **초과 수확**: 큰 수확인 줄 알았는데 계산해 보니 더 크다.
- 극한 수련·종말·미스터리처럼 긴장하는 장르에서는 언제든 수습해 줄 뒷배를 주지 않는다. 뒷배가 위기감을 없애면 안 된다.

### 6.5 도입부의 인물 설정

- 선택으로 세운다. 초기에 한 번 선택하게 하여 어떤 사람인지 보여 준다.
- 무적·인식 차이형 시작에서도 힘 자체보다 힘을 어떻게 쓰는지로 세운다.
- 남이 감히 못 하는 일·할 수 없는 일·그렇게 할 줄 생각 못 한 일로 행동력을 보인다. 인물상에 이유가 있어야 하며 뜻밖의 전개를 위해 무너뜨리지 않는다.
- 호색·탐욕·뒤끝 같은 비호감 면은 처음부터 밝히고 나중에 갑자기 성격을 바꾸지 않는다.

### 6.6 두 신분과 두 특전

| 차원 | 정의 | 기능 |
|------|------|------|
| 드러난 신분 | 사회적 신분/직업+상태 | 초반 갈등을 모으며 계속 성장/교체 필요 |
| 숨은 신분 | 비범한 출신 | 중후반 갈등 집결 |
| 드러난 특전 | 시스템·옥패·회귀 기억 | 초기에 얻어 작품 관통 |
| 숨은 특전 | 성격 | 남과 다르게 만드는 점 자체가 특전 |

**좋은 방식**: 첫 3장에서 한 선택으로 인물을 세우고(6.5) 이후 특전 장면으로 층층이 깊게 한다.
**인물과 작품의 기질**: 세계 기조와 맞아야 한다. 사회적 신분+출신+특전+성격 네 가지를 긴밀히 통일한다.

## 7절: 악역 구축 심화

### 7.1 핵심 원칙

- 오래 기억되는 악역은 완전한 세계관과 논리적으로 일관된 가치관을 가진다.
- 같은 외부 사건도 사람에 따라 다른 변화를 낳는다. 외적·내적 요인이 공명한다.
- 외부 사건만 있고 내적 가치관·논리가 없는 설계는 피한다.

### 7.2 악역도 주인공처럼 쓰기

**기존 문제**: 무대 이동 후 옛 악역이 뒤처지고 새 악역은 전형적 얼굴뿐이다.

**해법**:
- 악역을 주인공처럼 쓴다.
- 조연이 주인공을 돋보이게 하는 데 더해 조연이 조연도 돋보이게 한다.
- 새 무대로 옛 인물의 가치를 드러낸다. 옛 인물의 무능으로 새 무대의 어려움을 보여 주지 않는다.

## 품질 점검표

인물 설계 뒤 항목별로 확인한다.

### 주인공

- [ ] 최강이 되겠다는 공허한 말이 아닌 감정적 동기.
- [ ] 중요한 플롯에서 실수를 일으키는 치명적 약점.
- [ ] 외모에 기억할 핵심어 3–5개.
- [ ] 말버릇/특징적 행동.
- [ ] 독자가 깔보지 않을 격.
- [ ] 과도한 선인·전투 기계·악한 내면·어리석은 실수·자포자기 금지선 준수.
- [ ] 핵심 목표와 전체 주선 일치.
- [ ] 주요 인물의 세 층 태그 중 최소 한 대비를 행동으로 표현.
- [ ] 실력·돈·인맥·배경 등 전개를 바꾸는 설정 최소 3개. 취미는 기억 표지로만 사용.

### 조연

- [ ] 스승·동료·정보원·희생자·거울 인물 등의 명확한 기능.
- [ ] 핵심어 1–2개로 요약되는 특성.
- [ ] 기억할 대표 특징.
- [ ] 계획된 퇴장.
- [ ] 한 장면의 대사 있는 조연 최대 3명.

### 악역

- [ ] 단계와 분량의 일치.
- [ ] 등장 시 실력/수단 시연.
- [ ] 자신의 시각에서 납득할 동기.
- [ ] 중간 악역 이상은 최소 한 번 주인공에게 승리.
- [ ] 지능을 낮춰 승리를 헌납하지 않음.
- [ ] 큰 구간 보스는 이익뿐 아니라 이념 갈등.
- [ ] 최종 보스는 첫 장부터 복선.

### 동기

- [ ] 괴롭힘 같은 모호한 말이 아닌 구체적 원인.
- [ ] 계속 압도할 수 없게 하는 강한 제약.
- [ ] 중요한 것을 잃을 수 있다고 믿을 만한 위험.
- [ ] 변화에 준비가 있고 갑작스럽지 않음.

### 구축

- [ ] 목적을 해설보다 행동으로 보여 줌.
- [ ] 행동·언어·사고가 인물상을 따르며 플롯 때문에 설정을 바꾸지 않음.
- [ ] 주요 인물의 반복 행동으로 장편 일관성 유지.
- [ ] 조연이 주인공과 명확히 연결되어 활약을 빼앗지 않음.
- [ ] 내면 핵심은 미리 해설하지 않고 중요한 선택 때 공개.
