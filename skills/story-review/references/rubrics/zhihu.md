# 단편 Quality Rubric

## 채점 기준

공통 rubric에 추가하며 모든 단편(즈후 옌옌·판체·치마오·헤이옌·훙궈·미니앱·플랫폼 미정)에 사용한다. 플랫폼별 형식·따옴표·도입문 요구는 `설정.md`의 `平台基调`(플랫폼 기조)를 따른다.

| 지표 | PASS 기준 | FAIL 기준 |
|------|----------|----------|
| 일인칭 | ‘나’ 시점에서 아는 정보와 서술 태도가 일치한다 | 정한 일인칭에서 근거 없이 시점을 바꾼다. 다른 시점을 명시적으로 쓰면 이 항목으로 오류 판정하지 않는다 |
| 감정의 밀고 당기기 | 핵심 장면에 기대→실망→놀라움 등의 변화가 있고 연결 문단이 변화를 돕는다 | 여러 문단 연속 새 정보나 행동 없이 같은 감정을 반복한다 |
| 반전 설계 | 반전이 있는 작품은 앞에 복선이 있다 | 복선 없는 반전. 반전 없는 설계라면 응보나 관계의 보상이 실현되는지 본다 |
| 결말 여운 | 작품의 감정 목표를 실현하고 구체적인 결과나 감정의 여운으로 닫는다 | 공허한 요약뿐이거나 약속한 감정이 실현되지 않는다 |
| 형식 준수 | 짧은 문단 위주로 장단/밀도 변화가 있고 빈 줄이 없으며 대화 형식이 플랫폼 기조에 맞는다 | 전체 문단 길이가 같거나 긴 문단/빈 줄/대화 태그가 연속된다 |
| 도입 훅 | 첫 문장이 행동·갈등·궁금증으로 읽을 이유를 세운다 | 첫 문장이 묘사/배경뿐이다. 이탈률은 실제 데이터로 검증해야 한다 |
| 글자 수 통제 | 이번에 확정한 범위 안이며 확인된 투고 요구를 따른다 | 작가가 범위를 바꾸지 않았는데 초과하거나 부족하다 |

## 사용 방식

- 훅·반전·감정 전달을 검토할 때 대조한다.
- 참고 항목이며 이것만으로 필수 수정으로 정하지 않는다. 서술 시점과 마무리는 이 작품에서 정한 문체에 따라 검사한다.
