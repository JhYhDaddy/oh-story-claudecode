# 판체 소설 출판 자료

메타데이터의 `장편`은 파일 저장 시 사용하는 필드·선택지·상한이며 형식 검사가 직접 읽는다. 단편의 같은 규칙은 `fanqie-short.md` 첫머리에 있다. 플랫폼 필드명과 선택값은 입력·검증 계약이므로 중국어 원형을 유지한다.

## 확인 범위

- 장편 읽기 태그·내용 태그: 2026-10-25 웹의 ‘작품 관리 > 소설 > 작품 생성’ 남성향/여성향 팝업 스크린샷과 대조했다.
- 단편 분류·게시 설정: 2026-10-28 웹 단편 관리 화면 스크린샷과 대조했다(Lv.2 계정, 미게시 초안).
- 제목·표지·소개 요구 사항: 판체 작가 도움말의 ‘작품 정보 요구 사항’을 2026-10-29에 읽었다.
- 위 날짜는 확인일이며 플랫폼 갱신일이 아니다. 앱·다른 계정 등급·빈값 차단·제출 결과는 확인하지 않았다. 현재 화면과 자료가 다르면 화면을 따르고 차이는 `待平台核实`(플랫폼 확인 대기)에 기록한다.

## 작품 유형부터 구분

장편과 단편은 필드가 다르므로 후보를 서로 바꿔 쓰지 않는다.

- 장편: 대상 독자를 먼저 정한 뒤 `fanqie-reading-male.md` 또는 `fanqie-reading-female.md`에서 읽기 태그를 확인한다. 내용 태그는 `fanqie-content-tags.md`를 읽는다. 대상 독자가 미정이면 읽기 태그를 고르지 않는다.
- 단편: `fanqie-short.md`만 읽는다.

`作者/笔名`(작가/필명)은 판체의 작품 생성 필드가 아니다. 표지와 나중의 양식 작성을 위해 자료에 기록하되 플랫폼의 필수 입력이라고 말하지 않는다.

판체에는 두 가지 작품 생성 경로가 있다. 독립 생성 양식은 제목과 계약 방식을 요구한다. ‘먼저 장 쓰기’ 경로는 자동으로 ‘作者ID的新书’(작가 ID의 새 책)라는 이름과 연재 기본값을 부여한다. 이 기본값을 작가의 확정값으로 보지 않는다. 이후 자료 보충·장 제출 시 어떤 필드를 더 채워야 하는지는 아직 확인하지 않았다.

계약 글자 수(연재는 2만 자부터 신청 가능), 일일 신규 생성·갱신 한도는 계약과 게시 규칙이며 작품 생성 문턱이 아니다. 작가가 물으면 관리 화면 표시를 기준으로 확인하도록 안내한다.
