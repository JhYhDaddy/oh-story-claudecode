# 단편 분석 접근법

Stage 2–3과 Stage 4–6에서 각각 이 파일을 읽는다. 무엇을 어떤 순서로 분석하며, 어떤 방식은 피해야 하는지 설명한다.

## 분석 접근법

### 핵심 원칙

| 원칙 | 설명 |
|------|------|
| 이야기 핵심을 중심으로 | 먼저 이야기의 핵심 발상을 한 문장으로 찾고 모든 분석을 그 중심으로 전개한다. 핵심이 바뀌면 작품 전체의 분석 방향도 달라진다 |
| 독자 관점 우선 | 매 단계에서 독자 경험을 출발점으로 삼는다. 무엇을 보았고 느꼈으며 왜 관심을 갖는가? 창작자의 동기를 추측하지 말고 텍스트가 실제로 만들어 낸 독자 경험만 분석한다 |
| 재사용 가능성 지향 | 중요한 분석에서 다른 작품에 옮길 수 있는 구조·서사 기능·적용 조건을 뽑는다 |
| 폭발 지점 중심 | 단편 분석의 핵심 질문은 무엇이 독자의 감정을 폭발시키고 공유하고 싶게 만드는가이다. 폭발 지점을 찾아 사전 축적과 해소 원리를 분석한다 |
| 공감과 확산 | 어떤 사건이 공감과 토론을 일으킬 수 있는지 설명한다. 실제 확산 효과는 독자 반응이나 시장 데이터로 뒷받침해야 한다 |

### 분석 순서: 바깥에서 안으로 단계적으로

이야기 핵심과 구조 → 감정선과 폭발 지점 → 반전과 작법 기법 → 인물과 도입·결말 → 공감·화제성·종합 평가. 순서대로 Stage 2–6에 대응한다.

### 단계별 핵심 질문

분석의 목적은 질문에 답하는 것이며 기계적으로 표를 채워서는 안 된다. 각 단계에는 핵심 질문이 하나씩 있다.

| 단계 | 핵심 질문 | 답하지 못한다면 |
|------|----------|-------------|
| 이야기 핵심 | 이 이야기가 무엇을 매력으로 내세우는지 한 문장으로 설명할 수 있는가? | 아직 이해하지 못했으니 서둘러 분석하지 않는다 |
| 구조 | 텍스트를 어떻게 배치했는가? 발단/전개/절정/결말은 각각 얼마나 차지하는가? | 배치가 리듬을 결정하므로 배치를 모르면 리듬도 모른다 |
| 인물 | 주인공은 누구이며 능동형·수동형 인물은 누구인가? | 누가 이야기를 추진하는지 모르면 어떻게 움직이는지도 모른다 |
| 감정선 | 독자의 감정을 어떤 단계로 밀고 당기는가? | 단편의 핵심 가치이므로 분석하지 못하면 작업의 의미가 없다 |
| 작법 기법 | 어떤 기법으로 독자에게 이 경험을 만드는가? | 재사용 가능한 기능 단위로 분해하지 않으면 다른 작품에 옮길 수 없다 |
| 공감+폭발 지점 | 어떤 사건이 공감이나 토론을 일으킬 수 있는가? | 텍스트의 작용과 독자 경험 사이의 연결이 빠져 있다 |
| 종합 평가 | 어떤 구조를 재사용할 수 있으며 조건과 위험은 무엇인가? | 다음 작품의 참고 자료로 쓸 수 없다 |

### 분석 제약

1. **평가에는 근거가 필요하다** — 작동 원리와 텍스트 효과를 설명하고 ‘좋다/나쁘다’만 쓰지 않는다. 점수에는 위치와 증거를 붙인다.
2. **경험에서 기법을 역으로 찾는다** — 독자의 감정 정점을 먼저 찾고, 그 정점을 만든 기법을 역으로 분석한다.
3. **망라보다 깊이를 우선한다** — 핵심 항목인 이야기 핵심/폭발 지점/공감은 깊이 분석하고 선택 항목은 필요에 따라 다룬다.
4. **전용에는 조건이 필요하다** — 재사용할 구조를 추릴 때 적용 상황과 실패 위험도 함께 설명한다.
