# 치마오: 수집과 분석

순위는 먼저 `/browser-cdp`로 Chrome을 시작한다. 서고 신작은 웹페이지를 직접 요청하므로 Chrome이 필요 없다.

## 기본 명령

`--channel`은 Phase 1 채널에 따른다. male=남성향, female=여성향, all=둘 다 수집.

```bash
node scripts/qimao-rank-scraper.js --channel all --type hot --period day --outdir {outdir}   # 남녀 채널 대인기 일간 순위
```

작가가 신작 중 떠오르는 것을 보려면 신작 순위와 서고 신작을 추가한다.

```bash
node scripts/qimao-rank-scraper.js --channel all --type new --outdir {outdir}    # 남녀 채널 신작 순위
node scripts/qimao-rank-scraper.js --source library --pages 3 --outdir {outdir}  # 서고 신작 첫 3페이지(최대 10)
```

서고 신작은 모든 채널의 ‘30만 자 미만·3일 이내 갱신·연재 중’을 조회순으로 정렬한 앞쪽 페이지다. 페이지당 15권이며 순위가 곧 조회 순위다. 인기 수치는 없고 글자 수 중앙값을 낮추므로 장르·글자 수·태그만 본다. 작가에게 ‘치마오에서 최근 사흘 동안 갱신 중인 30만 자 이내 신작을 조회순으로 첫 3페이지 수집한다’고 설명한다.

## 선택 매개변수

- `--type`: hot 대인기 / new 신작 / finish 완결 / collect 소장 / update 갱신 / all 전체.
- 대인기 순위는 `--period day|month|all`로 일간·월간·둘 다를 고른다. 기본값은 일간이며 다른 순위는 기간을 구분하지 않는다.

## 필드와 인기 측정 기준

순위·제목·작가·장르·분류 태그(집계 시 태그에 포함)·상태·글자 수·인기(핵심 지표이며 집계의 인기 기준, 서고 신작에는 없음)·최신 갱신·작품 페이지 링크·소개를 수집한다. 서고는 분류 페이지에서 대분류를 보충하고 얻지 못하면 소분류를 쓴다. 집계에 매우 세분된 장르명이 나타나면 출처부터 확인한다.

## 수집되지 않을 때

- 터미널에 「页面实际榜单与请求不一致，已跳过」가 나오면 원하는 채널·순위로 전환하지 못한 것이다. Chrome에서 해당 남성/여성 순위와 순위 탭을 직접 한 번 클릭하고 그 항목만 다시 수집한다.
- 머리말 「数据质量」에 문제가 표시되면 「问题摘要」를 본다. 인기·링크 누락이 많으면 인기값이 있는 작품만 결론에 쓴다.

## 분석 차원

| 차원 | 확인할 내용 |
|---|---|
| 대인기 순위 | 인기 순위와 유입 집중도 |
| 신작 순위·서고 신작 | 유입 유행 후보. 대인기 순위 및 비교 가능한 이전 시점과 대조 |
| 완결 순위 | 오랫동안 가치를 유지하는 작품 |
| 인기 | 플랫폼 공개 지표. 같은 기간끼리 비교하고 독자 수로 환산하지 않음 |

## 플랫폼 독자

무료 읽기이며 독자층이 넓다. 빠른 리듬·강한 플롯·늘어지지 않는 전개를 원한다. 문학적인 허세·느린 리듬·통쾌함 부족은 기피 요인이다. 남성향은 역전·응징, 여성향은 강한 감정·달콤함과 고통의 밀고 당기기에 기운다. 편집자 선호(과거 자료이며 이번 순위를 우선): 후회와 재결합·시대 배경의 달콤한 로맨스·여러 남성 인물의 관계 쟁탈.
