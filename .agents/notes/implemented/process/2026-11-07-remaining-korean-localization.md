# Agent Note: 사용자 노출 문구 추가 한국어화

Status: implemented

## Problem

문서와 경로 현지화 뒤에도 대시보드, 집필 CLI, 생성 프롬프트, Chrome 준비 도구와 README 실행 예시에 중국어가 남았다. 기존 문서 번역에서 보존했던 실행 문자열도 사용자 요청에 따라 추가 번역한다.

## Decision

대시보드의 화면·접근성 레이블·오류·상태·확인 문구와 한국어 숫자 표기를 적용한다. 집필 프롬프트와 storyctl의 안내·오류·명령 도움말, Chrome 준비 도구의 모든 안내·오류, README의 실행 예시를 한국어로 작성한다. 한국어 장 제목의 형식을 이어 쓰기 프롬프트에도 유지한다. 구간 임시 파일은 전반.md/후반.md로 통일하고 이전 파일명의 복사 변환 규칙을 추가한다.

브라우저 테스트는 한국어 데모 사본을 사용한다. 원본 데모, 파서가 읽는 필드, 상태 스키마와 문장 감지 정규식은 보존한다. 긴 한국어 탭 이름이 글자 중간에서 줄바꿈되지 않도록 간격과 글자 크기를 조정한다.

## Alternatives considered

- 한자를 전부 치환하면 검색 결과는 사라지지만 외부 사이트 파싱과 기존 데이터 호환성을 파괴하므로 채택하지 않는다.
- 문서만 번역하면 동작 변경 위험은 작지만 실제 화면과 실행 메시지가 남으므로 요청을 충족하지 못한다.

## Consequences

대시보드와 이번에 수정한 집필·브라우저 준비 안내는 한국어로 표시된다. 한국어 메시지와 기존 차단·저장 동작을 함께 검사한다. Windows 전체 CI 명령 61개가 통과하고 Chromium 데스크톱·모바일 UI 검사는 24개가 통과한다. 공유 동기화는 추가 변경 없이 일치하며 문서 예산 상한은 늘리지 않는다.

이 기록은 저장소의 모든 실행 문자열을 번역했다는 뜻이 아니다. 추적 상태 렌더러, 호스트 훅, 개요·분석 묶음 생성기, 순위 수집·집계에는 중국어 출력이 남는다. 이들은 단순 표시와 파서 계약이 섞여 있으므로 후속 변경 시 생산자·소비자·테스트를 함께 수정해야 한다. 상세 현황은 docs/LOCALIZATION_KO.md와 저장소 밖 remaining-localization/잔여조사.md에 기록한다.

## Follow-up implementation

추가 요청에 따라 다음 출력도 한국어로 바꾼다.

- 개요·설정 작업 묶음(build_architect_brief.py), 가져오기 상세 개요 묶음(build_outline_brief.py)의 지시문·도움말·오류·요약 표시명.
- 기존 분석 검사·장 색인 재구성의 충돌 안내와 영감 카드 검증 안내.
- 추적 트랜잭션의 수정 초안 작성 안내·형식 예시·길이·분량 기록 오류.
- 공통 JS/Python 훅의 본문 차단·상태 리비전·연속성·품질 보완·커밋 안내와 Bash 대체 경로, OpenCode 부가 안내.

중국어 원고 입력과 추적 파일의 기계 판독 제목·상태·절명은 유지한다. 시험 자료를 한국어로 바꿔 통과시키지 않고 출력 기대값을 수정하며, 정규식 변이 검사의 수정 문구 앵커도 한국어로 갱신한다. 호스트 간 판정·문구 일치를 계속 검사한다.

생성되는 작업 지시문의 번역 길이에 따라 개요 생성 관련 예산 21개를 실제 측정값의 100자 단위 올림으로 조정한다. 전역 35,000자 상한, 기존 예외 목록, 읽는 파일·분기·중첩 조합은 유지한다. 공유 훅 3개와 추적 스크립트 2개 사본을 동기화한다.

이번 추가 변경의 검증 로그와 남은 출력 조사 자료는 F:/Novel/.localization-work/runtime-localization/에 보관한다. 순위 수집·집계 보고서, 분석 실행 상태와 추적 파생 문서의 계약 표제, 일부 세션 시작·배포 안내는 아직 중국어가 남아 있다. 전체 실행 문자열의 완전 번역으로 표시하지 않는다.

최종 결과: Windows 전체 명령 61/61 통과. 개요 작업 경로를 `.story/work/개요작성/`, `핵심설정.md`, `가져오기상세개요_…`로 바꾼 뒤 관련 명령 10/10을 추가 확인했다. 경로 이전 테스트 11개가 통과했으며 `第001-012章` 같은 범위형 파일명도 원본을 보존하면서 변환한다. 호스트 에이전트 생성 결과를 갱신했다. 커밋·푸시는 하지 않았다.
