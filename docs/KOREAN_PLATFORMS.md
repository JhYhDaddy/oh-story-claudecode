# 한국 플랫폼 지원 범위

확인일: 2026-11-08. 한국어 번역과 플랫폼 연동은 구분한다.

## 기본 선택

새 작품은 한국 시장을 기본 후보로 삼되 특정 플랫폼은 자동 확정하지 않는다. 직접 연재는 문피아·네이버 웹소설·노벨피아, 시장 조사는 네이버 시리즈·카카오페이지·리디도 포함하고 단편·개인 발행은 포스타입을 제시한다. 선정 이유는 시장점유율 순위가 아니라 직접 연재 경로와 공개 자료의 존재다. 기존 작품과 중국 플랫폼 명시 선택은 보존한다.

## 구현과 미지원 범위

- 집필: 한국 후보와 장르·작가 목표 우선. 국내 플랫폼 규격을 추정하지 않는다.
- 검토: 국내·미정 장단편은 generic. 중국 단편 기준의 암묵 적용을 제거한다.
- 조사: 공개 웹 자료 또는 사용자 제공 자료를 출처·시점과 함께 분석한다. 한국 자료는 중국어 지표 집계기에 전달하지 않는다. 자동 수집기·API는 미구현이다.
- 게시: `게시자료-플랫폼.md`의 한국어 초안 형식 검사만 지원한다. 문피아·네이버·노벨피아 최초 작품 양식과 일부 제한 안내를 확인했다. 서버의 필수값·길이 검사, 회차 등록 및 실제 표지 업로드는 미검증이다. 실제 게시·투고는 수행하지 않는다.
- 단편: 유료 발행을 정한 경우만 전환점을 설계하며 한국·미정에 중국식 도입 요약을 강제하지 않는다.

[2026-11-08 브라우저 검증 기록](evidence/korean-platforms/2026-11-08.md)에 공개 순위 및 세 플랫폼의 로그인된 작품 등록 화면 관찰 결과를 남겼다. 문피아 전화번호 등록은 사용자가 완료했다. 모든 플랫폼의 저장·제출 결과는 미검증이다. 플랫폼별 독자 취향은 실제 같은 장르의 표본으로 검증해야 하며 서비스 이름으로 단정하지 않는다.

## 다음 확장 조건

국내 자동 수집을 추가하려면 플랫폼별 실제 공개 화면에서 순위·추천 목록 구분, 페이지 이동, 누락과 로그인 실패를 검증하고 표본 테스트를 추가한다. 게시 양식 지원에는 확인일이 있는 공식 자료·관리자 화면과 허용값·길이·필수값 검증이 필요하다. 준비된 범위만 지원표에 올린다.
