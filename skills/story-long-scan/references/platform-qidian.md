# 치뎬: 수집과 분석

순위는 기본적으로 모바일 페이지를 읽으므로 Chrome이 필요 없다. 읽지 못할 때만 Chrome으로 데스크톱 페이지를 연다. 서고 신작은 Chrome만 가능하므로 먼저 설명하고 `/browser-cdp`로 시작한다. 스크립트는 남성향 중심인 치뎬 본사이트를 수집한다. 치뎬 여성향을 보려면 수집할 수 없다고 설명하고 작가에게 해당 순위를 붙여 달라고 한다(SKILL의 작가 제공 절 참조).

## 기본 명령

```bash
node scripts/qidian-rank-scraper.js --type newsign --outdir {outdir}    # 신인 계약 신작 순위
node scripts/qidian-rank-scraper.js --type yuepiao --outdir {outdir}    # 월표 순위
node scripts/qidian-rank-scraper.js --type hotsales --outdir {outdir}   # 베스트셀러 순위
```

작가가 신작 중 떠오르는 것을 보려면 서고 신작을 추가한다.

```bash
node scripts/qidian-rank-scraper.js --type library --pages 3 --outdir {outdir}   # 기본 3페이지, 최대 10
```

서고 신작은 ‘남성·연재·30만 자 미만·3일 이내 갱신’을 인기순으로 정렬한 앞쪽 페이지다. 순위가 곧 인기 순위이며 글자 수 중앙값을 낮춘다. 작가에게 ‘치뎬에서 최근 사흘 동안 갱신 중인 30만 자 이내 신작을 인기순으로 첫 3페이지 수집하므로 브라우저를 열어야 한다’고 설명한다.

## 선택 순위

`--type`을 아래 값으로 바꾼다. `all`은 모든 순위(서고 신작 제외)를 수집한다. `--mode mobile|cdp`는 모바일·데스크톱 읽기를 강제한다.

| 순위 | --type | 확인할 내용 |
|------|--------|--------|
| 신인 계약 신작 | newsign | 신인 계약 작품과 새 흐름 |
| 계약 작가 신작 | signnewbook | 계약 작가의 신작 |
| 일반 작가 신작 | pubnewbook | 잠재력 있는 작가 |
| 신인 작가 신작 | newauthor | 신인 영역 |
| 싼장 추천 | sanjiang | 편집자 선정과 플랫폼의 집중 추천 방향 |
| 월표 | yuepiao | 유료 지지 |
| 베스트셀러 | hotsales | 구독 실적 |
| 읽기 지수 | readindex | 종합 읽기량 |
| 소장 | collect | 모바일에는 없으며 서우 순위로 대체 |
| 창작 추천 | recom | 추천표 실적 |

모바일의 두 계약 순위는 같은 페이지라 `newsign`과 `signnewbook` 중 하나만 수집한다. 둘 다 수집했으면 집계에서는 하나로 센다. 머리말의 「移动端实际榜单」(모바일 실제 순위)을 따른다.

## 필드와 인기 측정 기준

순위·제목·작가·장르(대분류·소분류)·상태·계약·과금 방식·글자 수·총 추천·태그·소개·작품 페이지 링크를 수집한다. 누락값은 `[待补]`로 쓴다. 집계는 대분류를 장르로 삼고 소분류는 태그에 넣으며 총 추천을 인기 기준으로 쓴다. 서고 신작의 총 추천은 「新书总推荐」로 따로 두고 기존 작품과 섞어 계산하지 않는다.

## 수집되지 않을 때

- 모바일 읽기에 실패하여 Chrome으로 전환한 뒤 인증을 만나면 스크립트가 최대 120초 기다린다. 작가에게 Chrome 창에서 직접 인증하도록 알린다.
- 머리말 「数据质量」에 문제가 표시되면 「问题摘要」(문제 요약)를 본다. 장르·글자 수가 대량 누락되면 모바일 개편일 가능성이 크다. `/browser-cdp`로 Chrome을 시작하고 `--mode cdp`를 더해 다시 수집한다.

## 분석 차원

| 차원 | 확인할 내용 |
|---|---|
| 월표/베스트셀러 | 유료 순위 실적이며 원래 구독·연속 읽기 수와 같지 않음. 상위권에는 수년 연재한 유명 작가의 기존 작품이 많음 |
| 신작 순위·서고 신작 | 새 작가·새 장르의 초기 신호. 월표·베스트셀러의 장르 비율과 대조 |
| 싼장 추천 | 플랫폼의 집중 추천 방향 |

## 플랫폼 독자

유료 구독·남성향 중심이다. 능력 향상·성장·장기 연재를 따라갈 동기를 원한다. 실력 압도·지략 승리·기회 실현이 주요 쾌감이다. 오랫동안 답답하거나 주인공이 수동적인데 반격도 하지 않는 것은 기피 요인이다.
