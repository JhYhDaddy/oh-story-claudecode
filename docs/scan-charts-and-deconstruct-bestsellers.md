# 인기 소설의 구조를 배우는 순위 조사·작품 분석 자동화

먼저 순위를 조사하고 작품을 분석합니다. 순위 조사는 여러 표본에서 반복되는 패턴을 봅니다. 작품 분석은 황금 첫 세 장을 먼저 보존하고 연속 장 묶음에서 장별 사실, 장을 넘는 인과, 이중 시간선, 3차원 리듬을 함께 추출합니다. 이를 리듬과 감정 모듈이라는 두 재사용 자료로 집계하고 마지막에 원문 근거 위치가 있는 문체 자료를 생성합니다. MIT 오픈소스 Oh Story(`zenstory-ai/oh-story-claudecode`)는 `/story-long-scan` → `/story-long-analyze` → `/story-long-write` 흐름으로 제공합니다. 단편에는 대응하는 `short-scan` / `short-analyze` / `short-write`가 있습니다.

분석은 사용자가 처리 권한을 가진 텍스트를 입력으로 삼습니다. 추적 가능한 원문 근거를 보존하고 결과를 작품 분석 자료에 저장하며 입력 원문은 수정하지 않습니다.

## 1단계: 순위보다 반복 패턴 조사

`story-long-scan`의 원칙은 **한 작품의 순위는 단서일 뿐이고 여러 표본의 반복 패턴이 신호**라는 것입니다. 한 작품의 진입은 개별 사례이며 비교 가능한 동종 표본이 모여야 추세 후보로 표시합니다.

| 플랫폼 | 인기 기준 | 조사 초점 |
|---|---|---|
| 판체 | 현재 읽는 독자 수 | 남성향·여성향 독서 순위. 신작의 부상을 보려면 신작 순위와 서재의 최고 인기 목록(연재 중, 30만 자 이내) 추가 |
| 치뎬 | 누적 추천(순위는 월간 투표·베스트셀러 기준) | 월간 투표, 베스트셀러, 신인 계약 신작 순위. 신작은 최근 3일 갱신·30만 자 이내·인기순 서재 앞 몇 페이지 추가 |
| 진장 | 즐겨찾기 | 수입 골드 순위, 월간 순위. 신작은 신인 골드 순위 추가 |
| 치마오 | 인기 지수 | 남성향·여성향 인기 순위. 신작은 신작 순위와 최근 3일 갱신·30만 자 이내·조회순 서재 앞 몇 페이지 추가 |
| 츠웨이마오 | 각 순위의 집계 값 | 월간 투표·구독 순위. 목록마다 상위 10작품뿐이라 표본이 적음 |

완독률, 연속 열람, 구독 전환은 작가 관리 화면 데이터라 수집으로 얻을 수 없습니다. 작가가 제공하지 않으면 결론을 내리지 않습니다.

자료 공급 경로는 세 가지입니다. 우선 스킬 내장 스크립트로 수집합니다. 치뎬 순위와 치마오 서재 신작은 Chrome이 필요 없지만 치뎬 서재 신작을 포함한 나머지는 필요합니다. 판체는 글꼴을 이용한 수집 방지에 대응해 상세 페이지에서 여러 해독 전략을 사용합니다. 수집 후 먼저 집계하고 주 세션은 집계 결과만 읽습니다. 작가가 순위 텍스트·캡처·기존 파일을 제공할 수도 있습니다. 모두 없으면 내장된 과거 장르 후보만 사용하며 결론은 검증할 가설입니다. 조사 보고서와 `소재선정.md`를 이번 출력 디렉터리에 작성해 신작 기획에 참조합니다. 후자는 추천 소재 2~3개에 대해 흥행 가능 이유, 시장 검증, 차별화, 실현 가능성, 실패 위험, 검증 행동을 정리합니다.

추출 대상은 반복되는 장르, 설정, 클리셰, 제목 단어, 소개의 매력 요소입니다. 월간 투표·베스트셀러의 수백만 자 구작은 기존 독자층을 보여 줍니다. 지금 신작이 성장할 수 있는지는 신작 순위와 서재의 신작을 중심으로 판단합니다.

## 2단계: 하나의 파이프라인, 일곱 분석 단계

`story-long-analyze`는 하나의 심층 흐름을 사용하며 황금 첫 세 장 이후 자동으로 멈춰 계속할지 묻습니다.

| Stage | 작업 | 산출물 |
|---|---|---|
| 0 | 요약 추출과 기계적 장 색인 | `개요요약.md`, `chapter_index.csv`(장별 원문 해시 포함) |
| 1 | 황금 첫 세 장 심층 분석 | `章节/제1-3장_深度拆解.md` 후 일시 정지, `빠른미리보기.md` 생성 |
| 2 | 연속 장 묶음 추출 | 전체 배치 캐시와 호환용 `章节/*_요약.md` 뷰 |
| 3 | 집계 분석 | `플롯/리듬.md`, `플롯/감정모듈.md`, `플롯/이야기선.md` |
| 4 | 설정·인물·관계 | `설정/*.md`, `인물/*.md` |
| 5 | 종합 보고서·전체 요약 | `작품분석보고서.md` |
| 6 | 문체 | `문체.md`(문장 길이, 문장 부호, 대사의 숨은 뜻, 감정 교대 주기와 원문 근거 구간) |

모두 `작품분석실/{书名}/`에 저장합니다. 시간은 입력 길이·모델·병렬 실행 조건에 따라 달라지며 긴 작품은 진행 상태에서 이어 실행할 수 있습니다.

실행 상태는 `_progress.md`의 배치·단계 표 한 곳에만 있습니다. 색인은 장 경계만 관리하고 배치 캐시는 중단 복구에만 씁니다. 계획은 메모리에서 생성하며 여러 JSON 장부로 따로 저장하지 않습니다. 원문 묶음은 최대 3장·25,000자입니다. 플롯 항목 최소 수는 장별 글자 수로 계산하며 짧은 장은 실행 계획의 `min_plot_points`를 따릅니다. 일반 장은 10~20개가 기준이고 긴 장은 최대 30개입니다. 기존 요약이나 황금 첫 세 장 분석에 포함된 장의 원문은 다시 읽지 않습니다.

이전 프로젝트도 사용할 수 있습니다. 검사기는 스키마 값으로 신구를 나누지 않고 실제 장별 처리 범위, 보고서, 감정 모듈, 리듬으로 완전성을 판단합니다. 부분 프로젝트는 빠진 장만 보완하고 신구 요약이 섞이면 장별 출처를 유지하며 전체 재분석을 요구하지 않습니다. 원문 뒤에 새 장을 추가한 뒤 색인을 명시적으로 다시 만들면 새 장만 대기 대상으로 삼고 앞 장의 해시는 되돌리지 않습니다. 기존 요약을 덮어쓰지 않으므로 특정 장을 재분석하려면 해당 요약과 배치 캐시를 지운 뒤 재개합니다.

두 기준 산출물은 특히 중요합니다.

- **`플롯/리듬.md`**: 핵심 정보의 확장 방식, 쾌감·고통·기대의 준비→해소→여운 위치, 소·중·대 절정의 위치, 갈등 고조 경로, 장을 넘는 복선 지도
- **`플롯/감정모듈.md`**: 독자 욕구, 감정 동력, 클리셰 구조를 재현 가능한 모듈 카드로 정리합니다. 집필 스킬이 읽는 것은 이 두 파일이며 `작품분석보고서.md`는 요약 뷰입니다.

Stage 3~4는 장별 관련 인물, 상태 변화, 장간 관계 관찰로 인물 병합(장간 중복 제거·별명 통합), 인물 등급화, 장면 유형 태그도 수행합니다.

Stage 6은 독립적으로 재생성할 수 있습니다. `_style-sample.txt`를 우선 사용하고 없으면 `chapter_index.csv`에서 4~6장을 골라 지정한 줄 구간만 읽어 서로 다른 기조의 원문 근거를 얻습니다. 책 전체를 다시 훑거나 Stage 1~5를 실행하지 않습니다.

## 3단계: 집필에 활용하기

`story-long-write`는 비교 작품의 인물 역할, 감정 원리, 인과 구조를 이 책에 대응시키고 이 책의 인물·소재로 구현합니다. 비교 작품은 연구할 패턴을 제공하며 구체적인 플롯은 이 책의 상세 개요를 따릅니다.

집필 에이전트는 프로젝트 `비교작품/{书名}/`에서 플롯·인물·설정·문체 분석 자료를 읽습니다. 이 책의 사용자 지정 문체가 우선이며 비교 작품은 미지정 특성만 보완합니다. 성숙한 프로젝트가 단축 경로 조건을 충족하면 조립기가 제공한 감정·리듬을 재사용하고 매 장 전체 자료를 다시 회상하지 않습니다. 원리와 리듬을 배우되 자기 장면과 문장을 사용합니다.

## 수동 작품 분석과의 차이

수동 분석은 흔히 장당 한 줄 요약과 플롯 글자 수 기록에 머뭅니다. 이 흐름은 쾌감 포인트·복선을 장 번호로 색인하고, 반복되는 감정 패턴을 모듈 카드로 추출하며, 문체를 문장 길이·문장 부호 분포로 계량하고 원문 근거를 붙입니다. 집필 에이전트는 현재 작업에 맞춰 이 자료를 읽습니다.

## 한계

- 순위 데이터는 당시 접근 가능한 출처에 달려 있습니다. 수집 실패 시 대체 경로 사용을 명시하고 데이터를 꾸미지 않습니다.
- 구조와 기법만 분석하며 원문을 복사해 출판하지 않고 작가의 소재 판단을 대신하지 않습니다.
- 한 작품의 분석 결과는 가설입니다. 소재 결정에 반영할 때 “한 작품만 분석했으므로 확인된 추세가 아님”을 표시합니다.
