# 장르별 본문 프롬프트 카드 색인

> `genre-prose-cards/`의 개별 카드를 장르별로 찾는다. 자동 연결은 아래 검색 규칙을 따른다.

---

## 사용 원칙

본문 집필은 **공통 본문 요건+장르 카드+작품 문체**의 세 요소를 사용한다.

- 공통 요건은 한곳에서만 관리한다. 상세 개요의 플롯 의무를 지키고 천천히 진행하며 후속 플롯을 미리 쓰지 않는다. 집필 후 결정적 분량·훅·금지어·퇴화 검사를 한다.
- 장르 카드는 세계관·생활 논리·독자 기대·핵심 만족과 감정·주요 장면·훅·이탈 금지라는 안정된 핵심만 다룬다.
- 작품 문체는 문장 길이·부호·함축·기준 구간·어조를 정한다. 카드는 장면·기대를 보완하고 `플롯/감정모듈.md` / `플롯/리듬.md`는 감정·리듬의 근거를 준다.
- 사건·연속성·정보 경계는 장별 상세 개요와 권위 있는 검색을 따른다. 표현 충돌은 `style-resolution.md`로 판단하며 명시적 작품 문체가 카드 기본값보다 우선한다.

## 검색 규칙

1. 단일 장 본문 절차에서 조립 보고서를 먼저 받는다. 스크립트가 장르 유형을 카드 머리말의 `genre` / `aliases`와 이미 대조한다. 수동 선택·조회 때만 `설정/소재방향.md`에서 주 장르·플랫폼·독자 채널·주 비교 작품·핵심 소재를 확인한다.
2. 보고서에 주·보조 카드 경로가 있으면 그것만 읽는다. 미일치이면 지정 범위의 `style-genre-modules.md`를 읽는다. 수동 조회는 이 색인을 쓰며 카드 전체를 프롬프트에 넣지 않는다.
3. 혼합 장르는 주 카드 1개 전체와 보조 카드 1개 중 일반 장면·이탈 금지 1–2항목만 읽는다. 두 리듬을 가득 병렬로 쌓지 않는다.
4. 높은 신뢰도는 1장 전 만드는 `설정/소재본문안내.md`에 바로 쓸 수 있다. 중간은 비교 작품·상세 개요와 대조하고 낮음은 보조로만 쓰며 낮은 신뢰도를 명시하고 같은 장르 비교 자료를 우선 보완한다.
5. 매 장 narrative-writer에 주는 `genre_prose_card`에는 관련 항목만 권장 120–300자로 남긴다. 장르 제한·핵심 논리·독자 기대·만족/감정·본문 구현점·전중후반 방식·장면 세부·이탈 금지·현재 선택·신뢰도를 포함한다.
6. **카드는 집필자 내부에서 장르 느낌을 맞추고 본문은 이야기만 출력한다.** 카드명·장르 태그·신뢰도·항목 번호·증거 요약 데이터·카드 준수/분량 충족/위반 없음 같은 자체 평가를 쓰지 않는다.

## 카드 작성

장르 핵심·주선 목표·갈등 동력·만족 위치·일반 감정 전환·장면 세부·본문 구현점·전중후반 방식·이탈 금지의 아홉 질문에 답한다. 도시 일상은 생활 목표부터 정하고 낮은 강도의 갈등이 관계·처지를 바꾸는 과정을 설명한다. 시작·갈등·끝을 물건·장면에 놓고 작지만 보이는 만족을 준다. 장르마다 고유한 갈등·해소 방식을 유지한다.

## 고정 규칙으로 만들지 말 것

로컬 장편 표본은 50–60자 고정 행 길이·대화 50%–60%·‘地/得/很/像/모점’ 전역 치환·무작위 도치·세 호르몬과 여덟 감정·세 반전 네 놀라움 같은 기계적 틀을 뒷받침하지 않는다. 카드는 흔한 장면·감정 구현점만 주고 문단은 상세 개요·문체·현재 장면에 맞춘다.

아래 별칭은 의미를 한국어로 안내한 것이다. 자동 매칭용 원래 값은 각 카드의 머리말에 유지한다.

## 낮은 신뢰도 카드

현재 없다. 새로 추가하면 초안 방향으로만 사용하고 집필 전 같은 장르 비교 작품·사용자 설정·최신 순위 결과를 우선 읽는다.

---

## 낮은 신뢰도 사용 안내

카드만으로 본문을 결정하지 않는다. 먼저 세 가지를 보완한다.

1. 같은 장르 비교 작품의 `플롯/감정모듈.md`·`플롯/리듬.md`.
2. `설정/문체.md` 또는 비교 작품 `문체.md`로 문장 길이·말투·문단 리듬 확인.
3. 현재 상세 개요의 목표 감정·등장 순서·정보 차이·장 끝 훅.

둘 이상 없으면 낮은 신뢰도라고 명시한 임시 `genre_prose_card`만 만들고 카드가 상세 개요보다 우선하지 않게 한다.
