# 마무리 점검

전체 작품 또는 이번 지정 범위의 분석을 마치면 실행합니다. 모두 통과한 뒤 [author-facing.md](author-facing.md)의 전체 완료 문안으로 보고합니다. 아래 검사 결과는 작가 보고에 넣지 않습니다.

- 검사기·계획기를 다시 실행합니다. 완전한 프로젝트는 `direct_use`여야 하고 `continue`의 이번 지정 범위에는 미처리 묶음이 없어야 합니다.
- 전체 파이프라인·재개에서는 「文风一句话」를 `문체.md`에 따라 보완했는지 확인합니다. 옛 프로젝트의 문체만 보충했다면 기존 보고서는 유지합니다.
- 보호 경로 확인: 옛 `장별분석/`·`플롯/`·`인물/`·`설정/`·`문체.md`를 일반 보강·복구 흐름에서 다시 쓰면 안 됩니다. 문체·주 보고서 재구축 또는 감정 카드 수정을 명시 요청받았다면 각각의 지침을 따릅니다.
- 일반 보강·복구는 누락 산출물·새 근거·`_progress.md` 관리 상태 영역만 보완합니다.
- 옛 `schema_version` 값이 바뀌지 않았는지 확인합니다.
- 새로 투영한 사건 순서·주제·기조·유형·「涉及」 필드를 가져오기·집필 흐름에서 읽을 수 있어야 합니다.
- `소재선정.md`를 찾았다면 장르가 맞는 소재의 해당 행만 결과 반영했는지 확인합니다.
