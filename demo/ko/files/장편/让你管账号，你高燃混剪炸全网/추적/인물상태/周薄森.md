# 저우보썬｜현재 상태

- 상태 개정: 1
- 기준 장: 제21장
- 신분: 로켓군 문예단 부단장, 뉴미디어 담당
- 위치: 로켓군 문예단 본부
- 현재 목표: 장천의 창작 공간을 지키며 공개행사 홍보를 심사 목록과 기한에 맞춰 안정적으로 진행하기
- 심신 상태: 단에 공개행사 임무가 주어져 흥분하면서도 14일 기한과 심사 경계를 걱정함

<a id="能力与资源"></a>

## 능력과 자원
- 문예단 뉴미디어 관리 권한
- 장야오쭈와 치 지휘관에게 보고하는 조직 경로
- 공개행사 준비팀 심사 목록의 연락 창구

<a id="关键关系"></a>

## 주요 관계
- 장천을 보호하고 육성할 핵심 창작자로 봄
- 장천 문제에서 장야오쭈와 보조를 맞춤

<a id="已知信息"></a>

## 알고 있는 정보
- 공개행사 자료는 준비팀 심사를 통과한 화면만 사용 가능
- 장천은 14일 안에 노래·영상·현장 공연을 만들어야 함

<a id="未结事项"></a>

## 미결 사항
- 장천이 다음 날 영외 취재를 위해 휴가 허가를 받아야 함
- 제1권 군 홍보 정비의 권 경계는 아직 확정되지 않음
