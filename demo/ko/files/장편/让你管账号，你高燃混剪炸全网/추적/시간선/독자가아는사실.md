# 독자가 아는 시간선

> 상태 개정: 1. 현재 장까지 독자가 알거나 믿는 내용만 보여 주며 작가 측 객관 진실은 누설하지 않는다.

| ID | 독자의 현재 인식 | 인식 기준 장 |
|---|---|---:|
| E001 | 환생 뒤 꼴찌 계정을 맡고 5일 내 100만 과제를 받았음을 안다. | 20장 |
| E002 | 훈련장 자료와 〈중국 군혼〉으로 첫 영상을 만들어 올리는 것을 본다. | 20장 |
| E003 | 하룻밤 흥행과 군보 인터뷰 기회를 안다. | 20장 |
| E004 | 중자자가 할아버지에게 보여 주고 인정·홍보 지원 약속을 받는 것을 본다. | 20장 |
| E005 | 저우보썬의 영혼이 없다는 지적과 장야오쭈의 원본 복귀 승인을 본다. | 20장 |
| E006 | 100만 과제 정산과 반주·새 능력을 받았음을 안다. | 20장 |
| E007 | 중자자의 노병 자료와 장천의 창작 방향 결정을 본다. | 20장 |
| E008 | 우웨이가 스스로 허위를 만들었고 장천은 모르고 곡에 몰두했음을 안다. | 20장 |
| E009 | 윗선이 사업을 취소하지 않고 노병 관심의 기회로 삼는 것을 본다. | 20장 |
| E010 | 댓글이 의심에서 경의로 바뀌고 100만 돌파·관영 매체 지지를 본다. | 20장 |
| E011 | 계정 정지·기소 통지는 알지만 최종 판결은 아직 없다. | 20장 |
| E012 | 1억 돌파·새 보상 정산·중자자 선물 방문을 본다. | 20장 |
| E013 | 절반만 맞혔다는 말만 알고 구체 계획은 모른다. | 20장 |
| E014 | 과제 3·이별 승인·첫 피아노·50년 이야기 회신을 본다. | 제21장 |
| E015 | 탄서우이가 50년간 말해도 아무도 끝까지 못 들은 이야기 존재만 안다. | 제21장 |
