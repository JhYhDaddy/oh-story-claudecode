# 장편의 장별 품질 검사

완성된 현재 장만 검사한다. 집필 절차와 같은 필수 수정·검토 권장·참고 알림을 사용한다. 문체는 탐지 안내에 따라 수정하며 세 층 전체 검사는 `/story-deslop`으로 진행한다.

## 1. 단일 장 검사

### 장 구조

- [ ] 날씨·풍경·일상으로 시작하지 않고 훅이 있는가? 1–3장은 opening-design의 도입부 집필도 확인한다.
- [ ] 중간에 진전이 있는가? 빠른 장르는 보이는 사건, 느린 장르는 상태 변화여도 된다.
- [ ] 읽은 뒤 세계가 달라졌는가?
- [ ] 끝은 요약이 아닌 변화에 놓였는가?

### 진행

- [ ] 목표·위험·정보·관계·자원·정체·감정 입장 중 최소 하나가 바뀌는가? 판체·통쾌물처럼 빠르면 보이는 사건·만족이 필요하며 느린 감정물만 작은 저압 변화로 충족할 수 있다. 매 장 절정을 강요하지 않는다.
- [ ] 분량 채우기가 아닌가? 장을 지워 잃는 상태 변화를 답하지 못할 때 압축한다.
- [ ] 과업이 막힌 뒤 위 상태 변화가 생기는가?
- [ ] 고정 분량 대신 작품의 장르·충족 주기·비교 기준에 맞는 진전 강도인가?
- [ ] 절정·기대 충족 뒤 즉시 새 위기를 기계적으로 넣기보다 잠깐의 저압·작지만 보이는 이익을 허용하는가?

### 정보

- [ ] 긴 설정 설명문이 없는가?
- [ ] 사건·갈등을 통해 설정을 전달하는가?
- [ ] 장당 새 개념이 3개 이하인가?

### 장면

- [ ] 인물의 목표가 있는가?
- [ ] 막는 것이 있는가?
- [ ] 끝의 상태가 시작과 다른가?
- [ ] 심리 구간은 같은 감정의 반복 번역이 아니라 새 판단·오판·결정인가?
- [ ] 사실·인과·말투·관계·감정 연결을 잃지 않는 구간만 삭제하는가?

### 장 끝

- [ ] 위기·결정·발견·반전 중 하나 이상이 있는가?
- [ ] 요약형 끝이 아닌가?
- [ ] 다음 장을 읽게 하는가?

### 언어

- [ ] 공허한 서정 문단이 없는가?
- [ ] 대사가 인물 정체에 맞고 인물별로 다른가?
- [ ] 감정어가 행동 문장·대화 지시·다음 사건·현장 사물로 연결되며 감정만 더하지 않는가?
- [ ] 제목 밖에 장·집필 메타정보가 없는가? `第[一二三四五六七八九十百千万两0-9]+章|上一章|上章|前一章|本章|这一章|前文|后文|伏笔|细纲|读者` 같은 어휘는 금지한다. 이전 내용 연결은 인물이 지각할 사건·상대 시간으로 바꾼다. 이야기 안에서 실제로 X장을 읽고 토론하거나 실제 독자 신분을 말하는 맥락은 예외다.

### 연재 연속성

- [ ] 이전 약속·복선을 잊지 않았는가?
- [ ] 새 설정을 갑자기 많이 넣지 않았는가?
- [ ] 주인공 행동은 설정에 맞고 악역 위상은 현재 단계에 맞는가?
- [ ] 승인된 상세 개요와 새 요소를 대조했는가? 잡담·즉시 반응·기존 플롯을 잇는 작은 연결은 제외한다. 새 관계·약속·후속 의무는 신고 표에 적어 주 세션이 처리한다. 상세 개요·등록 사실과 충돌할 때만 필수 수정이다.

### 불필요한 분량 탐지

다음은 분량 채우기일 가능성이 있는 신호다.

- 장 전체 대화에 새 정보가 없다.
- 감정만 반복하고 이해·행동이 변하지 않는다.
- 긴 장면 묘사가 플롯·인물·분위기에 기여하지 않는다.
- 새로운 관점 없이 과거를 회상한다.
- 없애도 손실 없는 절차 세부·과업 지연은 압축하거나 삭제한다.

## 2. 다섯 차원 점수

차원마다 0–100점으로 평가하고 결과에 맞는 수정 방법을 고른다.

### 차원 1: 핵심 일관성

핵심 갈등·행동·동기가 일관되는지 본다.

| 문제 | 심각도 | 수정 |
|---|---|---|
| 준비 없는 동기 급변 | 필수 수정 | 변화 촉발 사건 보완 |
| 핵심 갈등 불일치 | 필수 수정 | 갈등 설정을 거슬러 수정 |
| 핵심 행동·성격 모순 | 필수 수정 | 행동 조정·설명 보완 |
| 부차 갈등 망각 | 검토 권장 | 회수·완화 |

### 차원 2: 표현

문형·어휘의 상투성을 본다.

| 문제 | 심각도 | 수정 |
|---|---|---|
| 탐지기 blocking 적중 | 필수 수정 | 해당 안내에 따라 수정 |
| 같은 문형 반복 | 검토 권장 | 기능에 따라 통합·재작성 |
| 수사 과다·문어체·연속 비유 | 검토 권장 | 구어체·행동으로 바꾸되 3~5자 단문 나열로 쪼개지 않음 |

### 차원 3: 형식 일관성

극적 단위·화면에 따른 문단, 주어·이름의 자연스러운 리듬, 시작·끝 형식을 본다.

| 문제 | 심각도 | 수정 |
|---|---|---|
| 글자 수로 기계적 분단·주어 과다 | 검토 권장 | 극적 단위로 재배치. 문단 앞 이름, 중간 대명사·생략, 핵심 전환에 이름 |
| 목표 분량 이탈 | 검토 권장(장편 부족은 작가 결정) | 플롯 구현부터 확인. 모두 구현했으면 분량 때문에 사건을 추가하지 않음. 초과는 순수 삭제 최대 1회. 기존 본문 문체 수정에는 새 플롯 금지 |
| 대화·묘사 형식 혼란 | 참고 알림 | 형식 통일 |

### 차원 4: 가독성

장황함·AI 문체·공허한 요약·상투 수사를 본다.

| 특징 | 식별 | 수정 |
|---|---|---|
| 공허한 요약 | 마침내 깨달았다, 말하지 않아도 모든 것이 통했다 | 삭제·행동 대체 |
| 상투 수사 | 운명이 장난치는 듯했다 | 삭제·구체화 |
| 비유 누적 | 같다·마치·듯하다로 모든 장면 설명 | 서사 기능이 큰 소수만 남기고 행동·사물·소리·결과로 전환 |
| 연결 없는 감정 | 슬픔을 느꼈다에서 끝남 | 삭제하거나 지금 못 하는 일을 씀. 직접 표현 자체는 결함 아님 |
| 제자리 심리 | 새 정보 없이 감정 반복·독자가 아는 내용 재진술 | 제자리 부분만 줄임. 정보·결단·감정 전환이 있는 독백은 문장 수로 줄이지 않음 |

### 차원 5: 논리 연결

문장·문단 연결과 설정 충돌을 본다.

| 문제 | 심각도 | 수정 |
|---|---|---|
| 설정 모순 | 필수 수정 | 찾아 통일 |
| 시간선 오류 | 필수 수정 | 시간 표시·수정 |
| 인물 정보 불일치 | 필수 수정 | 인물 기록 대조 |
| 인과 끊김 | 검토 권장 | 연결 보완 |

### 정밀 수정 방법

| 주요 문제 | 방법 |
|---|---|
| 핵심 일관성 낮음 | 핵심 갈등 중심으로 관련 부분 재작성 |
| 초과 분량·무의미한 지연 | 플롯에 기여하지 않는 내용만 줄이고 지연이 만든 변화 보존 |
| 강한 AI 문체 | 단어별 치환 대신 탐지 안내로 수정. 전체 제거는 `/story-deslop` |
| 작은 문제 다수 | 언어 세부 교정 |
