# 집필자 prompt 수동 조립

조립 스크립트를 실행할 수 없거나 사용자가 스크립트를 쓰지 말라고 지정했을 때만 읽는다. 데이터 누락으로 exit 2가 발생했으면 데이터를 고친 뒤 다시 실행한다.

- **prompt 첫 줄은 고정이며 `{}`만 바꾸고 그대로 복사한다.** 호출 계약의 원문:

  `本次任务：{写／续写／补写／重写／就地改}第 {N} 章，范围 {全章／哪几点、哪几段，范围外一字不动}。开始前先按「参考文件体系」逐行独立判定命中并读取，命中即必读，未命中不预加载；交付摘要里报出读了哪几个。`

  한국어 뜻: 이번 작업의 행동·장 번호·수정 범위를 밝히고 범위 밖은 한 글자도 바꾸지 않는다. 시작 전에 참고 파일 체계를 행마다 독립적으로 판정해 일치하면 반드시 읽고, 일치하지 않으면 미리 읽지 않는다. 납품 요약에는 읽은 파일 목록을 보고한다.
  - 행동은 실제 작업 방식으로 쓰고 초고 같은 단계명으로 쓰지 않는다. 보충 집필로 돌려보내거나 품질 저하로 재작성하거나 자체 점검 후 재작업할 때도 실제 방식으로 다시 채운다.
  - 첫 줄은 자료 항목이 아니라 **지시**다. **납품 요약에 읽은 파일 목록이 없으면 읽기 프로토콜이 미완료이므로 다시 spawn한다.**
- 둘째 줄부터 이번 장에 필요한 자료를 전달한다.
  - 프로젝트 디렉터리·장·상세 개요 파일(**전문 없이 경로만**), 이전 장 끝 조각(완전한 행 단위로 되돌아가 약 400자, **경로는 주지 않음**), 출력 경로·제목 행 리터럴. 현재 플랫폼의 기본 경로 구분자를 쓰고 장 이름은 상세 개요의 `### 第 N 章：章名`에서 해석하며 제목 형식은 기존 장을 따른다.
  - 집필 전 준비 출력: 이번 장 의도·작가의 이번 요청·이번 절 간단 메모·목표 감정·관련 인물·이번 장 기법 범주·필독 설정(**해당 문장을 직접 쓰고 경로는 주지 않음**).
  - 주 벤치마크/분석 경로와 주·보조 벤치마크 검색 요약.
  - `selected_emotion_module`, `rhythm_reference`와 출처 경로.
  - `genre_prose_card`: 이번 장 관련 항목만 담은 장르 본문 지침 카드 요약.
  - 문체 전문 경로, `style-resolution.md`에 따른 `style_resolution`, 원문 근거 조각. 같은 판정을 후속 AI 말투 제거와 검토에 그대로 전달한다.
  - `설정/소재방향.md`의 `作者已定`를 그대로 발췌한다. 약 600자 이내이며 넘으면 원문을 끝까지 읽으라고 명시한다.
  - `author_preferences`: 작가 기억 `query --kind prose_style --kind story_design`의 `lines`를 그대로 넣는다. 작품 장르·장편 집필 흐름에 한정된 항목이 있으면 장르×흐름 조합마다 `--genre`/`--workflow`로 한 번씩 조회하고 합쳐 중복을 제거한다. 없으면 전달하지 않는다. `omitted_ids` 중 어느 조회에서도 포함하지 못한 항목은 장 끝 보고의 템플릿 행에 `omitted_summaries` 원문으로 알린다. 전체 프로필·확인 대기 항목을 prompt에 넣지 않는다. 낮은 우선순위의 성향으로 자연스럽게 반영하고 항목별로 나열하거나 일치를 최대화하지 않으며 연결성·리듬·글자 수를 희생하지 않는다.
  - 이번 장에서 미리 공개하면 안 되는 정보와 각 지점의 `放`(허용 영역). 상세 개요에 단계 위치·구조 공식이 있으면 함께 전달한다.
  - 목표 글자 수·`visible_chars_v1` 기준·형식 하드 제약. 기본은 두 묶음 납품이며 주 세션이 checkpoint를 한 번 잰다. 사용자가 명시적으로 한 번에 완성하라고 해야 장 전체로 지정한다. 글자 수 목표는 장 전체 분량 척도이며 밀도는 스스로 배분하고 플롯 지점별 할당량은 적지 않는다.
  - **에이전트 정의에 있는 내용은 반복하지 않고 한 줄 참조만 남긴다.** 상세 개요 우선 경계=철칙 1, 본문 형태=철칙 2, 신규 요소 3등급=철칙 3, 읽기 경험 필드(本章标价／闭环状态／信息差触发点／镜头准入／情节点分辨率列／执行边界의 放 쪽)=철칙 4, 납품 첨부 3개(플롯 지점 구현 위치／마지막 本章没写成的 행을 포함한 신규 신고표／참고 파일 읽기 목록)=被调用协议. 신고표와 미구현 행의 후속 처리는 workflow-chapter의 12단계와 주 세션의 신규 요소 처리 절을 따른다.
  - 집필자가 배치되지 않아 주 세션이 직접 쓰면 이 참조에는 대상이 없다. SKILL.md의 신규 요소 3등급으로 분류하고 신고가 필요한 것을 썼으면 항목별 신고표(유형/명칭/위치/후속 의무, 없으면 `0`)를 만든다. 끝에 `本章没写成的`(이번 장에서 쓰지 못한 것: 상세 개요 미제공/작가에게 먼저 질문)를 붙인다. 작가에게 먼저 물어야 할 것은 쓰지 않는다.

## 검사 분담

수동 조립에도 같은 분담을 전달한다. 집필자는 구성·내용 포괄·형식 자체 검사를 맡고 주 세션의 품질 단계는 의미 중심 AI 말투 제거와 최종 파일 스캔을 맡는다. 집필자가 전체 정리나 같은 검사 사슬을 미리 중복 수행하지 않는다. 플롯 지점 구현 위치·신규 신고·기존 납품 요구는 유지한다.
