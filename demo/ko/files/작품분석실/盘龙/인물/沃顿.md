# 워튼

**archetype**: minor(단역)
**등장**: 약 39%(제2–4, 13, 16–17, 20장)

<a id="档案"></a>

## 인물 기록

바루크 가문 막내·린레이 동생. 시작 두 살 반·재난 때 네 살이며 출산 후 어머니가 병사했다. 가장 어린 가족으로 린레이 감정의 기준점이며 형제의 온기·구명의 은혜에 역할이 집중된다.

경력: 서툰 걸음으로 형에게 안겨 삼베로 바닥→요강→그릇을 닦았다고 아기 목소리로 말해 웃음을 준다(제2장). 검사 밤 힐리 품에서 잠든다(제3장). 훈련 귀가 형을 씩씩하게 맞고 씻으라는 말에 따른다(제4장). 저녁 식탁에서 떠들어 응접실에 웃음을 채운다(제13장). 창고 문에서 “형, 빨리!” 울며 외치다 린레이 아래 보호받아 작은 몸에 상처 하나 없으며 뒤에는 형을 흔들고 고개 숙여 미안하다고 운다(제16–17장). 점심에 기름 묻은 작은 손으로 떠나는 형에게 인사한다(제20장).

성격: 천진난만·형을 따름, 요강 뒤 그릇을 닦을 만큼 분별이 부족해도 잘못은 인정한다. 순수하다. 능력: 어려서 없고 감정 기능 인물이다. 관계: 형이 목숨 걸고 지키는 동생이자 중요한 약점, 자주 안아 주는 힐리와 친하고 호그의 막내다.

## character_arc

두 살 반→네 살로 자라지만 감정 기준점의 성장 곡선은 없다. 형의 보호 본능·형제 온기를 드러내며 재난이 일상 장난을 생사 보호로 높인다.

<a id="关键情节时序"></a>

## 주요 사건(시간순)

1. **제2장**: 형에게 안겨 바닥·요강·그릇 닦기 이야기로 형제 온기 수립.
2. **제13장**: 식탁에서 활기차게 떠들어 웃음을 만듦.
3. **제16장**: 문 앞에서 형을 재촉하는 울음이 몸 던지는 보호를 이끎.
4. **제17장**: 형 아래 무사하고 울며 미안하다고 인정.
