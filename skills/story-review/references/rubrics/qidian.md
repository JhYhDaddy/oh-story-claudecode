# 치뎬 장편 Quality Rubric

## 채점 기준

공통 rubric에 추가하며 치뎬 장편에만 사용한다. 성장과 특전 항목은 해당 장르에 적용한다. 등급이나 특전이 없는 작품을 누락으로 판정하지 않는다. 수치는 참고이며 작품 리듬에 맞춰 선택한다.

| 지표 | PASS 기준 | FAIL 기준 |
|------|----------|----------|
| 쾌감 밀도 | 성장/되갚기/보물 획득 같은 감정 지점 간격이 작품 리듬에 맞는다(참고: 약 3000자마다 한 번) | 긴 구간에 감정 지점이 없어 독자가 보상을 기다리기만 한다 |
| 성장 리듬 | 실력 돌파 간격이 작품의 성장선과 일치한다 | 오랫동안 성장이나 돌파가 전혀 없다 |
| 특전 활용 | 전개에 역할을 하며 등장 이유가 있다 | 독자가 잊을 만큼 방치하거나 매 장 억지로 한마디 언급한다 |
| 연재 추독 훅 | 장말에 궁금증이나 훅이 있고 감정의 연속성이 다음 기대를 돕는다 | 여러 장 연속 끝에 훅이 없거나 감정이 끊긴다. 추독 비율은 실제 데이터로 검증해야 한다 |
| 인물 존재감 | 주인공이 매 장 등장해 진행한다 | 여러 장 연속 주인공이 없거나 진행하지 않는다 |

## 사용 방식

- 성장선·특전·연재 기대를 검토할 때 대조한다.
- 참고 항목이며 이것만으로 필수 수정으로 정하지 않는다. 작가는 작품 목표에 맞춰 조정할 수 있다.
