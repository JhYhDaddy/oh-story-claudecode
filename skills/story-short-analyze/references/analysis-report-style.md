# 작품 분석 보고서의 표현 규칙

> **용도**: `작품분석보고서.md`에서 분석자가 직접 쓴 문장에만 적용하며, 원문을 고치거나 걸러내는 데 사용하지 않는다.
> 원문의 상투어, AI 문체, 독자 거부 요소도 보고할 수 있는 관찰 대상이다. 원문을 인용할 때는 원형을 보존하고 위치를 표시한다.

## 핵심 원칙

분석 보고서는 판단, 텍스트 증거, 위치, 기능을 중심으로 구성하여 독자가 원문으로 돌아가 확인할 수 있게 한다. 분석자가 원문에 없는 장면을 보충해서는 안 된다.

중요한 판단마다 최소 세 항목을 포함한다.

1. **결론**: 어떤 구조·기법·실패 유형을 사용했는가.
2. **증거**: 짧은 원문 인용, 사건 노드, 또는 찾을 수 있는 위치.
3. **기능**: 독자가 아는 것, 기대하는 것, 느끼는 것을 어떻게 바꾸는가.

증거가 부족하면 ‘증거 부족 / 재확인 필요’라고 쓴다. 확신에 찬 말투로 작가의 의도를 지어내지 않는다.

## 보고서 자체에서 주의할 표현

분석자의 문장에 다음 패턴이 나타나면 반드시 재확인한다. 원문 직접 인용은 제외한다.

- ‘A가 아니라 B다’, ‘A도 B도 아니고 C일 뿐이다’처럼 먼저 부정하고 뒤집는 틀에 박힌 문장.
- ‘쉽게 알 수 있다’, ‘명백히’, ‘의심할 여지 없이’, ‘주목할 점은’ 같은 내용 없는 안내 표현.
- ‘운명의 톱니바퀴’, ‘더 큰 폭풍’, ‘이야기는 이제 시작이다’ 같은 소설 본문식 의미 부여나 예고.
- ‘남김없이’, ‘층층이 전개된다’, ‘빈틈없이 맞물린다’, ‘숨 막힌다’처럼 증거 없이 쓰는 만능 평가.
- 직접 진술할 수 있는 관찰을 ‘첫째 / 둘째 / 셋째 / 마지막으로’로 연달아 잘게 나눔.
- ‘빠듯한 전개, 입체적 인물, 풍부한 감정’ 같은 꼬리표만 붙이고 구체적인 텍스트 원리를 설명하지 않음.
- ‘작가는 우리에게 말하려 한다’, ‘작가는 분명 깨달았다’처럼 작가의 심리를 추측함. 관찰 가능한 텍스트 효과로 바꾼다.

## 권장 문장

- `3절에서는 증거의 존재를 먼저 알려 주고 소지자는 숨긴다. 5절에 가서야 소지자를 밝혀 두 박자의 정보 격차를 만든다.`
- `이 단락을 관계 반전으로 분류한 근거는 어머니가 앞부분에서 호칭을 계속 피하다가 여기서 처음 이름을 직접 부르기 때문이다.`
- `충분한 사전 단서를 찾지 못했다. 반전 전에 결과를 암시할 뿐 되짚어 확인할 행동 단서가 없다.`

## 전달 전 확인

- [ ] 모든 핵심 판단의 근거를 원문·사건 노드·통계 결과에서 찾을 수 있다.
- [ ] 원문 직접 인용과 분석자 문장의 경계가 분명하다.
- [ ] 소재의 공식을 정답으로 간주하지 않고 원문이 공식을 어떻게 따르고 벗어나며 바꾸는지 설명했다.
- [ ] 추측을 사실로 쓰지 않았고 불확실한 항목에 ‘증거 부족 / 재확인 필요’를 표시했다.
- [ ] 보고서 자체의 부정 후 반전, 내용 없는 안내, 만능 형용사, 의미를 과장하는 문장을 정리했다.
- [ ] 완전해 보이려고 작가 의도·독자 반응·빠진 사건을 꾸며내지 않았다.
