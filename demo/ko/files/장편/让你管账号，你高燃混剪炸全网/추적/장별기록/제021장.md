# 제021장 · 이별이 어떻게 꽃을 피울까
- 결과: 과제 3은 공개행사 전 이별 주제 작품, 행사 당일 인기도 1000만+, 14일 제한이다. 장야오쭈가 영상·공연을 장천에게 맡기고 이별을 승인하며 자료 심사를 요구한다. 연습실 첫 피아노에 사람들이 모인다. 탄서우이는 이웃 도시 주소와 50년간 아무도 끝까지 못 들은 이야기를 회신한다.
- 다음 장 약속: 허가받아 영외로 나가 탄서우이 이야기를 끝까지 녹음하고 F057 공개. 제22장은 남은 13일로 진행하며 심사 목록 세부는 제23장.

<a id="角色变化"></a>

## 인물 변화
- 장천｜핵심｜과제 3과 작품 주도권을 받고 이별 주제 확정, 단내 첫 피아노, 다음 날 탄서우이 방문 결정
- 중자자｜핵심｜행사 일정·참석을 알리고 이별이 어떻게 꽃을 피우냐 물으며 다 쓰면 알 거라는 답을 기록
- 저우보썬｜핵심｜심사 목록과 14일 내 세 과업의 경계를 보충
- 장야오쭈｜핵심｜처음 직접 속사정을 밝히고 영상·공연을 맡기며 의심 뒤 이별 승인
- 탄서우이｜핵심｜이름 첫 등장, 주소와 녹음 장비 당부, 50년간 아무도 이야기를 끝까지 안 들었다고 회신

<a id="伏笔变化"></a>

## 복선 변화
- F024｜심음｜14일 뒤 로켓군 모 부대 첫 공개행사, 문예단은 영상·공연 하나 담당｜회수 제25장
- F054｜심음｜이웃 도시 주소 확보, 다음 날 방문｜회수 제22장
- F055｜심음｜과제 3은 〈이별이 꽃을 피우다〉 반주, 선율만 연주·가사 미작성｜회수 제25장
- F056｜심음｜연습실 피아노 첫 시연, 공개 작품에는 아직 없음｜회수 제25장
- F057｜심음｜50년간 아무도 끝까지 못 들은 이야기, 내용 미공개｜회수 제22장
- F058｜심음｜이별 주제·행사 당일 인기도 1000만+·14일 제한｜회수 제27장

<a id="时间与揭示"></a>

## 시간과 공개
- E014｜〈소원대로〉 1억 돌파 다음 날｜사실: 과제 3과 14일 카운트다운 시작, 장야오쭈가 영상·공연을 맡기고 이별 확정, 탄서우이가 주소 회신(관련: 장천·장야오쭈·탄서우이)｜독자: 과제·승인·첫 연주·50년 이야기 회신을 봄｜공개됨
- E015｜1974년 가을(탄서우이 고비 복무기)｜사실: 후보 진실. 같은 분대 한수셩이 1974년 고비 시험 사고로 순직했고 대신 보내 달라던 집 편지가 보안 때문에 보류되어 50년 미발송(관련: 탄서우이)｜독자: 50년간 아무도 끝까지 못 들은 이야기 존재만 앎｜미공개

<a id="连贯性约束"></a>

## 연속성 제약
- 행사 자료는 준비팀 심사 목록을 거쳐야 하며 설명 없는 우회 금지.
- 과제 3의 14일 카운트다운는 제21장부터 장별 검증 가능해야 하고 행사 당일 마감.
